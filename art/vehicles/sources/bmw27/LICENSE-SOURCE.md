# BMW model provenance

Original model: Mike Pan, BMW 1 Series M, created for the Blender 2.7 demo.

- Author portfolio: https://mikepan.com/bmw.html
- Original scene used here: https://download.blender.org/demo/test/BMW27.blend.zip
- Model license metadata: https://casual-effects.com/g3d/data10/index.html, BMW entry, Mike Pan and Morgan McGuire, **CC BY 3.0**.
- License: https://creativecommons.org/licenses/by/3.0/

The source scene is retained unchanged. CoastalDrive extracts one vehicle from the original scene, converts legacy Cycles materials to glTF PBR, removes brand badges and the registration plate, resets the wheel display pose, and provides four wheel pivots. The displayed source vehicle name is BMW 1M Coupé; its simulation parameters remain CoastalDrive design values, not BMW specification data. The McGuire corrected OBJ derivative is not used.

Credit in distributed assets: `assets/game/vehicles/ClubCoupe-License.txt`.
