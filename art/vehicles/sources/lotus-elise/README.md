# Lotus Elise 原件与许可

作者 [Stéphane Agullo / sa3d](https://sketchfab.com/sa3d)，主站 [LOTUS ÉLISE](https://sketchfab.com/3d-models/lotus-elise-75e9045ac1af4cdbb69318108c81edfd)，发布于2016-05-25。`sketchfab-metadata.json`为2026-10-22实际读取的作者、完整描述和CC-BY-4.0许可API记录；GLB的asset.extras内有同一作者/UID/许可。遵循明确CC-BY-4.0，不将描述里的royalty-free口语另作授权依据。

原始GLB从Ai2公开[Objaverse](https://huggingface.co/datasets/allenai/objaverse)档案取得：
`https://huggingface.co/datasets/allenai/objaverse/resolve/main/glbs/000-056/75e9045ac1af4cdbb69318108c81edfd.glb`

Objaverse整体数据库为ODC-By，单件继续原作者许可；本项目使用的是这一件CC-BY-4.0对象。数据集署名：Deitke et al., *Objaverse: A Universe of Annotated 3D Objects*, arXiv:2212.08051。

`lotus-elise-original.glb`完整原字节保留，包括原展示场景/人物/动画；加工时不运行任何源脚本。单车提取、去软顶、四轮根、PBR/车漆、既有轮位/外廓适配和法线重建见`tools/blender/prepare_elise.py`。可编辑衍生为`art/vehicles/lotus_elise.blend`，GLB/BAM/源与运行清单各记SHA。运行包署名见`assets/game/vehicles/Lotus-Elise-License.txt`。

显示名对应真实Elise来源，旧`coastal-roadster`存档ID和全部硬件配置保持；明确项目调校，不把通用参数称原厂标定。车库目录图片/接地阴影使用实际新网格离线渲染，原先R2简易模型留在原资源和Git历史。
