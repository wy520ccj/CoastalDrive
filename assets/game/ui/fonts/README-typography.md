# 字体资产

思源黑体 SC Heavy（静态 OTF）用于粗重中文标题、按钮和正文。Chakra Petch Bold Italic（静态 TTF）用于赛车数字与拉丁读数。主菜单字标是单独的透明 PNG，按同一设计图制作，并非把正文拉伸成 Logo。

Heavy与Chakra的官方来源、固定提交、SHA-256和许可见typography-sources.json；实验台和加载画面使用的Bold见lab-font-source.json。旧Fusion像素字体、Regular及其过期专属说明已从当前素材树清理，可从Git标签v0.9.0-dev.20261017.1恢复。现用字形文件保持原始字节，不使用系统字体回退。
