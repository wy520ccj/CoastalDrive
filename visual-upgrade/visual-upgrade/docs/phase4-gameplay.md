# 阶段 4：玩法、计时与道路扩展

当前为 0.4.1 / H3 修复版。复核记录见 `H3-review.md`。

## 计时挑战

Enter 或菜单进入滨海挑战，三秒倒计时后以 120 Hz 仿真时间计时；暂停停止计时。四个检查点位于 20%、40%、60%、80% 处。车辆必须沿正确方向，真正穿过柏油路面范围内的检查点平面，按顺序通过四点并返回起终点。起终线位置为路线进度 0，最后一步按过线比例计算成绩。

进度按有符号的净前进距离累计，不能靠低速前后挪动刷里程。允许倒车调整姿态，后退不取消比赛，重复经过已完成检查点不重复计数。驶离赛道、异常跳跃、复位或漏过检查点都会使本圈无效。车辆可以继续驾驶，但须重新开始才能再次挑战。自由驾驶不计圈速、不写成绩；从暂停菜单提前结束也不记录成绩。

界面显示时间、检查点数量、下个目标、最佳成绩或无效原因。有效完圈后冻结结算状态，支持重新挑战和返回菜单。

最佳成绩保存在 `%LOCALAPPDATA%/CoastalDrive/best-times.json`，按地图规则版本和模式隔离；当前键为 `coastal-v2:time_trial`。旧版仅以模式命名的成绩仍保留在文件内，但不沿用为新规则纪录。非法数值不当作成绩；写盘失败显示提示，游戏仍可继续。自动验收使用独立成绩文件。

## 场景与碰撞

滨海树木按道路净空筛选，树干和岩石有简化实体。检查点仅有一套框架，立柱在道路外侧，立柱和横梁的显示/碰撞由同一份尺寸和位置生成。框架上的 CP 文字已移除，顺序信息只留在 HUD。相机避障忽略框架，车辆碰撞仍保留；树叶、路面漆线仍是装饰。护栏、地形、路肩继续与显示对齐；实体接触不等于已有车损或撞击破坏。

## 高速原型

1.4 km 有限三车道，同向通行。8 辆交通车的初始车道、位置、目标速度、两款外形和五种颜色由种子确定。

交通车采用可受力的简化刚体，具备基础车道回正、前车距离减速和实体碰撞。直路使用共同定义的平整实体路面和护栏；修复超长三角形与简化车体接触引起的弹跳/失速。交通车离开路段后退出物理世界，不瞬移回起点，不在地面外无限下落。玩家到 1400 m 进入自由驾驶结算。

这是有限道路上的基础跟车验证，并非完整现实交通。尚无分段流式地图、持续交通补充、变道、超车、路口规则、交通车完整动力总成或 AI 模式。玩家的物理模型与交通简化模型目前不同。

## 扩展边界

`tracks.py` 提供地图目录、车道和计时路线定义；`race.py` 接收路线定义并处理比赛规则，已用另一套检查点定义验证复用。`session.py` 在固定仿真步内更新比赛状态；`scene.py` 读取仿真快照，换图时与物理一起重建。

无限道路后续需要独立完成道路分段加载/回收、累计里程与本地坐标、交通生命周期和跨分段碰撞；不能只把位置取模后称作无限地图。基础皮肤说明见 README，物理量取舍见 `vehicle-physics.md`。
