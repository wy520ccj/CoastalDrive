# 驾驶响应调校 0.2

2026-09-21，接用户“转向生硬、加速像一下到满速”的试玩反馈。保留 H1 的基础故障修复，继续处理驾驶手感；暂不推进正式地图或 AI。

## 对照旧项目

旧 `ADAS/Constants.h` 定义最大加速度 3 m/s²、最大减速度 8 m/s²。`ADASDlg.cpp:334` 的人工驾驶 W/S 选择这两个值；`CSimulationEngine.cpp:103` 用 `速度 += 加速度 × 时间步长` 更新车速。ACC 模式另有距离误差控制。旧版确实重视加速度，但人工驾驶本身仍是固定加速度模型，没有发动机扭矩、传动比和自动换挡。

第一轮 H1 已使用力推动 Bullet 车体，速度没有直接跳变；问题是油门请求立刻到 100%，转向按角速度限幅在高速小转角下仍能迅速打满，而相机每帧硬跟车头转动。这三个环节合在一起，使驾驶感受过于突兀。此前“能起步和转向”的玩家确认只代表基本可驾驶，不能替代手感验收。

## 当前实现

- **渐进踏板**：持续按 W 约 0.625 秒逐步踩到底；松开更快回收。S 刹车也有短促的建立过程，制动优先。原始 `Control` 保持标准化意图，执行器响应放在统一仿真内，键盘与未来 AI 共用。
- **动力总成**：用一条近似汽油发动机扭矩曲线、五个前进挡、主减速比和传动效率计算轮上驱动力；发动机转速随车速/传动比变化，低速有简化起步离合，换挡有 0.28 秒扭矩中断与防止频繁切挡的间隔。五挡用于轻负荷巡航，满油门不会为了凑挡位而强行升挡。
- **松油滑行**：保留惯性，叠加发动机制动、滚阻和随速度平方增长的风阻；不直接指定目标速度。
- **连续转向**：前轮角度和打轮速度都连续变化，短按、长按、反打和回正有不同过程。高速键盘转向包络按轴距、车速和约 7.5 m/s² 的横向加速度目标收小；轮胎抓地参数也下调。这个包络是键盘辅助，不是实车的机械转向限位。
- **跟车镜头**：方向约 0.22 秒缓冲，位置约 0.08 秒缓冲；视角距离平顺切换，复位立即对齐。镜头状态不写回物理。
- **反馈**：HUD 显示实际油门/制动量、D1–D5/R、rpm 和纵向加速度；F3 显示前轮转角与横向 g 值。只读快照新增这些状态，仍保持不同渲染帧率的仿真一致。

车辆动力采用 `轮上力 = 扭矩 × 传动比 × 效率 / 轮胎半径`，再由物理引擎积分运动，可对照 [MathWorks 纵向车辆模型](https://www.mathworks.com/help/sdl/ref/longitudinalvehicle.html)。当前底层仍是 [Panda3D Bullet raycast vehicle](https://docs.panda3d.org/1.10/python/reference/panda3d.bullet.BulletVehicle)，新增的是可调校的简化动力/执行器模型，尚未实现真实轮胎滑移曲线或经过实车数据标定的高保真车辆动力学。

## 本机测量

seed=17，120 Hz，同一仿真和参数；车辆先静置、在平坦柏油路上测试。

| 操作 | 当前结果 |
|---|---:|
| 轻点 W 0.15 秒后松开 | 峰值约 0.22 km/h，油门正常回到 0 |
| W 持续 0.5 秒 | 约 1.51 km/h |
| W 持续 1 秒 | 约 7.34 km/h |
| W 持续 3 秒 | 约 36.94 km/h |
| W 持续 5 秒 | 约 63.60 km/h |
| 0–100 km/h | 9.383 秒 |
| 100 km/h 刹停 | 42.345 米、2.950 秒 |
| 全油门 22 秒 | 154.245 km/h |

这些是当前模型输出，不是某款实车性能。短按转向在静止/100 km/h 两种执行器探针下，都不会在 0.1 秒内达到满转角；反打不跳变，松手连续回正。
