# H4A 复核与修复 — 0.5.1

2026-09-21。工程复核通过，可推进 5B。人工驾驶手感尚待用户试玩；不是最终美术版。

## 修复结果

- 玩家和 NPC 共用四轮 BulletVehicle、渐进踏板/方向盘、换挡、扭矩及轮胎受力。交通策略 20 Hz，物理 120 Hz；不再通过侧向拉力让盒子沿直路滑行。
- 滨海自由驾驶加入 8 辆沿真实弯道行驶的交通车；计时赛没有交通，自由驾驶的检查点框关闭全部碰撞查询位及显示。
- 净距考虑车长、转角和横向包络；受撞先制动，满足条件后继续；严重事故停车，不传送回正。
- 安全复位检查附近占用和来车制动空间，无位置时提示等待，保持玩家与比赛状态。
- 回收重新加入刚体及车辆，避免回收后停死；generation 阻止跨地图插值。未找到安全空位的车辆后续重试。
- 原高速超长盒子造成车轮射线高度错误。改为 40 m 三角形路面与短段实体护栏；轮迹/路肩/接缝误差检查和高速通过检查通过。短盒面边界仍有凸体射线误差，因此路面采用三角面，不能改回超长或短凸盒来代替。
- 交通模型两款分别适配，四轮取真实世界姿态。保留此前主车轮胎和车身参数。
- 首次同模式启动也按 NPC 数量重建场景；主菜单换漆仍独立于物理。检查点相机位不碰撞，倒车调姿不取消比赛。
