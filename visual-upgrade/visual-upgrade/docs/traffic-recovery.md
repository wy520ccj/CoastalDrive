# 高速交通事故恢复记录

修订日期：2026-09-22。对应版本：0.7.1。

## 范围

`TrafficRecovery` 只接入无限高速的 `HighwayDriver`。车辆出现严重偏转超过45°、偏离目标车道2.8米或翻滚超过35°时进入恢复流程。

恢复先刹停，要求平面速度低于0.7 m/s并持续0.6秒。随后观察前方2.5秒的车体扫掠和邻车匀速预测，等待道路边界及车道间隙连续满足0.8秒，再用2–3 m/s的物理油门/转向控制回到最近车道。姿态稳定0.8秒后恢复原驾驶风格；恢复期间保持双闪，路径再次被占用时重新停车。

翻倒、方向几乎反向、或回正会穿过护栏的情况保持刹停和双闪。远处车辆继续按已有视野外回收处理。恢复没有瞬移、清除速度或关闭碰撞的路径，因此不能宣称任意事故都能自主恢复。

## 已有短检查

24项相关短检查通过，覆盖真实Bullet直路90°和坡路−60°受扰初态的18秒普通控制回正、车辆占位与后车逼近等待、路径再次被占用后的停车、翻车/护栏阻挡，以及普通交通行为和5C挑战回归。

`logs/phase5c/recovery-probe.json`记录6个场景的30秒探查。侧移初态约4–5秒回正，60°偏转初态约10–12秒回正属于初态恢复证据，不等同于真实碰撞后的全场景恢复，也不覆盖复杂翻车救援或事故抢道。

本轮不运行长测。0.7.1双闪实际渲染、构建及独立版弯坡启动已通过，记录见`logs/phase5c/recovery/render.json`和`logs/phase5c/recovery/package/h0-render-smoke.json`；繁忙交通长程、严格可见窗口和后续7B长测另行处理。
