# 阶段 3：滨海环路

H2 修复后的路线长约 **722.9 米**，柏油路宽 **8.6 米**，含路肩总宽 **12.8 米**，道路高差约 **8.08 米**。路线依次包含起步直道、北侧上坡弯、西侧 S 弯、南侧海边弯和回程直道。

## 地图实现

`src/coastal_map.py` 中的少量控制点生成平滑闭环，再按距离重采样为 256 段。`map_meshes()` 生成路面、内外路肩、内侧陆地、外侧悬崖和两侧护栏；物理与画面使用完全相同的顶点和三角形，避免可见路肩踩空、护栏有看不见的断续墙。

道路边线、3 米长/10 米间隔的中心虚线、交替路缘颜色、反光片与柏油颗粒提供近处速度参照。树木和岩石通过静态地面射线放置，不再按道路高度悬空摆放。植被仍是装饰素材。

`point_at(distance)` 按沿路距离取点；`project(x, y)` 返回最近中心线位置、横向距离和沿路距离。这些是路线几何查询，尚未承担圈数、检查点或比赛成绩判定。

## 驾驶与复位

- 游戏默认使用 `Simulation(track="coastal")`，起点为 `(95, 0, 0.55)`，车头朝 +Y。
- R 就近放回当前路段中心，沿道路方向/坡度扶正并清除速度、踏板和转向。
- 车落到海面下会就近复位，显示不会在掉落点和复位点之间插值。
- 追尾镜头用 0.3 米球体扫掠避让路面、护栏和地形；该查询不推进物理。
- 动力学测试显式使用 `Simulation(track="test")`，拥有自己的平面、直道、墙和坡道，正式世界不含这些设施。

`tools/route_driver.py` 仅供验收，未在游戏内加入 AI 按钮或训练模式。比赛计时、检查点、音效、碰撞反馈、完整美术和 AI 接口继续按后续阶段实施。
