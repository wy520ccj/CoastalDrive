# H4A 统一车辆控制设计

2026-09-21：采用一个 Bullet 世界、多辆共享 Vehicle；替代 5A 的受力盒子原型。

## 对象与接口

- `Vehicle` 持有一辆 BulletVehicle、刚体、四轮、VehicleResponse 和动力学诊断。玩家与 NPC 共用现有扭矩、换挡、轮胎、制动力和悬架公式；不为每车复制地图。
- `Simulation` 拥有世界、道路、车辆和回收生命周期。车辆 close 通过 removeVehicle 退出世界；它同时移除车体，不重复 removeRigidBody。
- `vehicle_state.py` 保存 Control、CarState 和轮姿态；simulation 保留原导出入口。快照只读，NPC 附 active 和 generation。
- `traffic.Road` 提供车道采样与沿路投影；高速按距离、滨海按闭环距离判断前后，仍是同向车道。
- `traffic.Driver` 每 0.05 秒输出普通 Control；所有车每 1/120 秒执行控制并在同一世界求解。控制器只操作方向盘与踏板。

## 行驶与安全空位

按前后车旋转包络计算净距，目标速度取巡航、跟车和前方曲率限速的最小值。严重受撞、偏离或翻转先制动；回到合理朝向和偏差后才重新巡航。不能恢复的事故车停下，不传送纠正碰撞结果。

车体碰撞半尺寸沿用 (0.78, 2.05, 0.42) 米，轮距 1.68 米、轴距 2.2 米。占用查询采用 (0.95, 2.15) 米保守平面包络，包含既有车身及外露轮胎；NPC 两款外观适配同一物理尺寸，暂不引入不同性能车型。

R 搜索附近安全车道点，除占用外留出后方来车反应与制动空间。无空位返回 False，HUD 提示等待，比赛/输入不作假复位。玩家 S 仍支持倒车；NPC 制动不会自动换倒挡。

有限高速终点前减速停车，只在远距或车后视野外回收并寻找空位；失败下一周期重试。回收增加 generation，使渲染直接采用新状态，避免跨地图插值。此规则只用于有限预览，5B 将改为随玩家的分段生命周期。

## 模式与画面

滨海和高速自由驾驶默认 8 车，计时赛 0 车。自由驾驶检查点框同时关闭所有碰撞查询位和显示。每辆 NPC 四轮使用真实世界姿态；车辆数量改变也会触发场景同步，避免首次进入自由驾驶缺车。

主菜单换漆、倒车调姿不作废比赛、检查点不拉镜头等已有约定保持。美术资源仍为基础版本，正式车库和素材精修在 6A/6B。

## 基准

车辆组件提取后：0–100 km/h 为 9.383333 秒，100 km/h 刹停 43.289764 米，与原基准一致。详细长期、碰撞、画面和容量证据见 H4A-review.md；物理检查和离屏画面不能替代用户主观手感验收。
