## 找到并修复的问题

| 问题 | 修复 |
|---|---|
| 从高速返回菜单后按 Enter，物理换到滨海，画面仍可能留在高速 | 统一同步当前地图，键盘与按钮路径一致 |
| 仅累计正向距离，低速前后往复可能刷进度 | 有符号净距离、最远前进位置及逆行容许距离 |
| 检查点依赖最近路线进度，不能证明真的穿过检查点 | 有方向的有限宽度过线检测，结合高度、顺序及净里程 |
| 终线画在起点前方，结算计时与视觉不对齐 | 棋盘格从进度 0 开始；最后物理步按过线比例计时 |
| 最佳成绩只按模式保存，非法数字及写盘错误处理不完整 | 分地图规则版本，过滤无效成绩；临时文件替换，失败提示 |
| 高速树木进入车道，树、石和检查点框架无实体 | 道路净空筛选；共同摆放数据；树干/石头/整套框架碰撞 |
| 高速可穿越护栏，交通只做位置循环 | 实体护栏、动态交通刚体及跟车；有限道路明确结束与退出 |
| 交通车直接接触超长三角形地面后弹跳失速 | 道路/路肩/护栏改用显示与物理共同定义的平整实体 |
| 配色只能换整个模型，容易把车灯等一起染色 | 两款现有模型的车漆区域单独换色，保留灯/窗/轮胎 |

## 物理补充

保留用户已认可的渐进踏板、扭矩曲线、自动换挡、发动机制动、连续转向和镜头缓冲。增加空气密度/Cd/迎风面积、相对风速、滚阻系数、轴距/轮距、重心高度及准静态轴荷转移、制动转矩/前后分配和纵向附着限制。新增量参与实际计算；横摆与侧偏作为诊断输出。详细公式、单位与暂缓项目见 `vehicle-physics.md`。

| 动力学指标 | H3 |
|---|---:|
| 0–100 km/h | 9.383 s |
| 100 km/h 刹停距离 / 时间 | 43.290 m / 3.025 s |
| 全油门 22 秒 | 154.244 km/h |

制动距离比 H2 的 42.345 m 约长 0.945 m，原因是加入前后分配和附着限力。没有用更快的位移或虚高速度表掩盖驾驶问题。
