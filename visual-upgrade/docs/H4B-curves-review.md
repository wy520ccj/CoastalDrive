# H4B 弯坡高速接入复核 — 0.6.2 预览

2026-09-22。无限高速现可从主菜单选择直路或弯坡路。弯坡路每公里形成连续缓弯及起伏，200米分段加载，按道路弧长判断交通前后、生成和回收。路面、标线、护栏、地形和树木使用同一道路采样；车仍由 Bullet 四轮物理驱动，未沿路线直接设置位置。

## 已核实

- 10个种子、两种曲线地形的接缝及轮迹射线检查通过：路面最大高度误差1.168毫米，标线0.576毫米；同一接缝的112组实测顶点最大间隙约1.5e-14米。树木到道路边界最小约20.1米。记录：`logs/h4b/curves/surface-final.json`。
- 玩家与12辆交通车共同跑真实物理：种子0的纯弯路180秒行驶5.023公里、2次重定位、42次NPC变道；弯坡路180秒行驶4.247公里、2次重定位、39次NPC变道。采样时车辆均在检测范围内，玩家碰撞计数为0。记录：`logs/h4b/curves/drive-curves.json`、`drive-hills.json`。
- 弯坡种子1追加600秒实车运行：17.641公里、8次重定位、112次NPC变道，所有每秒采样的车辆位置/高度/横滚符合检查范围，玩家碰撞计数为0。记录：`logs/h4b/curves/drive-hills-seed1-600.json`。
- 弯坡离屏渲染540帧，覆盖弯顶、坡顶和一次坐标重定位；相邻帧相机移动小于2米，场景段与物理段一致。主菜单直路和弯坡切换也实测通过。记录：`logs/h4b/curves/ui/report.json`及截图。
- 全套169项回归与Ruff通过，含弯坡倒车跨200米接缝实车检查。实体边界补了同帧重定位支撑检查：静态路面移位后立即更新 Bullet 碰撞世界，避免轮胎射线短暂落空。记录：`logs/h4b/curves/pytest-final.txt`。
- 0.6.2独立版从滨海、无限直路、弯坡路分别启动并完成离屏渲染冒烟检查，三项均通过。记录：`logs/h4b/curves/package-*`。

## 尚未验收

这仍是预览地图。弯坡模式尚无100公里、10个种子各10分钟的动态耐久，也未补足停在接缝、复杂撞击恢复与严格连续可见窗口30分钟。0.6.1的30分钟运行结果及失败条件见 [H4B-endurance-review.md](H4B-endurance-review.md)，不能转记为0.6.2弯坡通过。当前美术仍是低多边形占位；车库、音效与玩家实际试玩要在后续阶段完成。

下一批先补 H4B 剩余耐久和弯坡人工试驾问题，再推进 H4C 的交通密度、复杂切入与碰撞恢复；完整通过门槛见 [development-plan.md](development-plan.md)。
