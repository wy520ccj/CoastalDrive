# H0 修复与验收结果

## 结论

H0 架构关卡通过，阶段 1 骨架补齐，可以进入阶段 2 的车辆物理实现与 H1 调校。

本结论针对独立仿真、时间推进、控制、状态归属、生命周期、测试和显示整合。当前车仍使用明确标注的临时运动模型，没有车身碰撞、悬挂、轮胎模型或正式赛车规则，不代表车辆物理、手感或最终画面验收通过。

## 已完成的修复

- `simulation.py` 独立维护车辆、原型交通、种子、计时与事件。不导入 Panda3D、ShowBase、窗口或 GUI。
- `Control` 和不可变 `Snapshot/CarState` 提供统一输入与只读输出。键盘、脚本控制器走同一个 `Simulation.step`。
- `session.py` 以 120 Hz 固定步长推进，一帧最多补 8 步，记录丢弃时间，显示插值不写回仿真。
- 主菜单、加载、三秒倒计时、驾驶、暂停、结束会话和返回菜单已建立最小流程。结束会话不假装比赛结算。
- Esc 暂停/继续，失焦暂停，恢复焦点后不自动继续。清除旧输入和暂停时间积压。
- 键盘以物理按键集合处理别名；刹车优先、左右抵消、R/C/Esc 边沿触发。S 先刹停，再保持 0.4 秒进入倒车。
- 区分整局重开与车辆复位；复位清零速度、方向和油门，整局重开清理计时与事件。
- 仿真前方统一为 +Y；Kenney 资产子节点旋转 180 度校正原始模型朝向，场景节点仅消费快照。
- 相机切换两档追尾距离，移除原型中不可信的圈数和赛道有效性显示。
- 资源定位不依赖当前工作目录；应用日志写入 `%LOCALAPPDATA%/CoastalDrive`，不再写 `C:/` 根目录。
- 保留现有素材与椭圆道路；仅修复两点道路标线生成时的退化面，未扩建地图或改变美术目标。
