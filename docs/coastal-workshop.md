# 海岸工坊

把车辆改进变成有目标的短挑战：选择方案 → 固定条件试验 → 比较指标与预算 → 驾驶同一辆车。

## 01 制动配方

从源码启动器进入车辆实验室，点左下角橙色“工坊挑战”。这是一辆虚构教学车，基于参考后驱硬件，特意采用45%前制动份额；不代表默认游戏车辆或实车存在同样的问题。

任务要求在平路μ=1.1、80km/h初速、ABS开启/ESC关闭的相同条件下，把停车距离缩短至少10%，峰值横摆不超过0.05rad/s，总预算不超过3点。改变前制动份额花1点；大制动器把最大制动扭矩增加40%，花3点。两者叠加花4点，必须取舍。

点击“运行A/B”，程序分别计算原车与选定方案，每次使用真实120Hz参考试验与正常停车条件。关闭面板会停止挑战；未完成、碰撞、复位或计算失败不能获奖。选项变动后需要重新试验。

达到目标获得铜牌；改善至少12%获得银牌；改善至少12%且只花1点获得金牌。点击“查看曲线”，可用原实验室的速度、减速度、滑移率和ABS等信号比较方案。试验条件、原始命令、完整配置和版本摘要随报告保存。

通过后点击“保存并道路验证”，同一辆工程车进入滨海计时；按顺序通过检查点并完成有效圈，才保存道路完成状态。驾驶HUD显示任务，结算可直接返回工坊，继续尝试方案。道路圈速与参考制动指标分开评价；游戏仍使用既有单机械子步和键盘辅助。

同窗往返保留挑战结果；重新启动从已保存车辆的A/B原始报告恢复。电子控制开关或车型变化后，原工程成绩不再附在新硬件上。普通自由驾驶与专家实验仍可单独使用。

## 02 弯道循迹

在同一工坊顶部选择“02 弯道循迹”。虚构教学后驱车以60km/h为目标，完成40m半径、10秒的定圆；固定路面μ=1.1、ABS开/ESC关和同一循迹/速度控制器。初段存在加减速，评分要求末2秒每一步车速都在60±1.2km/h内，避免靠降速改善误差。

前胎侧偏刚度原配35kN/rad，可选45k（1点）、50k或70k（2点）；前/后防倾刚度28/2可改8/22kN/m（1点、总量不变）；降低重心0.42→0.32m花3点。预算3点，轮胎峰值参数和路面保持。任务要求末窗平均绝对循迹误差≤1.6m且减少至少50%，全程峰值侧偏≤4°、侧倾≤3°；改善≥55%得银，≥65%且花费≤2点得金。

实测原配误差约3.175m；45k配方约1.496m得铜，叠加防倾分配约1.358m得银；50k约1.003m得金。50k再配防倾可降至0.920m并降低侧偏，但花满3点得银。70k虽误差更小，却超过侧偏与速度波动约束；单降重心可减侧倾，未解决循迹问题。查看路径跟踪曲线，比较误差、转角和侧偏，而非只寻找最小转角。

通过后仍可保存同车、完成滨海有效圈并返回或重启恢复。评分从A/B原始完成步复算，选项改变须重新试验；这是固定驾驶员的闭环循迹课题，不等于不足转向梯度测试或实车标定。道路使用游戏既有积分与驾驶方式，计时结果和参考试验分别评价。

## 保存多套方案并比较

实验台底部或工坊右上角打开“方案库”。完成参考试验后填写名称，点“保存当前试验为新方案”：保存的是已运行的完整配置、工况、原始记录、关联A基线和工坊结果，尚未运行的编辑值不会混进去。同名再次保存会建立独立版本，之前的方案保持；失败配方也能保留分析，但不会获得通过奖牌。

左右选择A、B方案，列表每次显示6项，可用下方箭头逐项翻阅全部方案。操稳题并排显示循迹误差、侧偏、侧倾、速度波动和预算；制动题显示距离、横摆和预算。普通工程试验采用现有指标的有效窗。条件一致时显示B−A；工况、路面、车型、控制器、源码或运行库不同会明确标出，不据此生成改装收益或合并曲线。

“比较A/B曲线”把左侧方案作为海蓝A、右侧作为橙色B；工坊本身的原车A仍独立保留。“载回B方案”恢复右侧完整配置、工况及原始A/B，再改装并重新试验。“驾驶B方案”应用这套冻结硬件，通过的工坊方案进入滨海道路验证，普通/未通过方案可自由试驾。返回实验台和重启后仍能选择原方案。

道路完成只更新本次驾驶的同编号、同硬件方案，其他方案保持各自进度。游戏改变电子控制开关或换车型后会解除原方案关联；保存文件失败提示并保留可用记录。方案文件保存在用户数据`design-loop/schemes/`，与当前驾驶车辆分开；坏方案提示并保留，原来的单份工程车辆仍可载入。

## 滨海计时反馈

计时挑战现按4个检查点和终点形成5段。每段结束时，左上角显示该段实际用时、与出发时整圈最佳的该段差值，以及到该检查点的累计差；负数表示领先。例如本段快2秒，但之前一段慢1秒，累计只领先1秒。

结算表逐段列出得失；只在完整有效且更快时保存这一整圈的全部分段，不拼接各圈最快路段。新纪录也仍对照出发时的旧最佳，让改进位置清晰可见。倒车调姿允许，重过同一检查点不重复记段；复位/越界无效圈不更新最佳。

成绩按完整车辆配置SHA256、输入/电子开关和分段规则版本分组；原文件的旧组保留，新增完整指纹组不混入旧版成绩。同组旧记录只有总时间时显示暂无分段，完成新的个人最佳后建立参考。损坏分段保留可用总成绩并提示；无法保存时仍可继续驾驶。

## 个人最佳幽灵

完成有效个人最佳圈后，会自动保存车身与四轮的120Hz真实完成步记录。下一次同配置计时挑战，可用G键或右上角“幽灵”按钮开关参考车。幽灵是半透明显示对象，靠近主车3米内隐藏，3–8米逐渐显现；不参与物理、交通感知、判圈、声音或阴影。

回放对照与分段参考来自同一整圈，出发后不会被新纪录替换。它按当前显示快照的仿真时刻插值，暂停/失焦冻结，重新开始回到记录起点，参考完成后不再外推。没有旧幽灵时，完成新的个人最佳即可建立记录。

记录要求车辆/输入成绩组、种子、物理/控制/判圈源码依赖、原生扩展和实际SDK精度/内容一致。源码版单独改界面不会使记录失效；冻结发行包按实际二进制内容保守校验。物理或SDK不兼容时保留成绩并明确提示，不套用另一圈的幽灵。旧成绩只有总时间/分段时也仍可使用。

成绩更新会立即解除旧幽灵链接，新的内容文件保存成功且仍匹配当前最佳的全部分段时才关联；任一保存失败都不会把旧幽灵冒充新纪录。记录上限30分钟，超过后继续计时但不保存本圈幽灵。文件存于成绩目录下`ghosts/`，原始内容文件不会被较慢圈覆盖。

## 短驾驶课题：定点刹停

主菜单选“高速与驾驶课题”，再选“驾驶课题 · 定点刹停”。使用当前车辆，在封闭直线三车道内从静止加速，以至少80km/h通过100米测速门，再把车身中心停在170米目标线。停车区蓝色外段为±10米，内段±5米，金色中心±2米；误差分别对应铜/银/金牌。

停稳后松开S并保持1秒，持续按住S仍会按既有规则倒车。HUD显示入门速度与剩余距离，结算显示停车偏早/偏晚、最佳误差和奖牌。超过30秒、离开三车道、碰撞、复位、驶过停车区或停得过早均不能获奖；失败会给出具体下一次操作建议。

可以直接重试，或返回实验台比较同车制动曲线，再返回/保存并试驾继续同一课题。选择工坊的道路验证则进入工坊计时路线。最佳误差按完整车辆/输入与规则版本隔离，重开保存；文件失败提示并保留本次驾驶结果。普通自由驾驶与5公里挑战仍使用原车流。

## 接续路线

当前重点是让每一次实验回答一个可行动的问题，并让道路体验提供继续改进的理由。后续依次推进：

1. 已有滨海分段与个人最佳幽灵，结合人工体验继续打磨驾驶反馈，并补有目标的短驾驶项目。
2. 已完成第二道操稳挑战及16种配方测量，保留不同代价的可行方案；轮胎硬件与路面分开。
3. 多套方案与挑战进度、有限的解锁成长，再根据人工体验完善速度感、镜头和声音。
4. 虚拟试车员作为可重复的道路评价工具；真实车型标定继续按外部实测证据单独推进。
