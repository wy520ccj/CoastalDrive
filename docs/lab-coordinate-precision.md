# 实验场坐标精度与有限棱边法线

## 实验场采用局部原点

此前lab继承测试地图SPAWN的X=95m。单精度在95m的相邻位置间隔为 $2^{-17}\,\mathrm m\approx7.629\,\mu\mathrm m$；0.0036m/s横向速度在1/960s内仅移动3.75µm，可被舍入为零。车身转动仍改变轮心相对位置，理想导向会读取这种偏移并进行位置修正。这是坐标数值条件问题，不能用轮胎刚度/阻尼标定解决。

独立五刚体/四导向、相同初速/角速度、无重力0.2s实验，只平移初始X坐标：95m时最大横向位置误差10.69µm、相对速度0.001465m/s；局部原点时分别0.470µm、0.00009154m/s。位置误差减少，但单精度与有限步导向误差仍存在。

正式`Simulation(track="lab")`从X=Y=0创建，Z初值仍按车型设计高度换算；重开同样处理。实体凸起仍按车辆起始相对位姿创建，控制、距离、转向路径、摩擦分类与读数消费实际世界。普通测试场、海岸和高速起点保持。没有在运行中移动或重设车辆/道路，也没有关闭约束或改变ERP。

保存的真实失败前状态另用于独立初值单步对照。原生motor实际误差乘−0.2/h与下一步横向相对速度相符至1.61e−7m/s。仅诊断把停止ERP设零，速度约3.5e−7m/s，但这不能保证导向位置正确，因此生产ERP保持。源实现见[Bullet6DOF](https://raw.githubusercontent.com/bulletphysics/bullet3/2.84/src/BulletDynamics/ConstraintSolver/btGeneric6DofConstraint.cpp)；[Panda同步](https://raw.githubusercontent.com/panda3d/panda3d/v1.10.16/panda/src/bullet/bulletRigidBodyNode.cxx)说明位姿读取边界。源代码说明算法，实际差额仍由上述本项目试验证明。

## 棱边内部特征的法线

局部原点下8子步在第947机械步暴露共同线搜索停滞：动量残差3.66893e−7Ns。已完成946步/0.9854167s，不作为完整凸起通过。完整纯数值输入保留为可信本机回归夹具，单步重放产生相同错误。默认EPA距离精度达标，但棱边法线微小噪声仍足以阻止1e−9Ns门槛收敛。

有限Box道路见证点位于棱的内部时，法线必须垂直该棱，且落在相邻面法线锥内。设两面单位外法线为 $\mathbf b_0,\mathbf b_1$，棱上参考点为 $\mathbf e$，轮心为 $\mathbf c$，包络支持点为 $\mathbf s(-\mathbf n)$。在法线锥中取

$$\mathbf n(\theta)=\cos\theta\,\mathbf b_0+\sin\theta\,\mathbf b_1,\quad0\le\theta\le\pi/2.$$

有符号分离距离为 $d(\theta)=\mathbf n\cdot[\mathbf c+\mathbf s(-\mathbf n)-\mathbf e]$。支持函数的方向导数给出

$$d'(\theta)=\mathbf n'(\theta)\cdot[\mathbf c+\mathbf s(-\mathbf n)-\mathbf e].$$

端点导数确实包围内部驻点时二分52次，再核对投影见证点仍在有限棱内部。该计算使用既有胎冠支持函数、真实尺寸和当前轮轴，没有新的拟合系数。面内部仍解析、未确定为内部棱的特征仍采用已验证的GJK/EPA；不是平滑所有法线或改变道路形状。独立圆/棱几何以实际原生尺寸核对法线至2e−13；尺寸本身是单精度，测试不能把名义0.01m误当实际精确高度。

同一失败输入修正后4次迭代通过，动量7.94e−13Ns、力1.17e−11N、端口零、局部能量−4.68e−12J。既有1e−9Ns/1e−5N/1e−9Nm共同门槛保持。距离精度足够不等于方向/导数足够；该修复使真实凸起轮荷与摩擦预算可稳定共同求解。

## 工程用途与未完成项

坐标与几何数值误差会进入轮心速度、轮荷和ABS/制动反馈，必须先处理，随后才有依据识别簧下质量、径向刚度与阻尼。参考值仍是设计假设；最终需要相同路面输入的轮荷、行程、车身加速度和制动实测对照。长距离场景、原生浮点累加/导向、完整能量细化、颠簸制动A/B及实测/人工Gate仍开放。完整结果和执行版本见[证据](evidence/SIM-UNSPRUNG-01/local-origin/README.md)。
