# 交通互动调校 — 0.6.1

2026-09-22。针对用户反馈：车流变化不明显、对玩家反应弱；尤其玩家从后方追近时不应统一让NPC减速。

## 本次行为

- 三类驾驶风格，期望速度19–35 m/s，跟车时距和变道收益门槛各异。每10–22秒选择持续的巡航、稍放慢或提速意图，目标速度变化率0.6 m/s²，仍由油门/刹车和四轮物理执行。这些是游戏调校值，不是驾驶人群实测分布。
- 被慢车压住时积累等待意图，更积极寻找安全超车机会；前方持续空旷后考虑回右侧。偏好不能跳过安全间距、后车减速度和目标空隙预约检查。
- 后方快速逼近：通过实际纵向速度识别，0.3–0.6秒识别门槛后寻找让行空隙，优先向右；右侧不可用时可检查左侧。不因后车接近触发危险刹车，两侧都堵住时保持车道。前方同时有障碍时仍必须制动。
- 侧面正在挤入或切到前方：读取物理世界速度，预测未来1.5秒的车身包络接近；按位置和相对速度收油/制动，允许最多0.65米的车道内避让，目标变化率0.6 m/s。另一侧有车时取消侧移，实际运动由轮胎受力产生。
- 变道仍提前打灯并经过连续路径。默认无限高速12辆车，初始分布范围从800米收紧到540米，增加可遇到的互动；三档密度选择还未完成。
- 本次高级行为只作用于无限高速。滨海、旧有限高速控制器及主车动力学保留。

参考 [MOBIL](https://traffic-simulation.de/info/info_MOBIL.html) 的动机/安全分离与 [SUMO sublane](https://sumo.dlr.de/docs/Simulation/SublaneModel.html) 的连续侧向运动、横向间距和合作动机。没有复制其源码；本实现是结合当前Bullet车辆的简化规则模型。

## 验证

- 全量139项回归通过，48.60秒；Ruff通过。覆盖反应时间、侧面预测、另一侧占用、后方逼近不制动、安全让行、回归车道和可复现变速。`logs/traffic-v2/pytest.txt`。
- 12车、种子0/1/2各600秒普通车流全部通过，共525次完成变道；未检测到玩家/NPC或NPC/NPC接触。`logs/traffic-v2/long`。车辆数和分布已改变，不能将变道次数与0.6.0直接当作同条件提升比例。
- 7个固定条件物理互动场景通过预期判据，6组无接触，1组保留不可避免的追尾。脚本 `tools/traffic_interaction_check.py`，证据 `logs/traffic-v2/interactions.json`。
