# 径向压缩的共轭法向端口

轮胎包络只由轮心位置、轮轴方向、半径、胎宽和胎冠定义；它不读取自旋角。轴对称轮胎绕自身轴滚动，不会改变包络高度或径向压缩。因此法向弹性势能对车轮自旋的梯度必须为零。这是模型几何对称性，不是低速阈值或小量钳零。

在固定真实支撑平面上，设单位法线为 $\mathbf n$，轮心为 $\mathbf c_i$，平面常数为 $d$，包络支持函数为 $e(\mathbf n,\mathbf a_i)$。压缩量为

$$\delta_i=e(\mathbf n,\mathbf a_i)+d-\mathbf n\cdot\mathbf c_i.$$

设 $\mathbf s_i^-$ 为未加载包络相对轮心、朝向道路的支持点，$\mathbf r_i$ 为轮心相对簧上CG的力臂，$\mathbf u_i$ 为导向单位矢量。法向速度端口满足

$$\dot\delta_i=-\mathbf g_{n,i}\mathbf z-v_{n,i}^{\mathrm{steer}},\qquad
\mathbf g_{n,i}=\left[\mathbf n^T,\ ((\mathbf r_i+\mathbf s_i^-)\times\mathbf n)^T,\ \mathbf n\cdot\mathbf u_i,\ \mathbf 0_{\mathrm{rotors}}^T\right].$$

第三块位于第 $i$ 轮的导向速度列。指定转向只通过轮轴方向改变支持函数；原车身/轮心质量与有限传动惯量保持。法向弹性/阻尼仍为现有 $F_n=\max(0,k_r\delta_++c_r\Delta\delta_+/h)$，同一Fn经过该共轭端口，进入共同质量响应和实际冲量提交。轴向自旋不直接收到Fn扭矩，纵横胎面力、制动、滚阻和真实转子陀螺作用继续保留。

问题来自扫掠见证点的坐标。原查询沿悬架上轴平移包络，在“未加载中心” $\mathbf c_i+\lambda\mathbf u$ 上找到道路见证点。直接用见证点减实际轮心，会把 $\lambda\mathbf u$ 的切向分量计入力臂；车身俯仰/侧倾后，它给Fn产生非零自旋半径。该速度不属于包络压缩，却被旧端口用于径向储能预测及轮速反力。当前明确把切向材料点端口和法向包络端口区分：Fx/Fy沿用材料点/拖距机制，Fn使用支持函数的梯度。支持点沿法线增加 $\delta\mathbf n$ 不改变法向力矩。

独立倾斜真实Plane查询以±1e−5rad虚旋转比较几何压缩导数，三个世界转轴的共轭端口1e−8m/rad检查通过；虚查询不移动实际刚体。原倾斜加载见证点会产生>1e−5m的假自旋半径，新端口的六个转子列严格为零，Fx/Fy端口与原函数逐项相同。Fn仍影响真实轮心/车身运动与负荷预算；修正不保证换轮速后整车轮荷完全不变，因为真实陀螺、驱动和制动依然会间接影响载荷。

真实60km/h手动0.125s，2子步累计径向储能差从-1.829919J降到约-0.001006J；整车累计残差从-1.940608J降到-0.098351J。4/8子步的径向储能差进一步约-0.000535/-0.000314J，但整车累计残差为+0.002786/+0.073198J，存在原生速度与几何惯性项，不能凭4子步相互抵消宣称整车收敛。凸起2.4s仍约8.028J峰值，边缘有限几何/末姿态联合求解需继续完善。

本节点不改变系数、质量、求解阈值、真实碰撞或固定120Hz时钟。它解决一个实际虚功错误，还不是全部有限接触/全车能量Gate通过。对改变的曲面法线和跨有限面特征，仍需核对末几何与离散压缩梯度；不能把支持平面的解析证明外推为所有凸体接触已通过。见[实际证据](evidence/SIM-UNSPRUNG-01/normal-port/README.md)。
