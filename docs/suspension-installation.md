# 压缩螺旋弹簧：安装预压、静载与松弛

2026-10-15，基线f839933，独立仿真工作树。新机制只在显式独立轮心模型启用；默认/游戏硬件保持原定义。弹簧受力进入既有真实五刚体、34未知量共同求解，不在UI另算一辆车。

## 安装量与刚度分别来自哪里

部件台架给出相对自由长度的压缩—力曲线及其斜率ks；安装几何给出参考轮心位置处的弹簧压缩x0；安装运动比rs给出部件与轮心压缩增量关系。[Altair Spring Dampers官方说明](https://help.altair.com/hwdesktop/hwx/topics/chapter_heads/spring_dampers_r.htm)也分别用预载力/自由长/安装长度表达参考位置处的力，而不是用提高刚度代替预载。本节点采用明确的压缩正方向：

$$
x_s(q)=x_0+r_sq,\qquad
k_w=r_s^2k_s,\qquad F_0=r_sk_sx_0.
$$

F0是q=0处的轮心等效预载，单位N；x0是部件安装压缩，单位m。系数中只对刚度乘两次运动比，对参考力乘一次，来自虚功`Fw dq=Fs dxs`。预载改变安装工作位置，不改变已接合线性弹簧的切线刚度。

当前q零位沿用原悬架参考长度：轮心位于连接点沿导向延伸一个`getSuspensionRestLength()`处时q=0。它**不是自动求出的静载车高位置**。若数据是在静载qref处测得压缩xref，应先换算`x0=xref−rs qref`，不能把xref直接当作x0，否则会重复安装压缩。q的读取与参考映射见`src/vehicle_unsprung.py::install_guides/read_mechanics`。

## 力、储能与完全松弛

未保持在弹簧座上的压缩螺旋弹簧不产生拉力。以`[z]+ = max(z,0)`定义

$$
a_i=q_i+\frac{F_{0,i}}{k_{w,i}},\qquad
U_c=\frac12\sum_i k_{w,i}[a_i]_+^2,
$$
$$
F_{c,i}=\frac{\partial U_c}{\partial q_i}=k_{w,i}[a_i]_+,\qquad
k_{t,i}=k_{w,i}\mathbf1_{a_i>0}.
$$

广义恢复力为`−∇U`，真实车身与轮心承受相反内部力。松弛后的弹簧力和切线刚度均为零；减振器、防倾杆及行程止挡有各自的连接和本构，不随弹簧松弛一并删除。

U保留参考位置已存储的安装能量。例如每角kw=48000N/m、F0=960N，q=0处存储9.6J，四角38.4J。总能量计算使用实际末构型的U差值，不把这部分能量伪装成发动机功、道路功或材料热。原生冻结力方向仍带已有有限步积分误差，原始总账与数值功继续分别记录。

物理用途是核对静态车高、轮心工作行程、回弹时弹簧何时卸载，以及安装长度和部件斜率能否对应同一硬件。单纯增大k可能碰巧匹配某一静态力，却会同时改变动态固有频率，因此不能代替安装数据。

## 数据与操作

沿用“高级参数 → 导入悬架台架”。新输入版本`coastal-suspension-bench-v2`在每角增加`spring_installed_compression_m`，声明零位为参考轮心行程，弹簧台架输入仍从自由长度计量。四角安装来源、部件ID、温度、单位、训练/整序列留出与误差门槛继续保存。

完整工程配置新增：

- `suspension_coil_enabled`：显式选择压缩螺旋本构，须已启用独立轮心模型。
- `suspension_spring_preloads`：四角轮心等效F0。未启用该机制时拒绝非零预载，不允许在不支持的旧原生分支静默忽略。

同目录[证据](evidence/SIM-UNSPRUNG-01/preload/README.md)含合成输入示例。导入v2后F1按当前实际配置显示新势能和安装换算；查看旧记录时使用旧记录的原双向公式。GR86旧车型账本没有这些字段时明确显示“未提供”，不归为原厂或实测值。

旧工程文件缺少新字段时恢复原双向弹性/零预载；旧v1台架输入也保留原声明和历史报告重算协议。v2报告可独立从嵌入原始数据重算，不需要虚构一个车辆惯量来验证来源。

采样适用域将真实轮心q转换为`max(x0+rsq,0)`，减振器仍按自己的运动比换算活塞速度。当前安装值被覆盖后，不沿用旧安装适用域；只核对120Hz完成拍采样，不声称覆盖子步峰值或其他温度。

## 验证与边界

相同部件/质量/轮胎的A/B只改F0，均显式启用压缩弹簧。平路同一静载下，理论行程差`Δq=−ΔF0/kw`；对本例960N/48000N/m，应减少0.02m悬架压缩，并提高簧上车高约0.02m。固有刚度保持，四轮静载不能凭增加预载而凭空增加。

独立原生空中释放检查使用正常重力、实际五刚体/四导向与全部碰撞，只在t=0定义离地初值；为匹配解析极限明确取无空气/无阻尼、零发动机外部驱动。簧上1040kg、轮端合计160kg、四角总刚度192000N/m，对相对行程的约化质量为138.6667kg，解析松弛时刻0.042214s。松弛后力保持零、内部能量不增加、质心按重力下落；2/4/8子步行程误差随细化下降。它是被动材料极限，不代替包含空气、传动/轮胎及道路的完整工况。

常运动比、线性部件及非负安装压缩仍是当前支持范围；负安装压缩意味着参考位置存在弹簧座间隙，当前明确拒绝，未偷偷置零。没有并圈、辅助弹簧、气体预载、摩擦/迟滞或温度模型。变运动比需要从`x(q)=x0+∫r(q)dq`建立势能，并保留`Fs·dr/dq`几何刚度；不能把rs换成曲线后只套`r²ks`。

实际命令、日志、完整记录、误差及原始能量残差见证据包；有限姿态整体能量、K&C、实测和人工验收仍开放。
