# H1 审查与修复

> 本文保留第一轮 H1 基础故障修复记录。用户随后确认基本可驾驶，但指出油门/转向手感生硬；最新实现、参数和验收状态见 [handling-v2.md](handling-v2.md)。本文 8.258 秒/41.088 米等数字属于第一轮，不是 0.2 调校后的指标。

日期：2026-09-21。审查基线：`94890d9`（阶段 2 提交）。

## 结论

原阶段 2 交付不通过 H1：用户报告的“按键没作用、车开不起来”能在原仿真中复现。原来的 31 项测试与自动油门截图不足以证明车辆可以正常驾驶。

本轮已修复这些工程问题并补充行为测试，H1 通过。车辆参数和应用输入路径的复测通过，真实键盘测试窗口已观察到车辆驶离起点并达到 54 km/h，用户随后明确确认“能正常起步和转向”。当前场景依然是测试场，不能作为“正式画面精美、游戏好玩”的验收结果。

## 发现并修复的问题

| 等级 | 原问题与影响 | 本轮处理 |
|---|---|---|
| P1 | 静止约 10 秒后车体休眠，之后连续给油 5 秒位置仍完全不变 | 禁用玩家车辆休眠；增加空挡静置 15 秒、刹车后静置再起步两条回归测试 |
| P1 | `setSteeringValue` 接收度，原来只传 `0.42`；转向幅度极小，旧测试只检查微小漂移的符号 | 改为低速最大 30 度，100 度/秒逐渐打轮和回正，高速收小转角；检查实际 3 秒转弯位移/航向 |
| P1 | Bullet 本车轴向下正角左转，原实现方向不匹配；倒车又人为乘一次负号 | 统一 `Control.steering > 0` 为右打轮，交给物理决定倒车航向变化 |
| P1 | 超大薄盒地面配置下接地检测异常，轮胎悬挂长度甚至为负，车体靠底盘贴地 | 改用平面碰撞体，调整车体偏置与轮位；静止时四轮接地，接地点 z≈0，悬挂长度约 0.339 米 |
| P2 | 车身渲染仅跟随位置/航向，轮胎不转，视觉尺度和碰撞不匹配 | 快照增加俯仰、侧倾及四轮位置/四元数；拆出原模型轮胎，独立渲染悬挂与滚动 |
| P2 | 在倒计时按下 W 会被丢弃，到开始时必须松开重按；无明确进入驾驶提示 | 保留倒计时期间按住的驾驶键；增加 Enter 开始/继续、中文说明、油门/刹车反馈与 raw 键事件 |
| P2 | 没有可用的碰撞/坡道场景，只有无限大地面 | 增加直道、实体墙、三个绕桩块和浅坡，物理与可视障碍共用几何定义 |
| P2 | 车辆参数散落、全轮驱动、刹车直接清零水平速度，缺少调校依据 | 参数集中到 `vehicle_config.py`，后轮驱动，动力/阻力/制动通过物理施加，不再靠清零速度刹停 |
| P2 | 交通车相位未更新，静止却输出非零速度 | 恢复种子控制的相位更新，H1 测试场暂不显示这些没有碰撞的装饰交通车 |

转向单位和禁用车辆休眠的接口依据：[Panda3D BulletVehicle API](https://docs.panda3d.org/1.10/python/reference/panda3d.bullet.BulletVehicle)、[官方 Bullet 车辆示例](https://docs.panda3d.org/1.10/python/programming/physics/bullet/vehicles)。轮位、地面和正负号均在本机运行验证，不能只套示例参数。

## 实测指标

使用同一 `Simulation`，120 Hz 固定步长，seed=17，平直柏油地面，静止后全油门；制动距离终点为纵向速度绝对值小于 0.15 m/s。

| 指标 | 结果 |
|---|---:|
| 空挡静置后再起步 | 静置 15 秒，四轮接地；随后正常加速 |
| 0–100 km/h | 8.258 秒 |
| 100 km/h 刹停距离 | 41.088 米 |
| 100 km/h 刹停时间 | 2.933 秒 |
| 全油门 22 秒速度 | 158.456 km/h |
| 高速撞直道末端墙 | 未穿墙；持续给油后车体仍留在墙前 |
| 30 / 60 / 144 FPS | 相同控制输入的完整仿真快照一致 |

具体数值是第一轮 H1 时记录的本机测量；`tools/h1_benchmark.py` 会测当前代码，后续重跑可能覆盖旧报告。0.2 的报告单独保存于 `logs/handling-v2/handling.json`，不要将新报告与本表混用。

## 真实玩家验收

修复版测试窗口已交给用户试按住 W / ↑ 和 A/D。自动化窗口工具只支持短按键，不支持持续按住，因此其短按记录不能替代持续驾驶的验证。`tools/h1_native_check.py` 只观察真实窗口的键盘事件和车辆数据，不注入控制器；关闭测试窗口后写入 `logs/h1-native/input-record.json`。

收尾时在这个无自动控制器的真实窗口中，已观察到车辆驶离起点并达到 54 km/h，画面保存为 `logs/h1-native/real-driving.jpg`。用户随后明确回复“能正常起步和转向”，基本可驾驶性验收通过。这不等同于对最终驾驶手感、美术或游戏趣味性的认可。没有为了收集日志而强制关闭玩家正在使用的窗口。
