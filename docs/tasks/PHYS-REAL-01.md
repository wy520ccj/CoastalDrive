## 参数与实验协议

1. 先完成实车几何与静载：前轮距1.52m／后1.55m、轴距2.575m、53:47静载；轮径.3146m为215/40R18名义未加载半径。实测Premium整备质量1287.295146kg与试验驾驶员／设备载荷分别记录。惯量、CG高度、弹簧、阻尼和限位必须明确推导或标定。
2. 录入同版本六个齿比、倒挡3.438、主减4.1、184lbft@3700rpm和228SAEhp@7000rpm、Cd.276。扭矩示意图可作曲线形状推导，原厂峰值／额定功率是锚点；全负荷有效矩不重复扣发动机闭节气门损失。
3. 原厂13.5整体转向比、锁到锁2.5圈；平均33.333°为推导值，结合转弯几何确认。原厂Torsen类型与模型中的实际限滑规律分开记录，缺失参数由实验标定。
4. 复用参考车的支撑、加速／滑行、制动、定圆、阶跃转向、弯中制动和对开附着实验，同一路面／风／输入／种子对照。先标硬件，再标轮胎与电子控制；每轮调整由对应指标和物理因果驱动。
5. 公共实测目标：0–60mph 5.4s省略一英尺rollout的.3s；以.3048m起计时协议比较，另存完整静止起步时间。1/4mile 14.0s@101mph、70–0mph 156ft、100–0mph 325ft、300ft直径定圆.98g分别使用对应协议。没有公开依据的响应保留模型指标，不填实测误差。
