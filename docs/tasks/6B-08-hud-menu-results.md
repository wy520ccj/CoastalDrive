## 实现与前后差异

- 旧 HUD 把速度、挡位、转速、油门、刹车、地表、加速度和任务文案放在固定小底板，长状态能伸出背景。现在速度独立放大，挡位与转速次级，模式目标与通知分别占区；油门、刹车、加速度、地表进入已有 F3 diagnostics。文本按实际字体宽度换行，HUD 底板按任务/提示行数向下扩展。
- 计时挑战呈现用时、检查点、下一目标、无效原因；滨海自由驾驶只显示模式；无限高速与 5 公里挑战呈现距离、用时和碰撞数。正式 HUD 移除交通实现细节和重复开发信息。
- 旧结算统一以“驾驶结束”作大标题。现在计时与距离挑战按结果分别显示“挑战成功”“挑战失败”，失败原因独立于数据；自由驾驶为“驾驶结束”。数据、说明和操作按钮各有独立层级，自由驾驶按钮文案改为“重新出发”，回调不变。
- 菜单将三个驾驶入口与车库/声音/退出分组；暂停隐藏背后的 HUD 与帮助条。车库仅调整侧栏文字、间距和按钮外观，未修改车辆构图、地板、灯光、材质或相机。
- 底板和按钮采用项目生成的蓝灰渐变细纹理，顶部蓝色细线和分组线统一视觉；没有加入新的 UI 框架或外部素材。曾检查 Kenney 的 CC0 UI 素材包，预览偏明亮卡通，与当前蓝灰驾驶界面不符，未集成。
- Session、比赛规则、按键语义、存档、声音语义、车辆与场景渲染均未修改。
