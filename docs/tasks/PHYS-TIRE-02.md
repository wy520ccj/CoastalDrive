# PHYS-TIRE-02 轮胎轮荷敏感性

- 状态：ready，等待CTRL-03及ABS/TCS/ESC功能组T2收口。
- 基线：CTRL-03最终源码与其完整电子控制证据；实际提交号收口后补齐。
- 目标：使左右轮荷转移自然改变轴的总抓地能力和侧偏刚度，保持标称轮荷下的既有曲线；两模式同一机制，不靠削减车速或加强ESC模拟轮胎效应。

## 已确认缺口与模型

当前 `tire_forces.py` 把峰值能力设为μFn、纵横滑移刚度均按Fn/Fn0线性放大，所以同轴总轮荷固定时，左右分配变化不会减少理论峰值总力；没有真实轮胎的次线性轮荷敏感性。稳态曲线也不含轮胎变形记忆，瞬态另立PHYS-TIRE-03，不能以本任务宣称轮胎真实性全部完成。

采用设计幂律近似：`D=μ*Fn*(Fn/Fn0)^(pD-1)`，`Cx=Cx0*(Fn/Fn0)^pX`，`Cy=Cy0*(Fn/Fn0)^pY`；Fn0=m·g/4，零支撑时能力与刚度均为零。首个候选pD=0.90、pX=0.90、pY=0.85，均为设计值，须先扫描0.5～2倍标称轮荷与实际悬架上限；不称实测MF6.2参数。三指数为1时保留原计算次序，建立关闭敏感性与冻结基线的严格机械对照。

峰值次线性时，固定轴总载荷下 `D(Fleft)+D(Fright)` 在均分时最大，轮荷转移降低总能力；标称载荷曲线不变，Cn单位及低滑移斜率可直接校验。该推导用于机制验收，不以游戏加速门槛倒推指数。

依据：[MathWorks负载相关Magic Formula](https://www.mathworks.com/help/sdl/ref/tireroadinteractionmagicformula.html)明确摩擦系数与滑移刚度随法向载荷变化；本任务使用少参数的设计幂律，而非复刻其完整经验系数。后续[轮胎参数拟合入口](https://www.mathworks.com/help/vdynblks/ug/tiremodel.fit.html)将纵横松弛长度与稳态载荷参数分别标定，为PHYS-TIRE-03提供证据边界。

## 修改职责

1. 纯轮荷特性计算以显式config参数定义，供稳态轮胎、静摩擦可行域和ESC能力预测共同使用；避免vehicle_config与控制模块循环导入。按实际功能组织，不建轮胎注册器或第二个状态中心。
2. 唯一Fx/Fy仍由原隐式轮-车体耦合积分实现；低速静摩擦、离地、倒车与路面变化采用同一新预算。力学子步数、120Hz、轮惯量、原生悬架/碰撞不改。
3. 新参数加入完整参考表/JSON读写、车型配置/reset/NPC与成绩版本；正常游戏与困难仿真共享指数，但保留既有发动机和输入差异。不得随手改动力/控制增益掩盖变化。
4. ESC参考与制动力矩分配使用相同轮荷预算；明确标称侧偏参考与实际非线性轮荷模型的近似关系，必要的模型推导在这一职责内解决。

## 验收

- 特性扫描：0、0.5、1、1.5、2倍标称轮荷，正反κ/α及联合滑移；Fn0曲线与旧版一致，小滑移刚度/峰值比符合指数；同轴固定载荷50:50、30:70、10:90的总能力按理论下降。
- 三指数为1的关闭分支与CTRL-03三场景各1200tick逐字段零差异，新增诊断另列；两模式同配置传递/reset/重定位/回收一致。
- 同车/同初值/同输入全tick A/B：铺装加速与制动、低μ、split-μ、定圆/转向阶跃/弯中制动、离地再接触；轮荷、Fx/Fy、几何/有效能力、κ/α、轮端转矩、真实横摆和电子请求均保存。不要求每工况更快。
- 同步检查静止坡面受力、轮-车体耗散与联合滑移上界、2/8子步的敏感度，不放宽既有交通/碰撞与游戏行为测试。
- 修改跑相关T0，完整功能块跑车辆/核心/交通/道路/玩法T1（包括test_core，防止旧定时假设只在T2暴露）。与后续瞬态轮胎按功能组安排T2；最终T3、可见性能与人体验仍按整阶段Gate执行。
