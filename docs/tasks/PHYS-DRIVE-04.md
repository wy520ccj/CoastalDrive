# PHYS-DRIVE-04 真实输入轴惯量与换挡同步

- 状态：ready，未实施。前置为DRIVE-03有限限滑收口；以实际收口commit建立基线。原护栏音频失败和功能组T2继续单列。
- 目标：曲轴之外增加实体输入轴的独立绝对轴速、惯量和相对壳体转速，纳入同一轮胎/传动/制动末状态；空挡闭合离合时曲轴可以自然带动输入轴，不能锁到虚构零速。
- 机械边界：离合滑差改为曲轴相对速减输入轴相对速；已挂挡的齿轮约束联系输入轴与布局平均轮速。齿轮效率按实际输入齿轮反力与速度计算，不能继续把离合矩直接当输入齿轮矩。输入轴壳体反力、陀螺、动量和储能同时记账。
- 换挡：用真实有限同步转矩消除待接齿比下的轴速差，之后才接受实际挂挡。齿比变化不能重设输入轴/曲轴/轮速，也不能用固定等待完成标记冒充机械同步。输入轴、离合与同步器仍由Powertrain准备请求、共同积分返回实际状态。
- 实施入口：powertrain、transmission_ports、tire_drivetrain、vehicle_tires、配置/快照/研究工具。核心接口需要先独立台架确认九维速度及齿轮反力/损失符号，不建通用多体框架、Manager或新世界。
- 验收：空挡离合开/关与有限升速、正反功流和壳体反力、挂挡/换挡/中断同步的真实能量与热、三布局限滑和制动共同状态。独立能量/角动量负对照检出缺反力或缺惯量；相关短T0后同输入模式A/B和T1。默认游戏参数先从现基线比较，现实参考惯量明确标为设计值，再实车型标定。
- 中间传动轴惯量是否随刚性齿比折算或需要额外实体自由度，在输入轴机制确定后按真实储能定义决定；不能靠配置字段存在宣称已建模。限滑全组T2、SI悬架/防倾、估计器、实车型、研究协议及总Gate仍保留完整目标。
