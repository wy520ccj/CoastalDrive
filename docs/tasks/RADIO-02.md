# RADIO-02 电台曲目区分

2026-09-30，基线main c4ff5ec、VI 2138194。

用户反馈两个电台像同一首歌。核对发现旧生成器共用Am/F/C/G和弦、同一主旋律与谐波音色，仅BPM、琶音八度和打击密度略有差别；RADIO-01波形匹配证明选台正确，但没有证明编曲足够不同。

本任务替换两首电台曲，并按后续用户要求将原海岸曲逐字节保留为独立首页BGM；更新简单音频路由、离线制作/许可/验证记录。海岸FM采用Kevin MacLeod的Bossa Antigua（70 BPM，吉他/贝斯/鼓，轻松Bossa Nova），夜驰FM采用Future Gladiator（132 BPM，合成器/贝斯/拍手打击，暗色电子）。作者官网现行CC BY 4.0授权，打包署名、曲目来源与加工说明。运行时继续使用RADIO-01音乐预载、单曲播放和廉价N/M路径；三首通过同一个播放列表切换，任何时刻最多一首。首页曲独立于驾驶电台选择；设置页始终试听所选电台。

先相关T0，再T1/三种子；真实OpenAL回录核对四个阶段及往返非整采样续播，不把正常乐器高频判成解码噪声。新包与主/VI同步；完整曲目与对比试听交付。已实施：59项相关T1与三种子、真实OpenAL105/105、四阶段与往返续播、可见N路径、响度与61个包音频SHA通过。追加底板修订并入最终包，主/VI同步；[证据](../evidence/RADIO-02/README.md)。用户听感待新版试听。
