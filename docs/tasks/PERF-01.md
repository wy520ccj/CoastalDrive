# PERF-01 — 启动与运行期瓶颈隔离

状态：`done`（诊断收尾；未做性能优化）。基线：`02e6217`，分支 `visual-identity-v1`。VEH-02 / HWY-01 仍暂停，PERF-02 不在本任务范围。

## 结论

- 启动菜单首帧中位数 7.372 s，驾驶切换中位数 2.366 s。时间主要落在 coastal environment 创建，尤其首次 `build_slice` 和既有道具 `add_environment`；切换时重复创建既有道具约 1.4 s。见 `docs/evidence/PERF-01/README.md` 和汇总 JSON。
- 运行期强信号依次为：交通更新/仿真链、阴影、整组 coastal visuals。离屏对照中关闭各自后的提升约 +12.7、+10.0、+8.4 FPS；这些改动互不独立，不应相加或直接变成优化承诺。仅隐藏交通画面提升约 +1.2 FPS，支持交通成本主要不在车辆网格绘制。
- 旧主车、反射和局部补光没有稳定明显的收益；水面 shader 关闭也未显示正收益。暂不把英雄车模型复杂度列为首要瓶颈。
- startup 的 slice / props 单项成本有子阶段计时和开关对照支持；props、slice、地形各自的运行成本仍受基线漂移影响，仅为候选排序。
- 最小化窗口期间约 8 FPS 的报告无效。PERF-00 的 47.62 FPS 缺少窗口状态记录，保留为历史值，但不作为根因结论。当前没有得到有效的可见窗口长测复现，因此性能 Gate 状态仍未确认。

## 测量边界

- 固定的 1080p、种子 23、规则路线短测用于 A/B 定位，不能代表 30 秒预热 + 300 秒的可见窗口 Gate。完成的离屏长测为 55.44 FPS、P95 22.04 ms、P99 24.66 ms、仿真丢时 0；它只能排查漂移，不能替代可见窗口门槛。
- 首版零交通启动案例跳过了 Scene 重建，其约 0.10 s 结果无效；修正后维持相同重建，零交通切换 2.144 s，与基线 2.187 s 接近。
- 本任务没有修改 `src/`、游戏规则、画面、资源、物理或加载行为。短期 case monkey-patch 与矩阵执行器已从工作区移除；汇总器保留作只读报告工具。标准驾驶基准固定为 30 秒预热 + 300 秒采样，并记录窗口状态与 30 秒分桶。
- 已有冗余/失败/中断实验报告移至被 Git 忽略的 `logs/PERF-01-archive/`；正式证据目录仅保留任务结论所引用的报告。被用户要求停止的 traffic CPU 矩阵只有一个不完整样本，不参与结论。
