# HWY-03 — 路肩闪烁修复

状态：连续路肩遮蔽修复及自动验证完成，集成0.8.3-perf03包；人工体验待确认。第一轮基线c9be01d，最新修复基线75413c0及PERF-03工作区。允许高速表现、定向诊断/回归工具和对应文档；物理路网、车辆、交通、UI、海岸保持。保持其他物体投影，不用全局关闭阴影作为产品修复。下面前两轮为历史记录，最新结果见[连续遮蔽证据](../evidence/HWY-03/continuous-shadow/README.md)。

验证：直道/弯坡连续帧前后对比、固定相机光源移动探针、相关T1和新包smoke；不做长性能测试。人工体验另记。保留原包，本地提交，不推送。


原因：curve_mesh.rail的侧面、顶面、底面与端盖绕序朝内。其朝上底面与路肩z=0共面，产生交替白色碎条；关闭阴影诊断仍可复现。只在高速显示副本反转三角形绕序，顶点坐标与原物理碰撞网格未变；直道原本朝外，不翻转。保留全局阴影。

验证：直道12帧正常/无阴影诊断；1080p弯坡24帧慢移动前后对照；720p弯道32帧每帧1m快速移动前后对照。逐帧接触表回看、对照MP4已导出，未将静态诊断算作实际驾驶。T1 Ruff、66项与三种子通过，增加顶底面朝向/原坐标一致回归。新包从TEMP启动弯坡smoke及20次重开检查通过。PIL接触表脚本因依赖未安装失败，改用现有ffmpeg完成，没有安装新依赖。

包：builds/0.8.3-hwy03/win_amd64；试玩-HWY-02.cmd已指向该修复包。原包保留。证据docs/evidence/HWY-03，原始帧logs/HWY-03。普通远处像素边缘抗锯齿仍是独立问题，不声称所有闪烁都消失。用户随后明确授权开始集中性能优化，转入PERF-02。

2026-09-30第二轮：用户仍看到左侧闪动。关闭阴影的同视角探针中左侧细碎硬边消失；固定相机/移动光源的24帧在首帧预热后基本稳定，说明现有世界纹素对齐已起效，剩余问题主要是移动视角下窄阴影边缘的空间采样。没有继续抬高路肩、增加全局深度偏移或提高阴影分辨率。

参考Microsoft阴影深度图指南及NVIDIA GPU Gems的PCF方法，高速路面、路肩和标线局部使用3×3固定PCF核，并按接收平面的深度导数校正每个邻居采样点。继承原global_shadow_bias，附加偏移限制为0.0003。继续使用2048阴影图、既有稳定光源、全部真实车辆/门架投影。海岸/车辆自身材质不修改。实现为既有simplepbr 0.13.1着色器的局部函数替换，没有引入新渲染框架。

验证：直道1080p24帧、弯坡1080p24帧前后同视角对照、弯道720p24帧每帧1m；左侧硬边平滑，门架及交通车辆阴影保留。环境T1 Ruff、46项测试、三种子通过（初次import格式检查失败，修正后重跑通过）。固定相机像素统计不能衡量移动视角锯齿，不将其称为闪烁改善百分比；未增加窗口性能测量。证据见[阴影过滤对照](../evidence/HWY-03/shadow-filter/README.md)。第二轮尚未打包，现有试玩包仍只有第一轮绕序修复；已交接PERF-02统筹集成性能复测及打包。
