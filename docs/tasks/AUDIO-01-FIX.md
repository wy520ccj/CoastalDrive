# AUDIO-01-FIX — 碰撞声库重制与电台/引擎混音

状态：原修订已交付；用户后续指出切台bug和碰撞厚度/响度问题，现由PLAY-01-FIX继续修订。

2026-09-30，基线main 2782552。用户实际反馈：Sunset吵杂沙沙声、碰撞样本含摩擦尾音、几乎所有碰撞偏小且不融洽、引擎默认过大。

范围：完整重制27个单次碰撞变体，去掉素材中的前置杂声和摩擦尾段，统一起音、短共振、形变和碎屑的响度；修正两首电台的噪声打击乐和旋律进入时机，降低引擎默认混音。按原功能模块修改，不改轮胎运行逻辑、真实接触擦碰、物理、UI或交通。完成后更新主项目和VI副本的源码及试玩入口。

原因：原主碰撞录音强撞击约在0.42s，旧裁剪从0秒开始且主体最长1.35s，保留非撞击杂声/摩擦；高通完整撞击尾音被当作碎屑反复播放；额外62Hz正弦和噪声鼓组不贴合驾驶混音。旧引擎满载0.495占据过多响度。

实现：真实撞击附近短取样、去掉人工正弦、全部单次样本≤0.36s，独立塑料落击替换碎屑长尾；瞬态增益0.25+0.5s→0.40+0.54s，主体0.20+0.62s→0.28+0.58s；引擎满载0.495→0.19（-8.3dB）。Sunset白噪鼓与嘶声改为轻音高打击，夜驰降低并滤波噪声，两台旋律提早进入。原4个真实刮擦循环不改。
