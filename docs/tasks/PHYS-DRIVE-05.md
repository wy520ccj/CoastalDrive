# PHYS-DRIVE-05 中间传动轴储能

- 状态：planned；前置PHYS-DRIVE-04实体输入轴与有限同步已接入，当前输入轴设计惯量不包含下游轴系。此任务尚未实施。
- 范围：按前驱、后驱、四驱实际拓扑，加入变速箱输出端及前/后驱动轴的转动惯量、储能、角动量、轴承反力和陀螺；空挡时下游轴仍随车轮转动，不能随离合分离丢掉储能。
- 机械选择：当前齿轮链保持刚性，轴速可按明确齿比约束消元，不为固定约束另加独立自由度。每个实际转子仍有自身惯量、转轴和真实速度观测。车身转动时必须保留惯量矩阵的车身/轮轴交叉项，不能只把一个标量折到输入轴或轮惯量。
- 初态与积分：reset一次设置一致初态；后续从真实上一末状态推进。转向改变机械轮轴时要明确轴速约束、指定转向功与轴承角动量交换，不能重算上一转子速度来抹掉变化。
- 功能入口：先独立机械台架确定刚性消元及反力，再接tire_drivetrain、Powertrain/VehicleTires、配置与Snapshot。按作用组织，不建通用多体框架。设计惯量明确标注，完整通用参考车之后才标定实车。
- 验证：与显式转子/刚性约束台架核对能量、角动量和端口功；覆盖三布局、倾斜转轴、空挡滑行、转向与共同限滑/制动。缺储能/缺反力负对照必须失败。相关T0、两模式标准A/B及功能T1，沿用有效结果，不追加整套长测。
- 后续独立机制：若加入轴扭转弹性或齿隙，相对轴速将成为独立物理自由度；当前任务不预建此扩展。

依据：[MathWorks惯量与齿轮](https://www.mathworks.com/help/sdl/about-inertia-motion-and-gears.html)、[差速器约束和惯量](https://www.mathworks.com/help/sdl/ref/differential.html)。刚性消元及车身耦合的实现选择是本项目推导，需要上述独立机械账验收。
