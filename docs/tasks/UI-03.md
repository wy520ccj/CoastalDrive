## 目标与范围

车库、声音设置、无限高速、暂停和结果面板支持键盘焦点选择和确认；W/S 与上下方向键等效，A/D 与左右方向键等效。可调项目按当前焦点调整，选中项沿用已有悬停素材高亮。

- 允许修改：`src/application.py`、`tests/test_ui.py`、本任务包、`docs/current-progress.md`
- 只读参考：`src/session.py`、`src/ui/main_menu.py`、UI-02
- 不得修改：Simulation、Control、Session 规则、车辆/交通/音频实现、UI 布局、资源和打包配置
- 局部重构：仅在现有 `application.py` 输入处理区增加面板导航与选项调整方法；不迁移文件、不增加框架
