## 完成内容与范围

- 两套固定 OFL 字体：思源黑体 SC Heavy（中文标题、按钮、说明）；Chakra Petch Bold Italic（速度、转速、计时和拉丁读数）。大标题采用轻微前倾，字形采样提高到 160 pixels/unit，覆盖 1080p 实际显示高度。
- 独立透明 wordmark.png、无文字 coastal-menu.png；以用户提供的主菜单设计图为明确参考，不采用生成图上的操作文字。
- 22 张无文字控件 PNG：按钮正常/悬停/按下/禁用、主按钮、面板、速度框和 12 个图标；附可复现生成脚本。
- 主菜单三主三次布局、鼠标点击/悬停、上下选择/Enter 确认。六入口保留原动作；只保存菜单选择索引，不写世界状态。
- HUD 提取至 ui/hud.py，实时显示快照中的速度/挡位/转速、计时、检查点、距离、碰撞和关键提示。7000 rpm 为显示色条标尺，未改变物理。没有小地图、伪造里程或性能数据。
- 暂停、结果、声音设置、车库面板统一字体与素材；结果按现有真实数据展示，动作仍由 application 调用原 Session。声音设置仍为原有即时保存的加减操作；车库仍显示真实选中车型，没有用固定汽车插画代替车型预览。
- 仅新增 main_menu、hud 两个业务 UI 模块；未引入页面框架或 Manager。为既有检查工具保留的 application UI 节点引用仅指向 HUD 自己的节点，不保存第二份状态。
