# GAME-FEEDBACK-01 滨海分段与个人最佳反馈

- 状态：ready；前置DESIGN-CHALLENGE-01，基线取实施前main，单条施工线。
- 目标：通过检查点时看到分段耗时与相同车辆/规则最佳有效圈的差值，终点可读各段得失，给下一圈明确改进点。
- 范围：RaceTracker/BestTimes数据与持久化、相关Snapshot/进程传输/HUD/结算、测试与文档；先读实际接口再定最小实现，不引入第二套物理状态。
- 禁止：物理、驾驶调校、检查点/倒车/复位规则、旧成绩覆盖和远端发布。旧best只有总时长时显示缺分段，不伪造。
- 验收：真实门线插值时间；反复跨线不重复记段；倒车/复位/越界无效；仅有效且更快圈更新整组最佳分段，不能拼接理想圈；完整车辆指纹/规则版本隔离；损坏数据可正常启动并提示；进程/暂停/重开一致。
- 验证：相关T0、gameplay T1/三种子、实际HUD/结算渲染；一批游戏反馈/幽灵完成后再T2。人工圈速反馈与趣味性待确认。
