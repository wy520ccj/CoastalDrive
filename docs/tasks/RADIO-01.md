# RADIO-01 — 电台续播噪声、混台与N切台帧耗时

2026-09-30，基线main fc2a16b，VI c729bbe。用户反馈偶发沙沙声、两曲混合与驾驶每次按N掉帧。

范围：电台播放/保存和驾驶提示排版；保留AUDIO-02引擎/碰撞及既有物理、音乐曲目、暂停设置和UI视觉系统。

修复：两首WAV以独立musicManager和SM_sample预载，避开Panda3D 1.10.16流式WAV续播seek的奇数字节错位；旧曲先淡出停止再启动新曲，连续快速切台最多一曲。驾驶N/M不即时存盘或刷新整页，暂停/菜单/结算/退出时保存。HUD三条电台标签加载时预生成，切台只切换可见性，取消当帧文字生成与逐字测量约11ms阻塞；其他提示一次换行，底板仅在行数改变时更新。
