# CHALLENGE-REBUILD-01 独立预算与能耗联合评价

状态：in_progress（2026-11-23 归并说明：独立预算、油耗、正式奖牌、自动试车及山脊内部边修正等核心机制已完整并入 `CAREER-SEASON-01`，剩余部分路况改装平衡与整包/真人验收统一随第一季及后续阶段推进，不再独立并行挂起）。用户于2026-11-06授权自动驾驶实跑数据替代真人标定。10项固定路线和五公里六种路况已启用正式奖牌，海岸巡回已计分，山脊穿行快跑异常已修复。基线HEAD为15c321f5，本任务本地实施。

## 已确定的产品规则

- 生涯、道路挑战、工坊共用参数改装和报价；每关固定原车与预算，重试免费，无永久购买性能套件。自由驾驶和专家实验保留。
- 工程参数为主；硬件改造收费，原硬件内制动份额、防倾分配调校免费。费用由最终方案相对原车计算，不累计安装，不靠降配返现。
- 超预算允许试验，不授奖/进度。工程和驾驶各占一半；道路按同一次驾驶的用时与L/100km联合分档，费用为预算约束及同档低成本纪录。刹停、定圆保留专项指标。
- 每关固定路线长度折算赛段油耗，发车至终点计量；倒计时、暂停、结算不计，绕路/倒车不能稀释。先燃油车，预留kWh/100km；不做油箱耗尽/冷启动/电驱物理。
- 保留旧车辆、报告、解锁和成绩，不补造旧油耗或兑换新奖牌。赛事临时车辆退出后恢复原车。正式成绩跨预算内方案比较，仍保存完整硬件及规则/能耗/报价版本。
