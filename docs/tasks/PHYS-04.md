# PHYS-04 Ackermann前轮转向

- 状态：done（专项与T1完成，统一T2收口中）
- 基线：`3337fad`，轮胎/动力/悬架/驾驶辅助参数保持
- 范围：vehicle_steering几何、Vehicle前轮角应用、真实转向A/B、定向与交通回归

虚拟前轴中心角δ仍是控制/快照的steering，齿条中心限位仍±26°，左右真实轮角由轴距L/轮距t得到：R=L/tanδ，δleft=atan[L/(R+t/2)]、δright=atan[L/(R−t/2)]。正角为右转，左轮为外轮，Panda实际steering值取反。内轮真实角可高于虚拟中心角；不单独钳两个轮角破坏共同瞬时圆心。低速几何用于减少两前轮互相冲突的侧向约束，不声称高速轮胎力已标定。

同一真实固定步：±6m/±20m低速定圆A/B，实际左右角与接点侧向运动测量；既有七标准工况复核转向、弯刹、split-μ变化；无转向加速/制动应保持。正反方向、倒车横摆符号与机械执行器回归。T0/T1之后本批统一T2。

结果：6m/20m接点侧向速度分别减少98.11%/97.80%，左右对称；质心半径以水平速度模长计算，更接近几何预期。直线加速/split-μ CSV逐字节相同。T1 143通过、三种子/双弯坡通过；T0实际仅原响应7项（重复--tests覆盖），新增检查均由T1覆盖。[A/B报告](../evidence/PHYS-04/README.md)。
