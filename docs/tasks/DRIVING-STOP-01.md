# DRIVING-STOP-01 短驾驶课题：定点刹停

- 状态：done（功能与自动/渲染完成，人工趣味性待确认）；基线main/2b9ed1a，开始前工作区干净。原整批T2真实精度失败单独留证，不作为本玩法已通过。
- 前置：海岸工坊、分段与幽灵已有；让驾驶目标可在约半分钟内重试，不要求先跑完整圈。
- 方向：玩家驾驶当前同一辆工程车，观察入门速度与停车误差，再回实验台比较制动方案；不自动调参，不宣称驾驶成绩等于参考台架精度。

## 目标与范围

- 新增明确入口“驾驶课题 / 定点刹停”，使用现有直线高速与当前硬件、原Game输入/倒车规则。该课题明确为封闭无车流练习；普通自由驾驶/5公里挑战继续原车流。
- 从静止起步；距起点100m测速门须以至少80km/h前向通过。随后将车身中心停在距起点170m目标；显示到门/目标距离、入门速度、停车有符号误差和规则进度。
- 静止约1秒后结算；门前停车不直接失败但30秒总时限保持，过门后停稳即按真实误差评价。目标误差≤2m金、≤5m银、≤10m铜，超出失败；驶过180m、碰撞/复位、超时失败。倒车不补造测速门过门记录；保留原操作方式。
- 全程车身中心保持在三车道标记范围（横向±6.5m），避免绕出道路再从目标纵向坐标获奖；标线与规则使用同一范围常量。
- 门/目标区为纯显示标记，无刚体、阻挡或AI状态；权威Session在120Hz完成快照上判定，测速门用过线分数插值速度；暂停/失焦不计物理时间。
- 成功/失败均可一键重试、返回实验台或菜单；每次显示具体可行动反馈。成绩按当前完整硬件/输入规则版本隔离，保存最佳停车误差与奖牌；存储失败提示且可继续驾驶。
- 菜单入口、短规则、实景地面门线/目标区域、HUD和结算必须实际渲染检查。避免只做后台规则或隐藏入口即称功能完成。
- 保持Simulation唯一物理权威/120Hz、原车参数/相机/声音/碰撞规则；不为达标限制车速或改制动力。

## 实测依据与待定项

普通SDK当前Game硬件，seed17直线高速/明确0车流、先静止120拍；全油门后在100/120/140m切全刹，分别以87.24/92.91/98.15km/h开始制动，停在135.94/160.21/184.76m，总驾驶10.65/11.61/12.53秒，0碰撞。原始`logs/DRIVING-STOP-01-preflight/baseline.json`。这是规则可行性采样，不是性能计时或人工趣味性结论。

100m速度门+170m目标允许玩家选择中间制动点；实施前再使用真实Session固定步/键盘输入确认一组可得奖策略、早刹/迟刹失败，并在Double复测。静止速度阈值用现有停车约定0.15m/s，1秒真实保持，30秒练习上限；奖牌精度是新玩法目标，不能改变既有物理Gate。
