- 状态：completed（首批主流程；程序人工视觉体验待反馈）
- 基线：353260a7914558f226ca03661c372a9d0ea780e7，开始时工作区干净。
- 用户反馈：多页复杂、混乱、文字堆砌；先生成设计图，再制作。用户已选择清爽工具感，以试车/专家试验台设计为准，插画只作点缀。
- 采用单条施工线。RUNTIME-FIX-01 的偶发呈现等待仍独立开放，不用界面改造冒充解决。

## 范围与设计

- 本包覆盖项目入口、两道改装、结果、方案库、虚拟试车、专家试验台及驾驶辅助。主菜单、声音设置、配方及联动入口同步调整文案；其他已有图解页保留，不宣称全游戏每一页均已重排。
- 默认先展示目标、可操作选项、直观图解和一个主操作。完整条件、专业指标与导出保留在明确的展开入口。
- 新手用“原装 / 改装后”“开始对比”“上路试试”；专家保留 A/B 和全部真实数据。
- 图解承担信息：制动共起点等比例长度、路线用真实记录、选择页用明确标注的课题示意。未运行无收益；失败轨迹不外推。
- 字体使用现有资源，奶白底、海蓝线条、橙色主操作；无需新增运行时图片或替换真实车型。
- 设计图生成时的示例值、车辆、装饰不当作实际游戏截图。原装制动45%消耗0点，生成初图误标已在第二版纠正。

## 不变项

- Simulation、120Hz、配置与评分、存档/方案/旧实验/道路记录不变。
- 旧视觉冻结是历史阶段限制；本次用户明确授权跨页布局及文案改造。
- 允许修改 src/ui 的实际业务页面、lab_application 的界面路由/字号、lab_scene 的展示镜头、直接相关的 UI 测试/采集工具与本任务文档；禁止迁移 DS、归档或其他工作树。

- 相关短 T0；功能块完成后相关完整 UI 模块 T1 和三种子短启动。复用未改变的完整物理记录，不重跑无关边界或 T2/T3。

- 人工视觉验收：用户已选设计方向，最终程序实际体验仍待反馈。

## 实现

- 六页设计图与完整提示词在 docs/design/ui-clarity/。用户选择第三张清爽工具方向，并要求普通人类口气。最终使用“制动改装”“试验结果”“开始试验”“试驾方案二”等菜单名，去掉口号、反问和刻意的引导句。
- 工坊先显示车辆/路线示意、两项选择、预算与目标；完成后原位显示真实同起点长度比较。默认保留一个主要操作，专业规则、完整指标与曲线移入明确入口。弯道偏差只画误差条，不把它画成停车位置。
- 项目入口三幅课题示意，完成进度按三个项目显示；内部原五步状态保持。方案库显示两套方案与主指标，保存时才输入名称，详细表与曲线在展开层。试车保留真实轨迹、门位和失败终点，默认显示是否完成与有效时间。
- 说明、详情、命名逐层返回；命名取消和保存释放输入焦点，说明层覆盖底层操作。修正底部按钮重叠及原页面边缘露出旧按钮的问题。导出反馈保留在可见位置。
- 专家试验台缩短页头、区分主次操作，继续使用真实3D模型及原两图分析。复载实图发现镜头过近裁掉车轮，统一竖向视野并在窗口布局后重新取景；原生投影检查覆盖整车和四轮。仅展示镜头变化，无物理/游戏追车相机变化。
