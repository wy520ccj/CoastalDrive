# PHYS-DRIVE-03 有限限滑

- 状态：ready。前置为DRIVE-02三布局自动功能块完成；开发基线使用其实际收口提交，不把DRIVE-01未通过的音频/T2清零。
- 目标：开放差速之外增加有明确类型与单位的有限限滑机制，差速反力由同一轮-车身-曲轴末状态产生，真实热满足转矩×滑差。默认限滑关闭，保留默认后驱与现有完整轨迹。
- 先确定机械模型：前/后轴及四驱中差的滑差梯度包含本拍真实机械轮轴与壳体角速；不能只修改左右轮驱动矩而漏壳体反力。配置写明粘性耦合或摩擦片类型，容量/速差作用直接、有物理单位；不把有限容量误称锁死，不钳轮速。
- 实施入口：transmission_ports、tire_drivetrain、vehicle_tires及配置/观测。限滑、离合、齿轮效率、制动和轮胎需同末状态联立，接触导数须计入限滑响应，不能积分后另加矩。
- 验收：解析功/热、车身反力与角动量，关闭分支默认轨迹保持，单轮低附着/离地、split-μ、转向、反功流及倒车同输入A/B；两模式、玩家/NPC及reset/rebase。原残差/能量门槛保持，先相关短T0，再任务T1；功能组T2单独收口。
- 范围不含虚构传动轴惯量；真实输入轴/中间轴储能下一独立块接入，空挡轴速必须有实体状态与方程。SI悬架/防倾、估计器、实车型和整体Gate继续保持原目标。
- 当前：未实施、未验证。下一轮先定具体有限机制与共同约束，再修改源码；不预建管理器或通用传动框架。
