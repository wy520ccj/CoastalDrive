# 接触区回正力矩与指定转向的功

SIM-ALIGN-01在独立仿真树实现。参考RWD/FWD/AWD设计启用；游戏调校及未标定GR86保持原硬件。旧工程文件没有新开关时明确按关闭导入，已有记录不回算。参数来源仍是通用设计初值，尚无轮胎Mz台架数据。

## 企业会用它研究什么

轮胎侧向合力的作用点通常不在接触区中心。这会产生回正力矩，影响车身横摆，也形成转向系统需要承受的负荷。只用Fy与侧偏刚度，不能据此评估转向负荷。当前模型输出四轮Mz、接触区拖距及指定转向运动的输入功，可比较轮胎方案与操稳响应；齿条角度仍由执行器指定，因此这些结果不能当作自由方向盘响应、EPS标定或方向盘手感。

需要测量的新增量是接触区**纵向半长a（m）**，当前0.08m为待标定设计初值。它不是胎宽。已有Fn、纵横刚度与峰值力共同决定黏着区；不再添加一个任意车身回正增益。Fx/Fy六参数拟合不能辨识a：需要指定轮荷、胎压、温度、速度下的Fx/Fy/Mz台架数据，联合滑移留出也须包含Mz。

## 刷毛积分与模型边界

接触长度2a，前缘坐标s=0、后缘s=2a。均布压力给出局部摩擦上限D/(2a)，试探刷毛剪应力由前缘起线性增长：

\[
q(s)=\min\left(\frac{Q}{2a^2}s,\frac{D}{2a}\right),\qquad
Q=\sqrt{(C_\kappa\kappa)^2+(C_\alpha\tan\alpha)^2}.
\]

黏着比例z=min(1,D/(2Q))；Q=0取z=1。积分合力与对中心的一阶矩，得到有符号拖距：

\[
t=\operatorname{sgn}(v_x)\frac{a z(3-2z)}{3(2-z)}.
\]

小滑移全部黏着时t=a/3；滑动区扩大时趋近零。倒车切换前后缘，拖距翻号；低速小于既有static_contact_speed或上一子步无实际轮荷时取零，不模拟停车扭转。这里采用均布压力刷毛的等效受力中心，实际合力仍由已有联合滑移曲线决定，属于明确的混合近似，不能称为完整Fiala模型或Magic Formula力矩模型。均布压力、无残余力矩、无外倾力矩及固定a是当前边界。

上一机械子步的实际轮荷、接触区滑移与完成步纵速决定本子步冻结拖距，当前路面μ已知；悬架候选接点只提供坐标，其轮荷为零，不能拿它计算拖距。新落地允许一个子步的建立过程。这个时序用步细化验证，未在迭代后追加独立姿态修正。

## 同一接触的速度、力矩和能量

令原接触中心p、胎面纵向单位向量e_x、横向e_y、法向n，e_x×e_y=−n。切向合力实际施加于p*=p−t e_x，因此Mz=t Fy。纵向力的力矩不因沿其自身方向移动而改变；横向力的广义力矩改为p*×e_y，车身惯量响应和轮胎隐式速度使用同一协向量。法向支撑点、轮轴滚动半径、碰撞及悬架几何不移动。

指定转向的附加横向速度为v_y,steer=(Ω_steer×(−t e_x))·e_y，进入同一接触滑移和弹性变形方程。理想执行器输入功为−h Fy v_y,steer；它可以为正或负，不能当成非负耗散。完整核对包含车身/曲轴/输入轴/输出驱动轴/四轮动能、轮胎/悬架弹性、制动/离合/传动/滚阻/材料/路面及离散积分耗散。

`aligning_angular_impulse`是现有`lateral_angular_impulse`中由拖距带来的部分，不能再次加到总角动量。Mz及t属于末机械子步，contact_steering_work是完整120Hz拍累加。完成步采样侧偏仍在接触中心，force_patch_alpha属于实际施力本构，两者不要混用。

## 实际验证与意义

同一1200kg参考车、60km/h、3°阶跃、t0=0.5s、3s试验；A/B唯一配置差异为开关。关闭/开启横摆峰值0.377226/0.361163rad/s；开启单轮力矩峰值56.2705N·m，接触转向输入总功2.22469J。a减至0.04m时峰值28.3486N·m、输入功1.10753J；车辆运动随真实接触力矩改变。

两/四/八机械子步末横摆率为−0.35423133/−0.35434026/−0.35437232rad/s。相对八子步误差由1.40995e−4降至3.20673e−5rad/s，五次完整试验均无碰撞、施力分量残差小于0.001N。各版本按自己的步长完成初始化；这是完整试验流程的细化证据，不代表所有工况的全局收敛认证。

独立数值刷毛积分、正反转向/前后行驶的能量闭合通过；实际世界取出的同一子步，Python/原生末速度1e−12、轮胎力/变形1e−7一致并通过完整机械能量/角动量核对。旧标定A/B完整396/393帧原字段可验证读回，新机制取零且原文件未改。T1 414项/Ruff/三种子1200拍和720/1080实际GUI通过，详见[证据](evidence/SIM-ALIGN-01/README.md)。这些是机制与数值证据，不证明实车准确度。
