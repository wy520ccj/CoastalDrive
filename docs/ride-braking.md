# 颠簸制动：轮端质量、接地与ABS

工作台新增“单侧凸起 / 制动”。默认30km/h滑行，0.6s后请求全制动；方向保持0°，空挡/离合零，真实10mm×0.9m×0.48m左侧Box位于起点前6m。压力仍按液压时间常数和ABS轮速反馈演化，凸起不通过改轮速、轮荷或车身位置伪造。需显式导入独立轮心工程模型。

## 参数为什么重要

簧下平动质量进入完整车身/四轮心质量阵。相同弹簧、径向材料和道路输入下，它改变轮心跟随道路的运动、轮胎压缩与轮荷。附着预算使用该次共同解的实际轮荷，轮速反馈又改变ABS压力；因此质量变化可传递到制动力，而不是给结果乘经验系数。

```mermaid
flowchart LR
  M[簧下质量与完整质量阵] --> Z[轮心运动与径向压缩]
  Z --> N[实际轮荷与附着预算]
  N --> F[轮胎力与轮速]
  F --> B[滑移反馈与ABS压力]
  B --> F
```

当前设计参考车总质量1200kg固定；25→65kg每轮是质量分配假设，簧上质量、CG/惯量分解和静态行程随之改变，不能解释为真实车型更换轮毂后的实测效果。轮胎参数、液压、ABS、附着及输入协议保持。企业标定需要真实轮端质量、径向加载曲线、阻尼、轮胎轮荷敏感性与制动执行器响应；本节点检验它们的计算链和可复现性。

## 正确的制动基准

停车距离从首次非零制动请求前的样本开始，以整车质量加权CG的水平路径累加，终止条件为CG水平速度≤0.1m/s。MFDD也以同一样本的实际速度为基准，排除接近凸起的滑行段，再插值80%→10%速度区间：

$$d_m=\frac{v_b^2-v_e^2}{2(s_e-s_b)},\qquad v_b=0.8v_0,\quad v_e=0.1v_0.$$

采用m/s和m。未到区间、区间内增速或异常终止时保留无效原因，不把凸起研究工况当作平路制动合格试验。该基准与[Racelogic的触发速度说明](https://racelogic.support/knowledge-bases/general-kb/mfdd/)一致；完整车辆/控制器/环境协同试验也可参考[MathWorks制动参考应用](https://www.mathworks.com/help/vdynblks/ug/braking-test.html)。工作台的默认参数和停止阈值不宣称法规标定。

## 有证明的Box剖面接触

最初25kg实际运行在离开凸起的轮端查询失败，一般GJK/EPA结果支持间隙0.836775m未闭合。严格检查拒绝了这个值；没有把它当轮荷继续运行。固定真实输入现在可以单步复现，不必每次重跑整车。

对于零margin Box，若整个轮胎在一个Box轴向区间内，接触可在垂直该轴的二维剖面求解。分离状态用支持平面/见证点证明最小距离；穿透状态还要求轴向净余量大于待求穿透深度，保证更短的三维平移不会通过该轴脱离Box，因此二维最小分离距离也是三维结果。

二维中分别核对四个面和四个角的法线锥。角点支持距离为 $d(\theta)=\mathbf n(\theta)\cdot(\mathbf c-\mathbf e)-H(\theta)$，其中H取原轮胎胎冠支持函数。方向导数上界B1、二阶导数绝对上界B2由半径、胎宽、肩部和胎冠推导，不是新增调参。驻点满足 $|\mathbf n'\cdot(\mathbf c-\mathbf e)|\le B_1$，因而

$$|\mathbf n\cdot(\mathbf c-\mathbf e)|\ge\sqrt{\|\mathbf c-\mathbf e\|^2-B_1^2}.$$

结合该法线锥的符号范围，可证明全部驻点为严格极大或极小；极大时用52次二分，极小时最大值在端点。无法分类时使用整个锥的支持上界，不能把局部根冒充全局距离。候选必须满足真实见证点、有限边界和所有法线锥上界才能通过。未证明的构型仍走一般凸体算法，其严格错误检查保持。远处Box按轮胎真实支持范围形成AABB下界，只有下界已超出原查询范围才剔除。

同一失败子步修正后4迭代通过，动量约1.42e−13Ns、轮胎力残差1.76e−9N，旧求解门槛保持。独立圆/Box解析距离、全空间支持方向采样与两份实际失败夹具通过。一般凸体查询在该原始输入上仍会报错，本节点没有宣称所有凸体数值问题已解决。
