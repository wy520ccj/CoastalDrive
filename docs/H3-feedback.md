# H3 试玩反馈修正：0.4.1

## 本轮行为

- 允许逆行、倒车调整姿态，不因此取消比赛或使圈速无效。进度仍按净里程累计，已通过的检查点不会重复计数；必须顺序通过全部检查点并回到终点。

复位、越界、异常跳跃和漏检查点判定没有取消。车辆动力学参数本轮不变。
