# 玩法试玩

双击[试玩入口](../launchers/challenge-play.cmd)，进入“无限高速 → 短途赛事 → 平路连弯”。这个入口保留当前本机画面，使用独立存档，所有试玩记录留在项目B盘目录，不改原有进度。

本机试玩入口已启用赛道路面接缝修正。旧存档保留，计时和油耗纪录按运行时版本分组，当前组从新版完赛开始比较。

熟悉路线后，可以用这两套预算内方案比较圈速和油耗：

| 方案 | 操作 | 本场费用 |
| --- | --- | ---: |
| 原车 | 恢复原车 | 0 |
| A 前轮响应 | 恢复原车；“轮胎与底盘”中前轴侧偏刚度设为65 kN/rad | 2000 |
| B 轻量低阻 | 恢复原车；“动力与阻力”中质量设为1152 kg、风阻面积设为0.6514 m² | 4780 |

其它参数保持原车。“重试本场”会沿用当前配置。有效完赛会保存对照，碰撞或复位会结束本次。

同一自动驾驶节奏下，A 用时92.150秒，B 用时93.770秒。B 的油耗为18.946 L/100km，比 A 少0.490 L/100km。两套方案均两次达到金牌线，原车也有一次达标。

平路连弯金牌要求同一次完赛用时不超过95.6秒、赛段油耗不超过20.1 L/100km，预算5000。正式奖牌线来自自动驾驶实跑，玩家有效完赛后保存自己的成绩。生涯奖牌会推进星级，海岸巡回每站至少达到铜牌。

试玩存档位置：`logs/challenge-player/CoastalDrive/`；逐拍记录位于其中`challenge-runs/`。启动器只使用正常键盘驾驶，不加载自动驾驶或改写计量结果。

## 山脊冲刺

从同一入口进入“无限高速 → 短途赛事 → 山脊冲刺”。新版在530—770米加入三组连续起伏，出缓弯后留意下坡急弯。先跑原车，再用相近的节奏比较轮胎与弹簧。本机新版的金牌要求是75.0秒和24.4 L/100km。

| 方案 | 设定 | 本场费用 |
| --- | --- | ---: |
| 原车 | 恢复原车 | 0 |
| 前胎与免费调校 | 前轴侧偏刚度65 kN/rad，前制动份额65%，前防倾份额40% | 2000 |
| 软弹簧 | 沿用上一方案，弹簧刚度改为36 kN/m | 3500 |

## 五公里无碰撞挑战

从“无限高速”选道路和车流，再进入“五公里挑战”。六种路况各有自己的奖牌要求和完赛对照，赛前方案页会显示本场要求。驾驶中如果用时或油量已超出一档，仪表会提示下一档仍可争取的目标。

## 滨海计时幽灵

在主菜单进入“滨海计时”，预算内有效完赛并刷新个人最快后，下次发车会出现这一圈的幽灵。更换方案也能跟跑同一条参考线，按 G 开关显示。
