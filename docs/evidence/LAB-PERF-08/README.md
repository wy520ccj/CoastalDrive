# 试验台四轮材料与有限端口残差批量组装

2026-10-15，基线`dff1955`。本块把共同残差的四轮材料调用及离合/传动/制动/差速投影移至严格浮点C批量入口，保留原物理方程和数值精度。持续优化目标active。

## 实现与保真

`unsprung_contact_residual`读取本次实际速度、四轮力/变形/接触速度和材料参数，直接调用原`tire_contact_values`及原Python `math.hypot`。四个轮胎的目标力、弹性/速率/滑移、模式及原列表/元组类型保持；不换近似轮胎公式或范数。

`unsprung_port_residual`保留原轴转矩/TBR容量及全部离合、同步/空挡/正负传动比、四轮制动和三差速投影分支，按原顺序写入残差。标量与数组clip的零符号语义分别保留。固定配置在本次共同解准备，没有跨状态近似。

原NumPy矩阵运算、动量/陀螺、真实几何、120Hz、两子步、34变量、差分epsilon、Newton/线搜索/收敛及能量账保持。共同解从config_rear之后的全部求解/结果/能量账尾部全文相同。mechanical_kernels.c去掉新增include/两行注册后与基线全文相同；原材料C函数没有改写。只重编机械扩展，四个其他扩展/共享.venv/隔离Double SDK及游戏源码保持。

## 数值验证

新增40项：12个量级/时间步节点各100组，共1200批/4800轮材料对照，覆盖滚动、粘着、滑动、零载与非连续数组；18个传动比/同步/驱动分配节点各100组，共1800组有限端口对照，覆盖TBR、容量边界及正负零；另有8项数组数量/形状/类型/只读错误边界和2项实际hypot回调/异常边界。材料完整细节列表、未写残差区及所有位模式均按原正式公式核对。

最终Double/普通SDK相关T0各124项，Double试验台32模块348项完整回归48.06s/Ruff通过，包含实际记录导出/加载/完整复算、原失败子步及新增测试。按用户范围未运行游戏seed/window；通用T1/T2/T3、人工体验、实时、原完整精度与EPA边缘拒绝Gate继续开放。
