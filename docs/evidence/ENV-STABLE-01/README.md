## 无限道路越界种植

新林片少量候选越出原无限道路8.5–120m条带，原ground_point以next查找区间，找不到时StopIteration令分段生成失败。实际独立重现日志r01-infinite-setup-failure保留。floor_point现按真实TERRAIN_COLUMNS判定，无地面则返回无种植表面；外侧山体仍用自己的采样，有限生涯地形未改。

相关四项原GPU/加载检查+新增边界检查、Ruff/三种子恢复通过，[报告](floor-recovery-validation.json)。视觉块T1-r2的36个有效通过结果明确复用；不称同次41项全绿。第一次新增测试误写HighwayCurve构造器的位置参数，已按真实hills=True接口修正，原失败保留。

## 车体显示快照不足

正常默认/Draw、独立120Hz山脊270m采集权威原始车身、显示姿态、相机和插值区间，未改物理或加姿态阻尼。r03的456显示帧中402帧目标显示时刻超过最新已领取快照，超出中位21.30ms/P9542.34ms/最大60.12ms。旧逻辑发出本帧frame请求后，等下一个绘制帧才领取；低帧率下原33.33ms插值缓冲反复不足，显示停在旧完成步再跳进。

SessionProcess.frame改为领取本次完成步回包后，再按同一个采样时刻与原33.33ms延迟插值。只改交接，不推进第二套物理，不外推、不改驾驶参数/悬架/相机参数、不丢模拟时间。r04同条件独立复测483帧，快照不足0；观察窗权威丢时0。显示中位45.85→44.84ms是分时段观测，不把约1ms差宣称性能收益。[完整前后摘要](handoff-comparison.json)。这证明修掉该停留来源，不等于所有物理俯仰和用户感知摇晃均已验收。

新增确定性回归：50ms显示间隔时，必须先领取新完成步，再显示原延迟的连续位置；旧交接会停在20m，新交接正确显示21m。T0通过；进程/时钟/相机/快照线格式等20项在[相关T1首轮](continuity-T1-partial.json)有效通过，草GPU项失败另列，不能称首轮整批全绿。

## 草的距离过渡

旧草shader把距离权重乘进整株随机存在阈值，140–190m随接近逐株增加密度。现保留固定世界株位、品系与高度，只以原4x MSAA覆盖率在140–215m平滑过渡，并在220m草格卸载前归零。近景高度/覆盖、地表贴合、原图集与候选数保持。新旧距离模式仅供独立诊断对照，不是玩家新增设置。

[实际GPU检查](grass-distance-gpu.json)：100m新旧像素完全相同，正交固定尺度下100–210m草格屏幕包围盒完全相同；新覆盖随距离单调退出，220m归零。并非缩短视距、缩矮远草或移动草根。首次诊断要求移动正交相机后整屏RGB完全相同，185m后交叠叶片深度精度产生少量内部像素差；原失败保留，最终明确以固定尺度包围盒检查高度，全部内部像素差原样登记，不冒称整帧字节恒等。

完整场景早退对照先出现3处叶面像素差；固定全场排序仍有1级重复差。没有放宽0差门槛或把它们记成0：完整场景差异全部保留，另隔离原镜头的完整真实草层，[严格开/关/重复像素比较](grass-layer-gpu.json)均0。诊断的固定排序/其他物体隔离未接入产品；不以这个草层检查宣称全场无闪烁。完整相交叶面的微小差异和连续驾驶仍须继续检查。

[恢复T1](grass-recovery-T1.json)的两项真实GPU检查、Ruff/三种子通过；其他20项复用前一批有效通过。没有重跑无关全套或虚构同次22项全绿。

当前入口美术另完成沿海450m连续取景：4505个已记录权威字段与上一轮沿海基线完全相同，六镜位/视场角相同，0碰撞。真实渲染视频568幅/15fps，只用于观看草与景物的连续性，编码时墙钟不能代表实时帧率。[字段核对](coast-video-validation.json)；[实际视频](../../../logs/environment-stability-20261026/r09-grass-smoothed-coast-video/driving-view.mp4)。已检查连续帧及原尺寸190m实图，近景草高保持，仍需用户在正常入口体验。第一次视频取帧的ffmpeg滤镜逗号转义错误，无输出；改用起始时间取帧后完成，不影响原视频或行驶记录。
