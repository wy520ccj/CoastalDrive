## 同进程诊断方法

从当前真实100km/h制动实验保存48个内部可信检查点，原解的每个数值字段、数组dtype/shape/原始字节和Python浮点位模式留作基准。冻结重放须先与原实际解逐项匹配；48个基准又与独立完整制动进程的共同解逐项匹配。

在单独子进程内同时加载明确路径/SHA的旧、新wheel扩展，只临时切换110处Python可见函数引用，记录所有模块/属性/原生函数名。两种各预热一批，再按ABBABAAB正式测八批。两个LAB-PERF-10新增Box入口均以诊断断言禁止调用，实际调用0，确认这批平面制动没有执行新增路径。引用在finally中恢复，生产文件保持不变。

最终测量为8×48=384次冻结解，另有2批预热；每次均匹配原解。初探和最终记录分目录保存，前者原工具字节单独归档；后者补齐绑定清单、输入文件SHA和完整实际配置。每批数值摘要/序列化在计时后。

冻结输入经可信检查点序列化，数组存储布局可能重建；该诊断不含世界读写、快照和UI，不能代替完整物理步性能证据。它用于核查旧/新原生函数在同一负载、同一进程下是否表现出稳定差异。
