# 有限胎宽与胎冠增量

基线0aae48d，2026-10-05。本增量沿用户批准的物理完成施工线实施，尚未关闭整体目标。

## 机制

- 实际驾驶从半径0.33m球体改为有限胎宽圆角圆柱。通用设计胎宽0.205m、肩部圆角0.01m、胎冠落差0.003m；都不是实车测量数据。
- 胎面内核沿轮轴截面为 `r(x)=R-s-c*(x/(w/2-s))²`，再加半径s的圆角。实际外径和宽度保持R、w。支持函数解析最大化该截面；平直胎面c=0保留为明确几何台架参数。
- Box面解析求交，棱角使用圆柱/Box凸体距离与保守推进；Box margin只计算一次。Plane解析，原生网格使用17截面×64圆周点内接凸包加肩部margin，最大径向离散偏差约0.39mm。扫掠形状按车辆硬件构造一次，不添加查询刚体到世界。
- 平面末姿态使用胎冠支持高度的稳定差商与有限转动平均向量，曲面使用真实末交点与离散梯度；实际行程和六维机械功同源。轮胎有效滚动半径同步采用同一截面。
- 原球形查询保留为已有几何台架接口，实际驾驶不走该入口。旧关闭耦合分支保持原轮胎几何。
