# PHYS-SUSP-01：法向、轮胎与传动共同末状态

2026-10-05，基线`cd005b7`。两种正式模式已把SI弹簧、轴向阻尼、防倾和止挡接入现有轮胎/曲轴/输入轴/下游轴共同求解；硬件、摩擦、控制增益及实际刚体碰撞不变。显式关闭有限传动仍是历史机械对照，独立法向试验入口保留。

## 实现

同一Bullet世界只在当拍读取一次接点。`SuspensionInput`保存材料初值、几何压缩、六维接触雅可比及硬件，纯机械求解不持有世界或车身。每个原有轮胎子步共同解法向力、纵横接触力、制动、离合及转子末速度：

`x_end = geometry − dt*A*(v_end, Ω_end)`，`Q = ∇U(x_end) + c*(x_end−x_old)/dt`。

单边接触及离地释放仍由原活动集处理。法向扭矩进入同一完整转子惯量/传动约束和陀螺输运方程，切向抓地与刚度使用当前未知轮荷；法向块的裸车身mobility只作隐式预条件，最终按共同末速度检查硬件反力。法向残差要求`<1e−8 N`，原轮胎`0.001 N`和制动`1e−9 Nm`门槛保持，超过原20轮迭代直接报错。收敛后才向唯一车身提交各项实际冲量，未设置运行速度或另建刚体世界。

子步之间用全部六维共同末速度推进约束坐标。Snapshot保留最后施力子步的力/速率，功和损耗累加全拍，`substeps`保存真实dt及原始机械结果。新`body_work`是法向力在共同末速度上的功；车身离散耗散属于完整机械系统，不再给法向独占重复计账。原有朝上且不陡于60°的轮胎路面资格继续传递，法向支撑不会把非路面接点变成切向抓地。
