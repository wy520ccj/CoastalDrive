# PHYS-SUSP-01：有限轮半径连续支撑包络

2026-10-05，基线`d0f64dd`。正常游戏/困难仿真均接入有限轮半径，弹簧、阻尼、防倾、轮胎、输入和电子增益保持。当前是设计参考车的球形支撑包络，半径直接取已有0.33m轮半径；有限胎宽/实际轮胎外形仍待实车型数据，不宣称新增簧下刚体。

轮心满足`c=h+d*l`，接点为`p=c−R*n`，实际行程压缩`x=rest−l`。Box内核及margin直接从同一Bullet世界的现有形状读取，求`Box内核⊕球(R+margin)`的入射交点：沿路径按三轴内核面分区，各段解真实距离平方的二次式，因此面、圆柱棱和球角连续；没有把Box简单扩大成另一个尖角大盒。Plane按法向距离R求交，网格采用同世界原生球形凸体扫掠。表面查询使用既有bit 0，车身碰撞bit 1及刚体碰撞保持。

路径从轮毂沿悬架上退R，保留原查询压缩行程覆盖范围。每个法向冲量仍是`Q/a`，`a=−n·d`，使用真实接点力臂及六维雅可比`(n,r×n)/a`；轮胎和快照读取同拍唯一轮荷。独立有限轮半径虚功检查通过。参考表明确记录`finite-radius-sphere-envelope`，schema为reference-v19、游戏成绩为game-controls-v16，车辆参数仍91字段。

依据：[Panda3D同世界凸体扫掠](https://github.com/panda3d/panda3d/blob/v1.10.16/panda/src/bullet/bulletWorld.cxx)、[Bullet球体半径/margin](https://github.com/bulletphysics/bullet3/blob/2.84/src/BulletCollision/CollisionShapes/btSphereShape.h)、[Box内核与margin](https://github.com/bulletphysics/bullet3/blob/2.84/src/BulletCollision/CollisionShapes/btBoxShape.h)、[凸体连续碰撞实现](https://github.com/bulletphysics/bullet3/blob/2.84/src/BulletCollision/NarrowPhaseCollision/btContinuousConvexCollision.cpp)。这些解释接口和形状语义，本机轨迹证明实际结果。

- 原单侧工况两模式各360拍，307源运行前后相同，逐拍完整新轨迹保存。当前接点距实际Box内核+margin表面误差≤1.87e−8m；0.001N轮胎残差和1e−7J局部机械残差门槛保持。之后只改诊断读取/记录和操稳结果复用，生产与测试源不变。
