# 动力、悬架升级与真实驾驶对照

接续基线`fcad47e0`，单线本地。先查阅[Forza升级/试车流程](https://forza.net/news/forza-horizon-5-upgrade-heroes)，沿用已冻结车库布局，用原01图及有来源的零件抠图生成09动力、10悬架设计，再实施真实控件。没有增加车型或更改十套原车配置。

## 实现和成长

| 零件 | 解锁 / 价格 | 只在明确安装后生效 |
|---|---|---|
| 街道动力套件 | 8星 / 450积分 | 原扭矩曲线每个转速点的扭矩×1.12，转速节点、挡位、质量、抓地与辅助不变 |
| 运动悬架 | 12星 / 400积分 | 四轮弹簧×1.15，压缩/伸张阻尼×√1.15；已有非线性阻尼表同步缩放力列，安装几何/预载/重心/行程不变 |

- 界面同一2×2分类和详情位；动力显示真实当前→候选峰值kW，悬架显示平均轮心等效刚度kN/m，安装后只显示当前值。分类可浏览，锁定/积分不足/已安装有对应主按钮状态；不是只启用按钮或加虚假性能条。
- 两件共850积分，全18星奖励2460，四件全部购买后剩1010；老存档版本1与前胎/制动配方保持。拥有零件后其他车也可免费安装，逐车配置独立保存。
- `career_tuning.py`保存安装标记，同一车重复安装不再次乘增益；前胎/制动安装保留标记。与原完整副本链同一次保存，原车报告、方案与成绩关联只留在不可变副本，恢复逐步回到完整原件。失败购买不扣钱；已购买但车辆写入失败仍拥有，重试不重复收费。
- 多项奖励按真实文本高度留位：四车时车行64px，零件行46px；赛事名合入解锁标题，避免压盖。顺带补上“只解锁赛事而无车/零件”时原先漏显示名称的问题。最后去掉冗余“· 零件”尾缀，消除窄屏孤行，不减少真实奖励名称。

## 实际驾驶

`tools/career_upgrade_check.py --output logs/validation/GARAGE-DESIGN-02-upgrades-driving`。真实Session/唯一Simulation、120Hz、静止起步与正常二值键盘；动力均全油门，悬架严格重放原车绕桩按键序列。逐拍独立CareerRun复核。不是改判定门槛或移动终点。

| 项目 | 原车 | 安装后 | 实际结果 |
|---|---:|---:|---|
| BRZ / 400米 | 17.183秒 | 16.475秒 | 均三星/0碰撞 |
| i20 / 400米 | 18.717秒 | 17.925秒 | 均三星/0碰撞 |
| BRZ / 绕桩侧倾峰值 | 0.43355° | 0.39713° | 下降8.40%；均35.058秒/三星/0碰撞 |
| i20 / 绕桩侧倾峰值 | 0.64282° | 0.59685° | 下降7.15%；均35.558秒/三星/0碰撞 |

八次共25384新驾驶拍。侧倾窗口为80米后且车速>8m/s，完整轨迹保留，未从短测推断所有路面/车型都会更快或乘坐更舒适。

`tools/career_upgrade_ui_check.py --output logs/validation/GARAGE-DESIGN-02-upgrades-flow`：实际应用四类购件→混装→换车复载→重复安装→升级车完成400米→结算→四步恢复→返回原赛事。18星初始进度为隔离UI夹具；真正升级车另1977新驾驶拍、16.475秒三星，已有成绩不再发奖。17图截图不推进物理，窗口/显示缓冲不累积；原玩家存档不读写。合计27361新驾驶拍，启动沉降与倒计时不冒充驾驶样本。
