# 旋转轮轴与接触共同末状态准备

2026-10-03接手期间，生产266个Python文件继续冻结，当前T2不受本诊断影响。这里的程序和数据仅位于证据目录，不是已经接入的驾驶机制。

## 同末状态轴承反力

轮的现有正转标量为ω，真实转子角动量为`S = −Σ Jw ωi ei`，ei是机械轴向。壳体随车身角速度Ω旋转时，转子轴向输运项为`Ω × S`，车身轴承反力为`S × Ω`。固定瞬时惯量与轴向，使用末轮速/末车身角速解`(I − h[S_end]×) Ωend = I Ωfree`，与四轮轮胎/制动同一次迭代完成，不在提交轮胎结果之后补一个陀螺冲量。

[共同末状态原型](rotor-coupled-prototype.py)沿用生产接触方程、0.001N全局残差、0.0001N局部残差、制动等效1e−9N和20次迭代上限。5种工况（无外力旋转、加速、倒车制动、非均匀支撑、静止制动）×2步长×开关，共20组，[最终原始数据](rotor-coupled-prototype-v3/summary.json)全部通过。能量核对保留原3e−9J门槛，最大误差约5.64e−11J；反力与末Ω正交，因此不增加陀螺项的功。无反力负对照的输运方程缺口逐项等于`h Ωend × S_end`，开反力时逐项小于1e−10Nms。迭代数1～6；没有改方程容差或失败处理。

此处只核对固定瞬时轴向的Euler输运平衡。真实Bullet一步之后轴向及世界惯量会旋转，尚不能据此声称有限旋转的世界角动量严格守恒；先前原生世界反力原型的时间离散误差仍需生产联合验证。[第二次运行的夹具失败](rotor-coupled-prototype-v2/failure.json)保留：使用不随h缩放的0.1Nms负对照下限导致1/960秒工况误报，已改为直接核对该缺项的完整向量恒等式。首轮、失败轮和最终轮各自保存源码快照及数据。

同末状态实现补充世界非对角惯量后，[实际Bullet无外力12条轨迹](rotor-joint-native-probe/summary.json)将轮胎与轴承反力作为一次联合结果提交冲量，不重设末速度/姿态。60rad/s、yaw=.2rad/s、1秒的120Hz总世界角动量变化由86.256139降至0.0888755Nms；240/480/960Hz分别为0.0443386/0.0223502/0.0129094Nms，能量变化分别−0.0630290/−0.0314036/−0.0158065/−0.00880049J。结果与先前独立轴承冲量诊断一致，因为这组没有接触/驱动/制动；不能据此推断一般道路联合轨迹也等价。零轮速原生对照误差仍保留，266生产/测试/工具文件SHA前后相同。此组证明联合提交在真实积分下能够作用，同时明确保留有限旋转和原生单精度误差。

## 接触横向方向与机械轴分开

现有接触axle由投影车头方向与路面normal构造；外观轮轴和后驱转速接口则随车身机械方向。它们在平路无外倾时一致，但一般倾斜路面并不一致。新增陀螺项必须使用真实机械ei，不能把路面切向坐标直接当转子轴。

保持现有射线支撑偏移`d = point − hub = −r n`。机械轴e、路面normal n定义接触纵向`t = normalize(n × e)`和横向`l = t × n`。纵向有效力臂为`ρ = e · (d × t) = r sqrt(1 − (e · n)^2)`；车轮相对壳体的旋转速度为`−ω − Ω·e`。于是实际接触点速度投影满足：

```
v_surface,t = vx − ρ ω
vx = V·t + Ω·(point × t − ρ e)
vy = V·l + Ω·(point × l)
Jw Δω/h = drive − brake − ρ Fx
τ_body = point × (Fx t + Fy l) + (drive − brake − ρ Fx) e
```

这组式子给出独立虚功恒等式：`V·F + Ω·τ_body + ω Jw Δω/h = F·v_surface + (drive−brake)(ω+Ω·e)`。同时总角动量的轴向作用/反作用抵消，只留下外部接触点力矩；不要求机械轴恰好位于接触平面内。

[45组独立几何与虚功核对](mechanical-axis-power-probe/summary.json)覆盖±20°/±5°/0°横坡、±30°/0°转向和±60/0rad/s轮速，最大功恒等式误差1.1824e−11W。旧接触横轴与机械轴对应的自旋向量差最大37.508Nms，这是该夹具几何下的差异，不能直接称作实际驾驶1秒动量漂移。此处保留球状射线支撑偏移，没有改变Bullet轮心位置，也不声称已经实现薄圆盘轮胎与路面几何求交。

随后将上述机械轴与各轮有效力臂直接纳入同末状态原型，[54组倾斜接触联合台架](rotor-bank-joint-probe/summary.json)覆盖−20°/0°/+20°横坡、−30°/0°/+30°转向、正向加速/倒车制动/静止制动、1/240与1/960秒子步。最大力残差0.000972976935N、最大能量误差6.0077e−11J，全部保留原0.001N及3e−9J门槛；最多6次迭代。原平面20组也在[扩展后的源码快照](rotor-coupled-prototype-v5/summary.json)重新通过。该倾斜台架接触位置与normal是显式机械夹具输入，未创建真实坡面或宣称道路驾驶通过；转向角在子步内固定，其执行器功仍待生产接入。

## 下一块生产要求

1. 机械轴、接触纵横方向和纵向力臂在明确接口分开；轮速、干式制动、转子动量和相对壳体功使用同一机械轴。观测、驱动轴反馈与施力坐标一致。
2. 轴承反力进入同末状态求解，并保存实际冲量及功；不开负载无关角阻尼替代。转向导致的额外轴向变化必须记录执行器功，不能归入零功车身陀螺项。
3. 实际无外力世界、时间细分、平路/斜坡/转向/制动/离地/再接触与生命周期，保留完整轨迹。原生刚体陀螺项仍由Bullet处理，避免重复计算车身自己的项。
4. 这些生产证据通过后，再接独立发动机惯量、有限离合和开放差速器；固定轴向台架与本原型都不替代动力总成完整驾驶验收。

理论背景见[MIT三维刚体及陀螺课程](https://ocw.mit.edu/courses/16-07-dynamics-fall-2009/resources/mit16_07f09_lec30/)，原生自身惯量的处理见[Bullet2.84刚体源码](https://raw.githubusercontent.com/bulletphysics/bullet3/2.84/src/BulletDynamics/Dynamics/btRigidBody.cpp)。以上离散方程与虚功恒等式为本项目推导，数值结论来自上述夹具，不由外部资料代替。
