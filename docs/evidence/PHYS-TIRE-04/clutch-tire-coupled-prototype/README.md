# 离合与生产轮胎共同末状态台架

本台架调用冻结的生产`advance_coupled`，四轮Fx/Fy、干式制动、胎体变形和车体末速度保持原方程与原门槛。新增独立发动机惯量、有限离合、带符号理想齿比及开放差速器；先证明固定轴向的一步耦合，不作为实际驾驶或换挡完成证据。

[二分参考脚本](../clutch-tire-coupled-prototype.py)与[完整结果](summary.json)包含加速、回拖、倒挡、制动、静止起步、全离地、不等支撑和离合分离，分别取1/240及1/960s，共16步。每次试算Tc同时计算发动机末转速与对车体的反力，调用生产四轮求解，再以共同末壳体速度计算`δ=ωe−Ω·ae−R(uL+uR)/2`。容量外保留正/反滑差；容量内求δ=0，残差门槛1e−11rad/s。所有16步均通过原3e−9J能量、0.001N轮胎力残差、制动非负功及共同车体末轴速检查。

总功账同时包含发动机与四轮动能、车体动能、胎体储能、材料/路面耗散、干式制动功、离合功、后向积分损失及曲轴相对壳体的燃烧功。二分参考最大能量账误差1.4195e−11J，角动量账误差1.2213e−14N·m·s。转矩没有先外算后覆盖轮速或RPM。

二分参考的锁止步需要37–45次生产四轮求解。独立[Brent脚本](../clutch-tire-coupled-brent.py)与[结果](../clutch-tire-coupled-brent/summary.json)保持同一物理方程、初值、容量及所有验收门槛；16步合计调用由272降至52（减少80.88%），锁止步3–7次。[逐项对照](../clutch-tire-root-comparison.json)显示最大轮胎力差2.34e−10N、轮速差6.72e−13rad/s、转矩差1.67e−10N·m，两组源码前后稳定。这里只统计调用，不据此声称实际FPS。算法使用插值与有界二分求同一离合残差，未更换力模型；没有引入SciPy运行依赖。[SciPy原始文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.brentq.html)说明该根算法的插值/区间组合及连续变号函数前提；当前接触系统仍须在完整轨迹中验证事件切换与收敛。

两种h是同初值下不同持续时间的一步试验，不把其末状态差异或锁止/滑差差异当作整段步长收敛证明。离合容量为0的记录仍按末滑差符号分类，实际转矩严格为0，属于分离状态。参数均为设计值，发动机轴取壳体前轴，Je=.2kg·m²，理想齿轮效率为1。

这些固定轴向证明尚未包含转子轴向随车身/转向变化的陀螺反力；[真实生产轴向输运审计](../rotor-transport-audit/summary.json)已发现该缺口。生产接入须补齐轴向输运、共末状态及执行器/换挡，再做标准车辆A/B和完整T1/T2。
