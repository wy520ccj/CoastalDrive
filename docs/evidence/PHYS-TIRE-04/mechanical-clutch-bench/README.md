# 发动机/离合台架预研

这是下一传动功能的固定轴向机械推导与独立实验，尚未接入车辆生产模型。脚本为[mechanical-clutch-bench.py](../mechanical-clutch-bench.py)，结果为[summary.json](summary.json)。所有惯量、转矩和容量均是合成设计值。台架不含轮胎、制动、齿轮损失、换挡控制或轴方向随姿态变化的陀螺项。

取车体角速度Ω、发动机绝对转速ωe与两输出轮绝对转速ωL/ωR组成q。三个转子正转轴为ae/aL/aR；当前车辆向前转动轮的正轴是车体右轴的反向，因此其壳体相对转速为`ωi−Ω·ai`，即现有`state.omega+body_omega`。定义带符号总齿比R，开放差速器的输入速度为两个输出相对速度的均值乘R。

设`b=ae−R(aL+aR)/2`，则离合滑差为`δ=ωe−R(ωL+ωR)/2−Ω·b=c·q`，其中`c=(-b,1,-R/2,-R/2)`。质量阵M由车体三维对称惯量与三个转子惯量组成。在自由末状态qfree上，有限容量离合的末反力为：

```
D = cᵀ M⁻¹ c
Tc_required = δfree / (h D)
Tc = clip(Tc_required, -capacity, capacity)
qend = qfree - h Tc M⁻¹ c
```

容量裁剪对应真实摩擦容量：容量内末滑差为零，容量外保留正/反滑差。对应转矩为发动机−Tc、两输出各R Tc/2、车体Tc b。转子与壳体的三维总角动量因此闭合。燃烧转矩Te同样对车体施加−Te ae反力，燃烧功按末相对曲轴速度`h Te(ωe−Ω·ae)`记账。外部输出轴负载的功及角冲量单独记录。

独立验证包含两个轴布局、正反齿比±12、2/4/8/16子步与六个工况：离合分离、正滑差、负滑差、高容量锁止、燃烧带外负载及不等轮速。每次运行0.4s，共96条CSV、34,560步。每步另解7阶锁止KKT线性系统核对未裁剪的容量需求，并直接核对离散运动方程、三维角动量与能量恒等式：

`ΔE = Wcombustion + Woutput − h Tc δend − ½ Δqᵀ M Δq`。

最大能量账误差1.5233e−11J，角动量账误差2.5461e−13N·m·s；容量互补残差4.8423e−12N·m，独立KKT转矩差1.0914e−11N·m，运动方程冲量残差1.1217e−13N·m·s。原始离合功保留符号。正滑差工况的后向积分损失随2/4/8/16子步细化约31.4→15.8→7.89→3.95J；该数值损失不冒充物理离合热耗散，也不作为驾驶响应的精度证明。

负对照故意省略离合车体反力，首步角动量误差2.00693N·m·s，被同一1e−9N·m·s台架阈值抓到。实际生产接入仍须同时求发动机、离合、轮胎与车体共同末状态，验证轴向输运/陀螺作用、真实制动与换挡连续性，不能用本台架替代完整功能T1/T2。

[MathWorks离合模型](https://www.mathworks.com/help/sdl/ref/discfrictionclutch.html)支持相对轴速、有限摩擦容量及锁止/滑差的概念；[差速器模型](https://www.mathworks.com/help/sdl/ref/differential.html)支持输入/左右轴的速度与功关系。这里的三维壳体反力和离散能量关系为显式推导，未调用对应软件。
