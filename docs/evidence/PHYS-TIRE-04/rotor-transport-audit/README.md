# 转子轴向输运核对

[实际生产审计](summary.json)在同一Bullet世界创建车体，重力与角阻尼为0，没有地面、转向、驱动或制动。仅设置初始偏航角速率0.2rad/s，分别令四轮初始绝对转速为0或60rad/s，按生产120Hz走1秒。运行中没有重设车体姿态或速度。

按现有能量/动量模型，轮转子正转角动量为`−Iw ω world_right_axis`，车体为`Iworld Ω`。零轮速对照1秒总角动量变化0.001160N·m·s；四轮60rad/s时变化86.256142N·m·s。两者车体/轮速轨迹一致，新增变化来自旋转轮轴的自旋向量方向变化。原机制处理轴向驱动/制动作用反作用，尚未处理旋转轴向的轴承反力。

为验证因果，独立[真实陀螺冲量原型](../rotor-gyro-impulse-prototype.py)在同一原生世界施加轴承反力冲量；不设置运行姿态或角速度。记`S=−ΣIwω eworld`，对一步固定瞬时轴向解`(I−h[S]×)Ωend=IΩfree`，施加`h(S×Ωend)`。原生Bullet继续处理刚体旋转及自身刚体陀螺项，不替换其积分器。

| h (s) | 无陀螺反力：总角动量变化 (N·m·s) | 原型反力：总角动量变化 (N·m·s) | 原型总能量变化 (J) |
|---|---:|---:|---:|
| 1/120 | 86.256142 | 0.0888755 | −0.0630290 |
| 1/240 | 86.255707 | 0.0443386 | −0.0314036 |
| 1/480 | 86.256104 | 0.0223502 | −0.0158065 |
| 1/960 | 86.255714 | 0.0129094 | −0.0088005 |

[原型全部12条轨迹](../rotor-gyro-impulse-prototype/summary.json)还保存各h的零轮速对照，其误差受原生单精度读回/积累影响，不能宣称严格为0。反力首步约(0,86.399,−.608)N·m，改进随步长细化；仍有分裂积分误差和耗散，尚未通过一般车辆的能量/时序/驾驶验收。该原型只定位缺失机制，不作生产修复或04通过依据。

下一传动功能先补共同末状态中的转子轴向输运：实际机械轮轴与接触切向坐标分别定义，方向盘执行器转轴变化的功单独记账，发动机转子与轮转子使用一致的壳体反力。不能把本原型的步后额外冲量直接接在制动/接触求解后，也不能用负载无关角阻尼代替反力。[MIT三维刚体与陀螺课程](https://ocw.mit.edu/courses/16-07-dynamics-fall-2009/resources/mit16_07f09_lec30/)给出角动量随旋转轴向变化的背景；[Bullet2.84刚体源码](https://raw.githubusercontent.com/bulletphysics/bullet3/2.84/src/BulletDynamics/Dynamics/btRigidBody.cpp)处理原生刚体惯量的陀螺项，独立轮/发动机转子的自旋并未自动包含其中。
