# GR86质量分布与惯量推导初值

输入来自已保存的[来源记录](source-preparation.json)：Premium实测整备质量1287.295146kg，原厂轴距2.575m、车长4.265m、不含镜车宽1.775m、车顶1.31m／离地间隙.13m和53:47前后静载。以下是明确假设的工程初值，尚未标定。[可重复计算脚本](derive-mass-prior.py)与[完整输入／输出](mass-distribution-prior.json)一并保存。

坐标采用X横向、Y向前、Z向上。几何中心为Y=0，CG纵向坐标由轴荷得`y0=WB*(front_share-.5)=.07725m`；相对CG的前／后轮连接点Y为1.21025／-1.36475m，与现有wheel_hubs定义一致。

质量沿X均匀、沿Y按`ρ(y)∝1+k*y`分布，`k=12*y0/L²`，在两端仍为正；沿Z采用[.13,1.31]内的Beta(1,β)分布。选择CG高度.40／.45／.50m作为敏感性初值，均为模型假设；不加入未知驾驶员／设备载荷。三轴分布独立，因此本模型的惯性积为零。

令`u=(CGz-zmin)/H`、`β=(1-u)/u`，则`σx²=W²/12`、`σy²=L²/12-y0²`、`σz²=H²*u²*(1-u)/(1+u)`。整车刚性随动惯量为`Ix=m*(σy²+σz²)`、`Iy=m*(σx²+σz²)`、`Iz=m*(σx²+σy²)`，单位kg·m²。

高度分布变化影响俯仰／侧倾惯量，横摆惯量保持，符合该质量分布模型的定义。纵向均匀偏置和可分离高度分布属于推导假设，不能称为原厂惯量或实测质量分布。

这张表是整车刚性随动的惯量初值。现有机械核心还显式计入轮轴、曲轴及传动转子的转动能；正式配置的body_inertia必须按该分帐定义协调相应轴向惯量，再运行同一标准试验。因此当前不直接把表值填入VehicleConfig，不减少来源账本中的待标定项，不宣称实车型已完成。
