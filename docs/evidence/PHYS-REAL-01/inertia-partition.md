# GR86惯量接入准备

整车质量分布初值见[mass-distribution-prior.md](mass-distribution-prior.md)。本次只核对其与现有机械核心的分账，未加载实车型、未修改生产源码或测试，尚未进行动态标定。

`powertrain.observe`把曲轴／输入轴／下游轴的绝对轴速减去车身轴向角速得到相对壳体速度；机械轮轴采用相反的正滚动符号。`tire_drivetrain`的质量矩阵分别计入车身、四轮、曲轴和输入轴，`driveline_inertia`再以完整约束梯度计入实际安装的下游转子。因此，当各转子相对壳体静止时，每个实体转子仍有`ω_abs=Ω·a`，并携带`J(Ω·a)²/2`的能量和`J(Ω·a)a`的角动量。

所以整车刚性随动张量映射为`I_body=I_whole−ΣJ aaᵀ`。整车质量仍在同一车身刚体中，轮／发动机的位置和平行轴贡献已经包含在质量分布初值中，不再减一次；仅扣除机械模型独立计算的轴向自旋惯量，转子的横向随动惯量保留在车身张量。

本次暂沿用reference-v28的明确设计初值：单轮1.8kg·m²、曲轴.2、输入轴.04、输出轴.03、后驱动轴.02；它们都不是GR86实测。直行时四轮轴沿X、纵置传动轴沿Y，RWD不安装前驱动轴，因此扣除量为`(7.2, .29, 0)kg·m²`。

正式接入时按最终转子标定重算一次，再重建车辆。转向后的轮轴由现有机械核心计算，不在运行中动态修改body_inertia抵消实际转子惯量变化。当前来源账本仍为71字段待标定；这些候选值不会自动变成厂家数据或标定结果。
