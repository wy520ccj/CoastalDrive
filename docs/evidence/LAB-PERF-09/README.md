# 试验台真实Box法线锥支持求值原生化

2026-10-15，基线`a8633e4`。本块只原生化真实Box剖面内部的角度支持求值和原52轮细化，保留全局距离证明、轮胎形状及完整物理。持续优化目标active。

## 实现与保真

`box_cone_samples`批量计算同一法线锥的两个端点，`box_cone_refine`按原比较和角度序列执行52轮二分及最终求值。三角函数仍调用实际NumPy标量`cos/sin`，支持函数仍为原`support_values`。同角度重复三角函数结果只计算一次，三维乘加/符号和dot保持原顺序与严格浮点编译。

原Box的容纳轴、上下界、驻点资格、候选顺序、见证点/全局距离证明、容差及不能证明时的一般凸体路径保持。原动量/材料/陀螺、真实中点/末点接触、120Hz、双子步、34变量、差分/Newton/收敛和能量账均保持。

只重编wheel扩展；原C文件去掉两行新增注册后全文相同，原lab_contact_native.h计算段逐字保留。其他全部源码与四扩展保持，SDK/共享.venv及游戏未改。三工况的对照工具增加`--bump-abba`，基线仍须显式指定。

## 调用数与剩余热点

六拍残差1692次、真实道路查询1122次、端口552次、陀螺1095次、姿态增量1080次和线性求解2823次保持。前样本复用LAB-PERF-08/profile-after，核心源码/五扩展摘要、配置/协议与相同初六拍快照核对；只比较调用数，不用跨时段分析器耗时证明速度收益。

完整凸起前后真实道路查询29260次、Box证明21598次保持。原Python内部求值1089419次移入86392次端点批量入口和17295次细化入口，严格满足`2×86392 + 53×17295 = 1089419`。外层Python支持包装1921247→831828次，差额也恰好等于1089419；每次真实支持求值仍执行，没有跳过几何。

新完整凸起诊断payload与速度实验、旧诊断逐字节一致。新采样中Box剖面约占21%、全部径向道路约占54%（嵌套不能相加），原内部角度函数的Python调用已消除；仍有831828次外层支持包装和950216次单位矩阵构造。下一块重点为Box包围盒/候选准备及这些重复组装。
