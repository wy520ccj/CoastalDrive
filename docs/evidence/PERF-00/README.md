同一分支的新构建独立版见 `package-startup/summary.json` 和各次 JSON/截图：三次菜单首帧 7.505、7.282、7.257 秒（以 JSON 精确值为准），中位数 7.2819 秒；八车切换额外中位数 2.3371 秒。源码与独立版并列记录，不能互相代替。

运行期正式采样见 `runtime-quiet/report.json`：1080p、八车、种子 23、30 秒预热后采样 300 秒；节点 730、GeomNode 359、Geom 1546、三角形 312642。这次未达 60 FPS / P95≤25 ms 门槛。第一次长测有持续补帧警告且主动中断，没有完整报告；第二次把控制台输出定向到文件，正式采样丢时 0.0167 s。两次运行状态不同；不依据本报告推断版本性能变化或根因。
