# 第一块：统一报价、权威燃油与样板赛事会话

2026-10-30，基线15c321f5及工作区既有改动。任务整体仍在实施，不能把本块测试当成全部挑战重做完成。

## 当前实际行为

- `challenge_build.py`实现原车相对参数、9项凸费用曲线、2项免费调校、允许参数限制；重新生成完整候选，不叠加安装。十进制报价防止边界多收10。
- `fuel.py`的通用暖机设计效率岛在`Powertrain.accept_step`观察已接受主动功；不进入机械方程、不增加世界查询。FuelState随真实完整快照传输。
- `snapshot_wire.py`保留燃油加入前及更早布局；旧快照恢复为fuel=None，不制造零油耗。
- `challenge_rules.py`联合判定同次用时/耗油、固定规定里程、超预算试验、缺测/无效资格；用实际燃油量比较目标额度，避免单位换算误伤恰好达标。
- `challenge_scores.py`跨预算内方案比较，每档分别保留最快、最省油、最便宜完整记录，包含参数、配置摘要和真实分段；版本/输入/物理条件隔离，原子保存失败保留旧记录。
- `challenge_run.py`从正式发车燃油基准开始计量，多门同拍和终点按同一拍比例截取用时与耗油，结束后冻结；只接受道路原有通过/失败判定。
- 三条样板通过`Session.start(challenge_spec=..., build=...)`及同签名独立进程API接通。临时固定原车、暂停/复位/中止、重试保留参数及退出恢复已有测试。
- 正式工程模式关闭旧SprintRun成绩写入，不让超预算试验或待标定模式写旧奖牌；原非工程入口行为暂保持，等待统一UI接管后移除重复入口。
