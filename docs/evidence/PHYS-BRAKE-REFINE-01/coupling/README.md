# 制动细化的闭环/机械分离

接续基线6b08c926；只新增诊断工具，没有生产控制、扩展、机械参数或原测试变化。

- `recovery-guard`：原线性预测不变，实际κ仍在原目标上带外时暂缓增压。原细化路径标准失败；正常铺装保持、低附着略差，不接入。
- `actuator-average`：120Hz控制不变，仅用各机械子步的一阶液压响应精确均值。原细化两标准仍失败，正常两组未跑，不接入。
- `fixed-pressure`：断开ABS闭环，四种机械分辨率全部使用原16子步的720拍压力；不是正式ABS工况通过。机械路径差逐级减半，末两组停车相差1拍。16组除制动状态外每个字段与原721条记录精确相同，见`comparison.json`。

每组summary保存完整配置、原数值标准、起止生产/SDK哈希和执行工具SHA。前两组`executed-tool.py`与各自summary的工具SHA严格相符；当前`abs_recovery_check.py`对应最终固定压力执行。轨迹保留实际样本/压力/施力和机械状态，原基线和正常对照明确复用父目录历史记录。

工具的滑移积分只统计“本行完成步仍支持，且上一完成步ABS滑移有效”的交集，三组与父目录原始记录按相同口径重算；它不是全部轮胎的连续滑移积分，不能与其他工具的锁止轮秒混用。固定压力的`over_slip_apply_samples=0`来自明确`recorded_pressure`诊断阶段，不能解释为控制性能改善。

只确认闭环放大了当前接触细化差异，未证明某个单独策略有错。原完整闭环T2仍失败；下一复核瞬时失支撑的命令复位和预测/目标带切换，不为过测调参。Ruff单文件通过，原生产T1复用，不新增大套边界、道路长测或人工结论。
