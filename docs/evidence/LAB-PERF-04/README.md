# 试验台有限接触/力端口批量原生化

2026-10-15，基线`82ba3ca`。本块将独立轮心试验台的四轮力端口、有限径向虚功梯度和接触坐标组装迁到严格浮点C批量入口，真实道路查询和原完整物理模型保持。持续优化总目标仍为active。

## 实现与边界

`lab_contact_native.h`新增两项数值入口，挂在现有`wheel_contact_kernels`。直接复用既有`support_values`和`crown_secant_value`，不另写低精度支持函数；保留NumPy原三元素dot累加顺序及原逐项算术，沿用`/fp:strict`。通过Python缓冲协议读写四轮双精度数组，支持非连续步幅；类型/维度/形状、只读输出等边界明确报错。

Python的`unsprung_drivetrain.tire_ports`负责准备数组并调用原生批量组装；`FiniteRadialContact`仍先查询真实中点/末点，再将同平面身份和命中状态交给原梯度公式。没有减少几何查询、轮端自由度、34变量、差分次数、Newton/线搜索/阈值、120Hz或双子步，也未改硬件参数/非线性部件能力。

`wheel_contact_kernels.c`只新增一个include和两项注册；移除这三行后，其既有代码与基线全文一致。共同求解器源码未改。setup.py增加头文件依赖。本地构建仅重编wheel扩展，其余四个pyd SHA一致；旧/新wheel二进制和构建日志均归档。使用者更新源码后需以项目Python执行`setup.py build_ext --inplace`，本目录已完成构建。共享.venv及隔离Double SDK未改，游戏源码/配置/入口未改且未跑游戏验收。
