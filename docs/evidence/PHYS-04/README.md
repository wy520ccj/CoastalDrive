# Ackermann转向 A/B

基线`3337fad`。唯一受力机制变化是左右前轮的转向几何；质量、动力、悬架、附着、输入辅助和虚拟中心角限制保持。

## 理论与实现

虚拟前轴中心角δ对应后轴中心转弯半径R=L/tanδ。左右前轮分别取atan[L/(R+t/2)]和atan[L/(R−t/2)]，正角右转；内轮角较大、外轮角较小，两前轮轴线会合于后轴线同一点。[MathWorks理想Ackermann说明](https://www.mathworks.com/help/vdynblks/ref/steeringsystem.html)采用共同转动中心定义，[ROS车辆运动学](https://control.ros.org/master/doc/ros2_controllers/doc/mobile_robot_kinematics.html)区分虚拟单轨角与双前轮几何。

`VehicleCommand.steering`及CarState.steering仍是虚拟前轴中心角，SteeringRack限位±26°/速率50°每秒保持；真实内轮角可以高于虚拟角。Vehicle将两实际角分别传给Bullet，按Panda坐标符号取负。未单独钳内轮角破坏共同圆心。

## 相同输入下的行为变化

独立真实BulletWorld无限平面；四工况目标10km/h，虚拟角±atan(2.2/6)、±atan(2.2/20)，初速一次赋2.77778m/s，之后只请求踏板/角度，无路径纠正。120Hz积分，20Hz CSV；统计8～12秒的481个完成步。两份配置/环境/初始条件/控制公式完全相同，源码SHA区分A/B。

左转角互换取反，指标对称。接点横向运动分别减少98.11%/97.80%，符合两前轮不再要求互相矛盾的滚动方向；未把这一读数称为物理α或车轮ω。

质心有效半径使用**刚体水平速度模长/横摆角速度绝对值**，不拿车身前向速度除横摆来冒充质心半径。R位于后轴中心，默认CG在轴距中点，几何质心半径应为sqrt(R²+1.1²)：6.1m/20.03023m。B更接近低速几何预期，仍有约0.9%残余；现有Bullet侧向约束和阻力响应需要后续轮胎模型研究，不能宣称真实车标定完成。

完整四组CSV与摘要见tight-A/tight-B，tight-comparison.json核对试验条件与变化比例。工具使用比例速度控制，不含积分/微分项。

## 回归

既有七标准工况：直线加速与split-μ制动CSV逐字节相同；定圆、阶跃、弯刹的微小变化见comparison.json。默认20km/h大半径转向差异比6m紧弯小，符合轮距/半径比随半径增大而下降。
