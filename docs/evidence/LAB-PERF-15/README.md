## 实现与保真

`finite_motion_vectors`按原逐项减法、乘法、加法和NumPy普通叉积顺序，批量准备四轮旧臂、臂增量及相对速度输入；没有将普通叉积替换为不同舍入的补偿叉积。原机械精确叉积仍用于导向增量。旧臂和臂增量按原输入K布局分配，后续矩阵运算保留原C/F/向量步长语义；非float64的四轮分量明确执行原NumPy表达式。

`rotation_increment_terms`准备原Rodrigues表达式的skew、I+sin(angle)*skew和(1−cos(angle))*skew三个C布局矩阵；原NumPy范数、sin/cos和矩阵乘法保留。严格保留先缩放skew再矩阵相乘的顺序，未改成先算skew平方。归一向量按原cross_matrix对本机实数类型产生的float64矩阵值准备，float32的归一/三角函数舍入没有先升精度替代；本机longdouble亦为64位。原angle==0分支原样返回单位矩阵，不加入小角阈值。

有限悬架的wheel_jacobians@velocity、increment@old_guide、小位移压缩恒等式的两个@以及相对速度einsum保持；新轮心位置仍按原表达式生成。保留上一版的精确缓存、真实中点/末点几何、全局证明/细化、全部材料/陀螺/能量账、120Hz/双子步/34变量/差分/Newton和门槛。没有改变积分或真实世界状态。

仅wheel扩展重编，使用/fp:strict；原C文件移除两行新增注册后全文相同，原头文件计算段逐字保持。其他物理源码、四扩展、SDK和共享.venv未改；旧NativeEndMotion及构造函数AST相同，独立参考为基线整份原文件。游戏源码/配置未改。旧单DLL交叉工具不能跨本次新增运动API混用，旧/新性能按匹配源码和五扩展的完整AB对照。
