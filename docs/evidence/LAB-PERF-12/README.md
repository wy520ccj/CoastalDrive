## 实现与保真

`box_face_candidates`继续逐个调用原六向支持函数，并按原dot/减法/投影顺序准备面距离、见证点和资格；Python仍按原轴序选候选。`box_edge_frames`按--、-+、+-、++准备四条棱的法线基、端点及差向量，保留正负零。各查询使用独立数组，无跨世界/子步缓存。

原float32轴归一化/全局曲率界限、NumPy范数/sin/cos、容差、52轮细化、候选顺序、一般凸体路径、真实中点/末点道路查询保持。120Hz、双机械子步、34变量、差分/Newton、材料曲线、参数和能量账均未改。六向支持仍为真实原函数，未用对称性替代。面候选提前准备全部六面，Python仍仅选择原fixed轴。

仅wheel扩展重编，C头文件既有计算段全文保持，wheel源文件去掉两行新增注册后与基线完全相同；其他物理源码、四扩展、SDK与共享.venv保持，游戏未改。原交叉工具更新已知Box新增入口清单，仍拒绝未列出的新增入口，并对新增分支设断言。
