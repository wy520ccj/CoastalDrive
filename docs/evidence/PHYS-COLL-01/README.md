# 护栏接触 A/B

基线 `b168345`。旧车120km/h斜撞失败的主要触发是竖侧面内部三角边的假法线，而非真实栏顶：A/sample62接触点距路面0.41285m，位于高度0.8m护栏的侧面中部，距内部对角边0.01000065m，与mesh margin吻合；normal.z=0.959756、冲量1852.327Ns。该步合计上向刚体冲量1777.91Ns，悬架支撑8253N低于11772N重力。[详细A证据](A/README.md)。

## 机制与实现

`coastal_collision.add_rail_shapes`逐段使用原`rail_mesh`的八角点构造实心凸体，原有外侧、内侧与栏顶位置保持；新增段端面和底面封闭实体体积。每段改用局部坐标避免大坐标精度损失，margin仍0.01m。竖侧面没有内部对角接缝。护栏仍0.24m厚、0.8m高，车辆质量、惯量、摩擦、悬架、碰撞盒、控制参数与可见网格未改。不加高墙或隐藏上盖，不钳车辆状态。

Panda3D 1.10.16的[TriangleMeshShape接口](https://docs.panda3d.org/1.10/python/reference/panda3d.bullet.BulletTriangleMeshShape)未暴露内部边修正；本机API检查见A说明。此处改变碰撞表示，消除数值伪作用；不以调悬架抵消错误刚体法线。

| 相同试验 | A侧距峰值 / 绝对roll峰值 | B侧距峰值 / 绝对roll峰值 |
|---|---|---|
|60km/h|4.77274m / 9.72935°|4.55063m / 1.38819°|
|120km/h|10.62709m / 19.92899°|4.83411m / 10.29886°|

B两项均通过原6m/45°门槛。首次撞击护栏有效冲量法线最大|z|为0.00010152，原侧面向上假法线消失。120km/h仍有真实弹离与回撞；不能把正常碰撞的垂向运动统统清零。

## 事故语义

[B-convex](B-convex/README.md)保留首次实现：120km/h sample111–232持续无刚体接触，sample170最外侧顶点与护栏投影间隙约1.485m，sample235以2044.885Ns冲量回撞。两次事故是真实分离后的不同接触过程。原“只能一次事故”断言因新轨迹不再适用；测试明确60期望1次、120期望2次，6m/45°阈值保持，并新增竖侧面法线与首次求解接触计数检查。

原计数用`contactTest`另做查询，第二次计数延迟51tick。计数现直接读取完成步的persistent manifolds，以非正距离或非零求解冲量确认接触；连续接触的120tick事故间隔逻辑保持。声音冲击判定仍使用原ImpactTracker。

`B-final`保存最终计数与每步events，附实际源码SHA256；`git_sha=b168345`表示父提交，SHA区分未提交实现。`B-convex`是只换碰撞表示、尚未修计数的中间结果，不能冒充最终版。

## 回归

- 七标准工况与PHYS-03新车B逐CSV比较：1168个记录时刻、117列，136656个单元格全部一致，见sample-equivalence.json。每tick物理仍120Hz，CSV每6tick一次。
- 首次原地图测试12通过、1失败：几何门槛已通过，失败是120km/h真实回撞的第二次计数，完整原因与语义如上；未隐藏该中间结果。
- 定向地图/交通碰撞/冲击事件/集成：30通过。
- 首次T1停止于新增import未排序（t1/ruff.log）；排序修正后运行t1-final，最终结果见summary.json。
- 最终T1 vehicle/traffic/road/audio：183通过，三种子1200tick及0/23种子弯坡30秒通过。最终120km/h计数发生在sample60、235，与实际撞击同步。

不由无窗口测试判定玩家驾驶体验、可见窗口性能或整个物理目标完成。Bullet原生轮射线仍可能命中真正的护栏侧面；后续轮胎核心应区分路面支撑与侧面接触，不将该缺口用假Fz或假滑移隐藏。
