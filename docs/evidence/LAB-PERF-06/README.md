# 试验台径向平面查询与接触坐标批量化

2026-10-15，基线`ae3704d`。只改变试验台真实接触查询的常量准备和计算组装，完整物理模型、120Hz、双机械子步、34变量、差分、收敛阈值和能量账保持。持续优化目标active。

## 实现

平面的世界法线与常量在当前子步只读`RadialSurface`内准备，四轮局部支持距离和见证点由严格浮点C入口批量计算。候选仍按原表面顺序和原支撑/距离条件选择；已选接触和腾空的法向、切向、侧向、加载偏置再批量组装。所有中点/末点真实查询继续执行。

矩阵变换继续使用原NumPy矩阵@向量及内存布局。10000组随机探针发现，普通C三项累加会改变C布局矩阵运算的9935个分量位模式，因此没有采用该替换。Box全局剖面证明、一般凸体GJK/EPA、有限三角面候选与查询公式保持。

只重编wheel扩展；其原C文件移除两行新增注册后与基线完全一致，原头文件计算段逐字保留。全部其他源码、四个扩展与隔离Double SDK的摘要核对一致；共享.venv、游戏配置/入口保持。

## 同批完整实验

旧源码与五扩展保存在`builds/lab-perf-06/baseline`，每次核对实际加载路径及源码/二进制SHA。A/B均使用隔离Panda1.10.16/Bullet285 Double SDK。速度实验串行完成后才运行分析和测试；完整物理步包括原快照/信号处理及双方相同的轻量共同解收集，序列化在计时后。

## 数值对照与已知边界

800组随机C/F布局旋转、平移、正负零量级与非连续输入对旧正式公式逐位核对；实体Box边缘/腾空、实际世界凸壳/三角网格及移动/移除一并覆盖。实际凸壳使用与生产相同的原顶点登记。

扩展的旋转三角网格边缘输入触发了旧EPA支持间隙未闭合；新旧查询在同一输入上拒绝，并报告完全相同的异常类型/间隙文本。该原有几何边界仍待修复，未放宽阈值或将失败接点当作成功。新增测试明确核对失败一致性，成功查询逐位比较。首次T0和专项的两个新增测试失败报告保留：凸壳夹具原缺顶点登记，另一个是上述原EPA边界；最终验证独立写入`*-final`目录。
