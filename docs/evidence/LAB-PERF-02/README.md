## 物理结果核对

八次完整实验共480拍、960个机械子步。各协议所有A/B的原始payload字节完全相同，包含：

- 全部完整快照，包括原生车身/轮心状态、接触、轮胎、传动及完成步信号；只归一运行实例epoch。
- 每拍全部分析信号与执行器输入命令。
- 每个共同解的全部数值字段，包括力/速度/行程、轮胎状态、能量/功/损耗、动量/力/端口残差及迭代次数；仅排除含原生节点对象的`contact_geometry`引用，实际接触已由完整快照覆盖。

各协议配置和输入逐项相同；没有用更宽误差容差接受差异。原生叉积还与NumPy对10000组随机双精度三维输入完成位模式相等核对。完整物理Gate已有开放项继续开放，本轮不声称修复原有有限姿态能量误差。

原始比较报告的config是请求配置；正式LabExperiment按LabOptions关闭ESC。原始文件保留，summary的分组config按核对未改的正式构造代码恢复实际配置（唯一差别为ESC关闭），请求值另列。比较工具今后直接保存run.config；这是报告字段修正，没有改变实验或重跑速度测试。
