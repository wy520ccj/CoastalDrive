## 依据与实现

先在原物理程序上计数真实残差序列，诊断payload与LAB-PERF-15逐字节相同。凸起44318次残差中，完整速度变化21674次、速度+接触力变化31738次、连续扭矩变化13497次；制动6768次中分别3312/4848/2064次。初始化另列，不将带调用计数的耗时当作性能。

在原velocity_terms的速度字节键下计算并复用原连续反力前缀engine−spring+normal；再用完整速度键和8个接触力原始字节复用切向反力前缀与陀螺所需轮心力。十端口投影矩阵在本次共同解固定，用完整扭矩字节复用原ports.T@torques。三个缓存均为本次solve局部的最后一项，每次调用重建，不跨物理子步、不按容差合并。

原矩阵@、左关联加减及轮心力表达式保持；前缀展开后与原表达式AST精确相同，端口投影和轮心力AST也相同。新unsprung_momentum_values严格逐项执行原端口减法、12至15槽滚阻减法、随后free−dt*(reaction−rotor_bias)，不融合乘加；直接填写34残差前16项。反力输出独立，不修改缓存前缀；陀螺增量仍按原算法扣除，切向/端口仍填写原其余18项。

没有减少残差/差分/真实几何或陀螺求值，也没有改动30轮Newton、线搜索、精确端口导数修正、收敛门槛及结果能量账。原迭代与能量结果段源码全文相同，UnsprungJointStep和dry_port_derivative AST保持。保留模型/参数/120Hz/双子步/34变量及碰撞。

仅wheel扩展重编，/fp:strict；原C去掉一行新增注册后全文相同，原头文件计算段逐字保留。其他物理源码、四扩展、SDK和共享.venv保持，游戏源码/配置未改。独立完整共同解参考来自基线整份原文，完整速度键包含旋转/自旋状态，不能只按轮心速度复用。
