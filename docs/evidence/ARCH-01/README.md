# 输入与执行器职责分区

基线`4f62401`。本包移除合并VehicleResponse，按作用分成DriverAssist、SteeringRack、Powertrain，Vehicle直接调用这些对象，没有中间管理器或兼容外壳。研究入口用VehicleCommand，默认玩家和现有交通继续用Control。

- DriverAssist：踏板输入平滑、速度相关转向包络、刹车键停稳后倒车/反向时先制动。
- SteeringRack：实际虚拟前轴中心转角、角速度、±26°机械限位与50°/s速率，阻尼响应算法保留。
- Powertrain：转速、自动档位、换挡/离合简化、转矩响应和发动机制动，原参数/运算顺序保留。
- Vehicle.apply_command：同一实际轮胎限力、悬架、阻力和刚体受力路径；Simulation.step以120Hz推进同一世界。

`VehicleCommand(steering=15, throttle=.5, direction=1)`明确请求实际转角（度）、踏板0～1、方向−1/0/1。直接请求省去键盘输入平滑与高速转角包络，齿条和动力响应仍有状态；`VehicleCommand(brake=1)`持续制动，不因为等待0.4秒变成倒车。接口声明有效输入范围，不增加内部反射、静默默认值或异常外壳。
