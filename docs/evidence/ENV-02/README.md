人工查看重点：驶入岩坡时的石脚/坡面衔接；两侧树干是否贴地；转出林地后留白是否自然；灯塔礁和浅水/泡沫是否融合；行驶时远处水纹与护栏边缘是否舒适。自动测试不能代填这些观感。
