# 城市街区进入实际驾驶视域

2026-10-29。本目标前一轮草土/后院修改是实际进展，但原追车图仅改变178像素，证据表明不能继续用材料和侧向图推进整体城市。本轮先复核几何原因，再更新设计和实施，没有前台窗口或桌面操作。

## 视域证据与设计45

一次离屏加载采原3.2米镜位的3600/4400/6000米三个实际图，已查看。新增采图元数据直接投影实际楼体AABB，HFOV68度：与视锥相交包围盒对应的最近楼体中心分别163.96/189.76/156.88米，100米内均为零。数据尚未扣除树木、地形或其它楼体遮挡，不能称实际可见像素/可见中心点。原首排横距89–94米导致住宅长期充当远景，只改表面无法解决。

沿用43已实际查看的FH5 Guanajuato/KCD2 Troskowitz作者完整场景，以本轮实际3600米图、44与43为参考，内置ImageGen生成45-city-street.png。图、原提示词和技术规格施工前保存。图中新增远山/海景/植物和改变的道路尺度不照搬，主路、原3.2米镜位/FOV、认可天空保持。45仍是目标，不能冒充成品。

## 实现

常规区间两条地方街65/155→41/131米，首排中心约65–70米；城市上缓台抬到主路下约1.5米，内侧车道边缘37.5米即有平整支撑，35米内原地形与物理树带保持。每行追加三个动态缓台断点，避免街道按公式落地却被原粗网格埋住。原约340米岸线、城市纵向渐变和其它地区/生涯保持。

发现原桥台约占横距41–51米，故没有机械地平移整段：桥前后75米逐渐退回旧街区横距，前后18米保持旧65/155米两街；原桥/桥台/填方保持。街道、横街、住宅、院落、根位和草土遮罩共用绝对里程偏移，入口楼体端固定楼门中心偏移。相邻段无需保存上一段状态。

原三组6树/12灌移到新街外侧和地块间，常规树根约50–57米，桥位74–81米；街树/院树和后院群落数量不变，没有35米内新增无碰撞树干。草格按人行道留退距，常规区保留至31米中心、最外四角33米，避免穿入35.7米起的人行道；这是街界调整，不能再沿用旧“35米内所有草格不变”的描述。物理树/地面不受该草格筛选影响，没有删除整片近景景观来换帧率。

保持四住宅族、原模型/纹理、共享LOD和原准备策略；未增加资源或通用场景API。只改现有环境私有函数/本机表现入口及检查工具，不改权威物理、车辆、存档、成绩、相机或主路。
