# 沿海生涯：地区光照已接线，海岸样板未完成

2026-10-29。上一轮城市树群重组为有效进展；本轮保留建筑与城市布置，转入原全场景计划仍缺的沿海生涯。全程只用后台/离屏，没有前台窗口、桌面操作或真实驾驶；没有提交推送。

## 当前默认版本

沿海冲刺coast-club、海岸杯coast-final复用38的同源8K HDR、离线反射、太阳方向/颜色和曝光。林地天空漫反射取区域清单的career_sky_diffuse_scale=2.6，固定滨海仍0.65；直接照搬固定滨海参数的首版林下过黑，未作为最终版本。原HDR和离线环境的实际SHA与清单均吻合，没有换成生成云图。

Scene、现有环境模块和本地植物启动链共同收口：本地KCD初始化不再覆盖沿海Scene的太阳/SH，护栏投影按同一落日方向与真实坡面求交；没有朝光交点时不伪造解析阴影。原流送阴影采样保持，未扩展固定滨海9tap滤波。天空、反射和远景空气透视使用相同色平衡。原点变换后阴影按绝对光空间网格稳定，退出Scene恢复此前曝光。山脊与普通高速仍走原晴空路径，实验台/车库光照没有纳入本次修改。

海岸地形、水面和短草已撤回。因此默认沿海生涯仍是原地形/原草木，尚没有满足46的海岸开口；不能把光照接线称为完整海岸样板。城市源码和原35米物理树带、物理地形/路网/车辆/交通/会话代码与本轮前哈希一致，120Hz架构与相机不改。未新增动态探针、SSR、阴影层或默认水面绘制。

## 研究、设计和未采用候选

实际查看38/26设计及沿海冲刺120/520米原镜位；复用26记录的KCD2 Nebakov/HD2 Rocks作者完整场景和38记录的RenderPipeline研究。以实际起点、26构图与38光色生成[46](../../design/garage-v2/46-career-coast.md)，图片已复制到B盘。图中的云形、巨大太阳、路牌文字等生成偏差不制作。

候选复制原8米笛卡尔地形，按世界东侧岸线/最近道路保护回头弯，48米内原顶点保持，外侧渐降到-8米，水面-3米。树根/草高场/平滑法线读同一表现网格；原Bullet地形不变。Scene持有一片低面数海面，沿用波纹与同源天空反射；补充海侧林群按地块留开口。后续复核直接混合原上坡与海底会形成新高脊，改为先去除持续上升的坡量，并试原株高45%的沿海短草，原物理树根位和相机保持。

两轮实图仍没有达到设计：正常3.2米/HFOV68镜位，首版沿海冲刺520米着色图强紫色海面像素为0；消除高脊后120/520米为0/91，决赛520/1120米均0。这是特定着色阈值的开口诊断，不是完整遮挡/审美/驾驶验收；实际画面也未呈现设计的宽海面。48米保护在原地形上保留约路面上2–3米的坡脊，而3.2米眼位看向更低海面时仍易被坡脊、草冠及近树阻断。最近道路保护还会让前方弯道成为岬角；只加太阳、缩草或反复混合高度无法保证视域。

按计划停止同路线试参，地形/海面/短草及其默认入口均撤回，源水面片元恢复本轮前原字节。纯几何保存在art/expressway/candidates/career-coast/geometry.py，完整失败源快照在logs/all-scene-20261029/career-coast-rejected-source，不是可直接启动的默认实现。下一步先复核35米实际保护范围与8米网格插值的关系，评估局部网格制作及预算，再更新规格，不抬高相机或改物理换开口。

## 验证与失败记录

- 光照T0六项：五个实际坡路投影、一次原点变换阴影网格检查通过。可复用此结果，相关数学源码未再改变。
- 最终T1仅两项集成：沿海冲刺→决赛→山脊→菜单的正式动作函数，以及固定滨海自由/计时的地区光照/检查点/水面快照回归。Ruff、两项pytest和原生headless0/17/23通过。成绩只在隔离夹具中解锁入口，未读写用户成绩，不等于人工菜单体验或跑完路线。
- 候选地形的8米网格、接缝、草根与法线九项T0通过，后续岸坡检查曾有两项严格字节相等失败（约1e-15浮点混合差异）；明确保留保护区原值后两项通过，没有放宽阈值。它们证明几何/保护约束，不证明候选画面应采用；对应测试随候选源归档，不纳入默认通过口径。
- 初次整图水面时间对照中止：不同时钟下旧冻结水面也有28像素变化，同一时间恢复有37像素变化、最高通道差24，波动位于树叶等边缘，不能据此归因水面。随后隔离非水面景物，同时间/冻结对照均0差异，0→2秒有1,129,069像素变化、2秒重复0差异。此结果只证明候选水面GPU时间功能，不证明正常视野看见海或帧率。
- 最终T1首轮被测试文件多余空行触发的I001中止，未进入pytest；修正该文件后另起目录完成最终T1，未覆盖失败记录。

最终默认成图只补一次沿海冲刺120米，目录career-light-final，作为撤回后的真实光照对照；早期带候选地形的成图不冒充最终默认。各次捕获都固定权威tick=60，原路线种子17；并未实际驶至这些里程。图形格式降级提示保留在原输出，不等于新GPU性能结果。
