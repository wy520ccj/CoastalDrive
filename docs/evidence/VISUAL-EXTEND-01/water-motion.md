# 滨海水面静止修复

## 原因与修改

Scene构造时对整片海岸执行flattenStrong，海面也被并入名为start-grid的GeomNode。初始sea_time=0被固化到Geom局部ShaderAttrib；随后Scene.apply虽修改所持节点的时间，实际绘制时仍被Geom中的0覆盖。因此旧静态截图中的细浪有形状，却没有真实动画。

只在coastal静态合批前临时摘下原ocean节点，合批完成后原样挂回。海面继续使用原Snapshot时间，不新建时钟，不改shader、波速、网格、材质、物理、镜位或原道路静态合批。自由/计时共用同一修正。暂停仍按原规则停止世界时间。

## 实际绘制验证

`tools/environment/check_coastal_water_motion.py`固定原镜位和快照姿态，仅替换表现时间，不作正常驾驶性能测试。修复前检查明确失败：0/0.5/1/2秒最终Geom时间均为0，海面ROI像素逐字节相同。修复后同一次零时间重复仍相同，实际Geom时间准确为0/0.5/1/2秒，GPU海面区域发生持续变化：

| 相对0秒 | 变化像素 | 平均通道差 |
| --- | ---: | ---: |
| 重复0秒 | 0 | 0 |

| 1秒 | 11809 | 7.4134 |
| 2秒 | 12067 | 11.3779 |

修复前后0秒海面ROI完全相同。全幅比较仅56个通道有差、最大53、平均0.0001183，属于重新合批后的极少深度边界像素，不能声称全幅逐像素零差。原/新summary分别归档water-motion-before.json、water-motion-after.json，固定帧原件在logs/visual-extend-20261028/water-motion-static-before/after。
