# 城市草土职责与后院群落

2026-10-29。前一轮街区靠近和街道草格修正属于实际进展，原追车构图仍空旷；本轮继续全场景计划的城市块，全程后台/离屏，无前台窗口或桌面操作。

## 按44制作

沿用44已生成的庭院/绿地目标及43的完整场景案例。实际查看当前侧向全景、Leafy Grass、Grass Ground和本机pasture原底色；前两者分别含大量落叶/干草斑，不因现成可用而用于更绿的城市地面。源码确认地表统一混入8–55%踩踏干土，底色/法线/光泽/高度均参与，城市庭院也因此灰荒。先补44用途规格，再改已有本机材质配比。

现城市65–155米两街之间降低干土权重，横向过渡藏在地方车道61.5–68.5/151.5–158.5米范围下，纵向仍为原3200–3440/6160–6400的城市渐变。相位由原路段根提供，600米局部UV/8000米城市周期及种子偏移一致；原35米内、自然路段和生涯遮罩为0。底色、法线、光泽和高度共用权重，林下覆盖仍有效。共用meadow_color保留原双参数入口，原草片继续用原配比。

首轮实图配比生效但城市表面仍显粗糙，按44补规格后，将城市区域法线幅度降到原30%、视差高度降到25%，不改变地形/碰撞高度。后院6株散置灌木重组成两组，每组1棵6米乔木和2株1.4米灌木，仍6株、沿原步道两侧布置。其它街树/院树、主路林缘、建筑与路网不改。

没有新增纹理/源模型/透明叠层/全屏效果/Scene公共API。地形源码与施工前副本逐字节一致，最终只改本机环境材料及入口、城市后院摆放；商业游戏安装只读，新增输出不包含商业原件。既有可发布资源和物理边界保持。

- T0-city-ground的GPU检查通过。T1-city-ground仅选城市遮罩GPU与原草地生长场GPU两项，Ruff和原生headless0/17/23通过；不是全玩法运行覆盖。未重跑无关旧12/40/91项。
