## 数值方法与精度边界

上一块实测中央差分占原完整凸起计算82.70%。本块首次仍按原34列中央差分构造缩放Jacobian，接受完整步且缩放残差范数下降超过一半后，采用Broyden一阶割线更新；发生阻尼步/下降不足/零位移则下一轮重建。旧Jacobian奇异或12次线搜索不下降时重建；首次完整Jacobian的错误仍原样传播，30轮上限不变。

更新在x/state_scale与F/row_scale坐标执行J+=(ΔF−JΔx)Δxᵀ/(ΔxᵀΔx)，与[官方SciPy公式](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.broyden1.html)一致。每轮仍按当前分支重写精确有限离合/同步/制动端口行；实际候选仍调用原完整残差，不能以更新模型的残差作为收敛判断。

原门槛仍为动量<1e−9 Ns、切向力<1e−5 N、有限端口<1e−9 Nm。首次试验达标时部分残差较接近门槛，因此增加一次收敛后校正：仅在完整残差范数下降且三类原门槛仍全部满足时接受，否则保留已合格的原状态。不增加迭代上限，不放宽任一物理门槛，不修改力/轮速或真实世界状态。

原共同残差/构型/速度数值定义、初始条件、质量/材料、碰撞、120Hz/双机械子步/34未知数及最终全部能量结果段保持。独立冻结模型的evaluate/configuration/velocity_terms与原函数AST精确相同，finish能量段AST与原结尾相同。只改unsprung_joint.py；五个原生扩展及Panda1.10.16/Bullet285 Double SDK未变。

默认启用Jacobian更新；jacobian_updates=False保留同一残差下的原完整Newton。历史36组共同解、8组真实有限接触逐位检查与旧预测文件1e−13/1e−9门槛均继续对显式完整Newton检查，不放宽原阈值。默认新算法另用冻结原方程独立验证；算法路径改变，不能再宣称旧新完整输出逐字节相同。相同算法重跑仍逐字节相同。
