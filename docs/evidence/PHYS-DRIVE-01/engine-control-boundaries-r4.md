# 当前发动机请求能力与实际挡位边界

## 主动发动机能力

现有曲线已声明为全负荷有效转矩。参考车600RPM全油门时曲线110Nm，原怠速补偿却把主动请求加到151.8879Nm。这里核对的是发动机产生的主动请求，不是受惯量影响的瞬态离合/轴端输出；后者可以与曲线瞬态不同。原数值、全部测试域与12条旧标准轨迹的非越界统计见[初始记录](engine-envelope-initial.json)。

MathWorks [Generic Engine](https://www.mathworks.com/help/sdl/ref/genericengine.html)把发动机输出表述为当前转速可用能力的比例，并明确区分产生的转矩与惯量后的轴端输出；[SI Controller](https://www.mathworks.com/help/autoblks/ref/sicontroller.html)也要求怠速转矩请求受能力约束。本项目保留自己的閉节气门损失和现有控制时间，不迁移其控制架构。

当前原曲线记为`Tmax(rpm)`，主动请求为`min(Tmax, Tdriver + Tidle)`。原24Nm闭节气门损失、怠速响应/65Nm设计上限、两模式0.02/0.2惯量、小油门能力内净增量均保持。约束发生在实际主动执行器输入；共同求解、发动机绝对ω、相对RPM、轮端反力和热全部继续由同一动力学积分，绝不钳RPM或清轮端转矩。

新增两模式7个RPM×5个踏板及动力不足原生检查共72项，原版17失败/55通过。将原生主动能力改为20Nm而保留24Nm怠速损失，旧版仍请求24Nm并凭空维持900RPM；当前请求≤20Nm，真实怠速自然下降。修复后的发动机/原驾驶响应/玩家制动倒车完整相关T0实际102通过（101.4s），280源前后一致。低速/反转测试只证明该机械请求约束，没有引入燃烧循环、化学熄火或启动器模型。
