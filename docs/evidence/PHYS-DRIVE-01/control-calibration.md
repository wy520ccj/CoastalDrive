# 传动接入后的控制闭环与模式标定

这些是当前候选的程序设计和原生诊断，不是实车参数识别或人工驾驶验收。源码/完整配置/逐tick轨迹分别保存，版本变化后旧结果只支持其当时版本。

## 机械因果

曲轴绝对轴速有独立惯量，相对壳体RPM由真实原生角速读回。有限离合滑动时按容量传矩，锁止时依靠约束反力维持共同转速；离合热与双向齿轮损失显式累计。没有目标轮速或积分后RPM修正。这与[MathWorks离合动力学](https://www.mathworks.com/help/simulink/slref/building-a-clutch-lock-up-model.html)中独立惯量/有限摩擦容量、锁止后合并动力学的方程一致；本项目仍使用自己的三维轮胎/陀螺联合求解，未迁移其子系统架构。

忽略轮胎滑移和壳体转动，仅作定比运动的储能解释，`ωe=R*v/r`，曲轴储能为`Je*R²*v²/(2*r²)`，运动学等效质量为`Je*R²/r²`。一挡总比12.025、轮半径0.33m，Je=0.2对应约265.6kg，Je=0.02约26.6kg；实际加速度还受双向效率/负载/离合状态影响，生产仍求完整方程。这解释为何加入真实曲轴后，旧无曲轴模型的早期位移不能靠仅改反馈时间恢复。参考：[转矩、惯量和齿轮建模](https://se.mathworks.com/help/sdl/about-inertia-motion-and-gears.html)。数值是本车配置计算，不是外部典型汽车统计。

原驾驶踏板/齿条参数、发动机曲线、制动硬件、电子增益和介入门槛保持。闭节气门24Nm口径、实际燃烧与怠速请求、有限离合控制分别处理。本拍请求先形成再计算容量，起步目标使用已执行节气门；0.30s离合反馈用于平衡曲轴升速与早期传矩。改变目标时序的独立T0仍4失败/7通过，保留记录，未宣称它消除了整体回归。

## ESC在介入速度处的参考连续性

旧控制低于1.5m/s把参考横摆和侧偏置零；新传动起步较慢、转向已建立，刚跨门槛时参考从零滤波，正常几何侧偏约0.23rad被误判为失稳，削矩至0后又跌回门槛。实际轨迹显示速度反复约1.5m/s，轮胎滑移并未表明这一削矩正确。Je扫描0.2/0.1/0.05均未消除该循环，转弯横向位移仅1.54/1.62/1.71m。

当前`continuous_reference=True`在有支撑、非零低速时继续跟踪可达参考；原1.5m/s门槛只决定实际制动/削矩介入。增益、时间常数、阈值和真实状态保持。独立负对照在同一正常转弯真值上比较旧零参考和连续参考：旧控制刚跨门槛削矩至0，新参考误差在原阈值内，无虚假介入；低速仍无电子制动/削矩。28项相关T0及原左右转弯检查通过。

该修正是单独明确的控制机制开关。冻结ROT对照须同时关闭`finite_drivetrain`和`stability.continuous_reference`，不能把只关曲轴但保留新参考策略称作旧版本精确对照。前一44条A/B仅切曲轴，未含这次参考修正，是历史候选证据。

## 两模式的新惯量设计值

正常游戏候选Je=0.02kg·m²，困难参考车Je=0.2kg·m²；差异写入完整参数表，并共用同一个机械核心。两值均为设计值；0.02用于保持原游戏起步动力性，0.2用于通用参考车自然动力学，未将其中任何值当作实测飞轮/发动机参数。

[原惯量扫描](inertia-diagnosis-r1/summary.json)保留0.2/0.1/0.05的全部起步/转弯/坡道轨迹；[连续参考后的0.02候选](inertia-diagnosis-reference-r2/summary.json)3s起步10.369m/s、位移12.170m，左右转弯/完整起步仍以原测试门槛复核，不将单侧诊断替代左右检查。困难参考车保持0.2，真实燃烧、惯量储能和离合负载参与机械闭环，不套用游戏起步响应。

机械独立账增加0.02/0.2两惯量的共同末状态工况，沿用3e−9J、0.001N、角动量和有限制动容量门槛。扩大T0实际365通过/1新增首拍容量=0预期失败；真实首拍容量7.458Nm，按有限执行器容量界修正该预期后，4项研究请求T0通过，原车速<0.1门槛保持。原H1动力/左右转弯/坡道和驾驶响应均通过。

完整T1-r1在出现4个H1失败后主动终止，启动/弯坡未跑；当前T1-r2与两开关44条A/B运行，记录完整保留，结果未预记通过。原生完整机械账保持所有符号，游戏仅曲轴240/480Hz存在约0.0004/0.0003J正漂移、960Hz角动量误差回升，反映当前原生时间精度边界；不会用机械台架能量门槛宣称世界积分完全精确。
