## 载荷机制与严格兼容

`tire_properties.py`给出D=μFn(Fn/Fn0)^(0.90−1)、Cx=Cx0(Fn/Fn0)^0.90、Cy=Cy0(Fn/Fn0)^0.85；Fn0=mg/4，离地能力为零。三个指数是设计近似参数。轮胎隐式求解、低速静摩擦可行域及ESC能力预测使用同一D；车体、轮速与接点冲量仍由原唯一耦合路径推进，120Hz与两个默认轮胎子步保持。ESC正常转弯侧偏参考仍采用标称后轴刚度的线性近似，实际能力上限采用当前非线性轮荷预算。

[候选扫描](candidate-scan/summary.json)覆盖1320行，两轴/两路面与0/0.5/1/1.5/2倍Fn0及6000N悬架上限；40001点正滑移峰值扫描，±1e−5小滑移差分。标称轮荷220行Fx/Fy与原网格严格相等；三个指数全1时1100行旧网格严格相等。固定轴总载荷，50:50→30:70/10:90时解析总峰值能力下降0.743828%/3.391421%；动态车辆能力还受实际轮荷、滑移和电子执行器影响。

[严格机械对照](mechanical-linear/summary.json)加载冻结`92edbf5`源码，仅把当前三个指数设为1，保留ABS/TCS/ESC。真实test/coastal/endless-hills三场景各1200tick，共2,366,896既有值零差异；新增轮胎能力/刚度诊断单列，70个生产Python源码SHA前后相同。完整冻结源码ZIP与双边原始JSONL gzip保留，解压研究副本不入Git。
