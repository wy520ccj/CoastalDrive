# 固定轮胎标定轮荷：物理因果与证据

基线ebcc448，本树codex/simulation-fidelity。原公式以当前mass*g/4为参考，改变整车质量同时改变峰值和Cx/Cy的轮胎函数。现在固定Fn0，只用实际Fn进入Fn/Fn0。

| 量 | 定义与作用 | 当前数据依据 |
|---|---|---|
| Fn0 / N | 固定的台架标定轮荷，不是每帧轮荷，也不是轮胎额定承载上限 | 参考车2943N为模型迁移值，GR86为3157.09134571215N；均非胎厂实测 |
| Cx0 / N/κ | Fn0下小纵向滑移斜率，影响轮速/制动/ABS响应 | 原设计/工程初值保留 |
| Cy0 / N/rad | Fn0下侧偏刚度，影响不足转向和横摆响应 | 前后轴分别已有定义，尚待台架数据 |
| pD、pX、pY | 峰值、纵横刚度随实际轮荷的指数 | 现有0.90/0.90/0.85为设计模型；未新增任意系数 |

D=μ·Fn·(Fn/Fn0)^(pD−1)，Cx=Cx0·(Fn/Fn0)^pX，Cy=Cy0·(Fn/Fn0)^pY。同一轮胎在相同Fn/μ/滑移下，其力学不随整车mass改变。增加实际载荷时D增大但D/Fn下降；不能为了满载保持相同停车距离，把Fn0改成新的mass*g/4。换胎或改台架基准时，应成组重新标定峰值/刚度/负荷曲线，不能把Fn0作为“更真实”的单独旋钮。

## 标准对照

`python tools/physics/tire_reference_probe.py --output logs/SIM-TIRE-01/ab-verified`。同一1500kg参考设计车，惯量同比缩放、硬件/初值/120Hz两子步/100km/h/μ0.6/ABS相同，只改Fn0：

| 模型 | Fn0 / N | 停车距离 / m | 时间 / s |
|---|---:|---:|---:|
| A，等价旧质量归一化 | 3678.75 | 65.864776 | 4.733333 |
| B，保持同一轮胎数据 | 2943.00 | 67.597686 | 4.866667 |

本实验是设计模型因果对照，不是具体乘员/行李装载或实车制动验证。CSV保存实际轮荷、峰值、Cx/Cy；ab-summary.json保存配置、源与DLL指纹、原轨迹SHA和施力残差。四轮持续接地，无碰撞。力预算与本构目标的误差按公开数值分量残差计入，上界√2×residual+1e-7N；A/B最大残差9.9995e-5/9.9872e-5N，未改求解阈值。

T1 485项/Ruff/三种子通过；GUI实际参数读写/短物理/导出载入720/1080通过。物理使用项目.venv，扩展从本树源码重建；不依赖main已有或待接入的悬架准备DLL。

## 留存的失败与覆盖边界

- 初始37通过/1来源账本失败：新Fn0及既有native_tire_forces字段未入完整GR86账本，已补明模型/迁移来源，未伪造原厂测量。
- 首T0原夹具有3个完整NPC身份断言失败：夹具未选择困难完整NPC，或要求游戏简化NPC与玩家配置对象相同。显式选择完整模式/核对实际简化角色后83通过；没有改游戏模式路由。
- 首探针错读不存在的supported_wheels字段，改为真实四轮接触；不算有效A/B。
- Python/遥测首次修改时，干地及μ0.6整车轨迹完全相同，暴露原生联合求解/采样仍使用旧质量基准。已统一三个原生入口，最终轨迹实际改变；早期83项通过不能当作全链完成证据。
- 新力预算检查首次在近停时以1e-7N当成无残差严格边界，实测力超预算1.9837e-5N，同时已有分量残差3.2799e-5N。验证改为真实本构残差的数学上界，未动机械阈值或掩盖误差。
- 原log目录保存失败/中间记录；这里只保留最终证据。T2/T3、独立轮胎实测拟合、主目录整合和人工结论未完成。
