## 修改与验证

- App/Cull/Draw分离为引擎原生Cull/Draw；120Hz物理、交通12车、车辆/碰撞参数不变。PBR仅保留实际使用的一束直射光，2048阴影图、4xMSAA、后处理和有效光源不变。
- 车身姿态/速度与接触状态重复读取合并；Bullet轮矩阵直接读取，避免临时TransformState进入全局缓存。三路形各2400tick快照对照：车身、位置、交通、事件、动力学等非轮转字段完全一致；6396个轮转对齐q/-q后最大分量差2.38e-7。原始逐分量比较因q/-q等价符号失败保留在日志，未将2.0的原始分量差当作旋转变化。
- 排水盖的道路投影按精确XY复用，每个36顶点Geom交还装配预算。地形按行筛选有效群落，种植缓存上限32项；完整200m段才进入渲染树，远景渐现和连续护栏遮蔽保持。
- T1：129项相关pytest、Ruff、三种子headless及两种子30秒弯坡物理通过。最后全局光槽精简后，另跑58项环境/外观T0通过。
- 三路形共12个真实固定视点，负里程、170m、830m及8.4km，几何/Geom数量与修改前相同；重开复用、菜单释放、海岸切换及车库生命周期通过。灯光8槽/1槽对照平均每通道差<0.0011/255；每张约105–230个像素超过2%差值，集中在树冠细小高光，全图逐像素≤2%检查失败并保留light-pixels.json。实际检查没有整体底色、密度或地形变化，不宣称逐像素完全相同。全局PBR光槽另作固定海岸驾驶视点及车库对照，分别52/5个像素超过2%（均为2073600像素图片），平均通道差0.000265/0.000048，保留other-pixels.json与原图。
- 固定镜头移动太阳覆盖的左路肩对照，HWY-04 /Draw与PERF-04 Cull/Draw采样像素完全相同，最大差0。沿用旧HWY-03绝对稳定阈值时本次为8.33/255且失败；同一个HWY-04资产/植被基线也为8.33/255，说明本轮没有增加该变化，不将历史阈值检查写为通过。
- 路牌两模型×四距离×24帧检查通过，保留国内牌面、公里牌与新群落植被。独立包仓库外海岸/弯道/弯坡启动、三场景20次重开及55件高速资源哈希通过。

诊断中的cull-draw单因素56.11FPS仅用于选择管线；后续追踪试测包含额外计时，不作为最终值。一份光槽试测第34秒切出窗口，无效；一份并行诊断误启动的试测主动终止，无性能结论。临时海岸截图探针在未推进PBR任务/已关闭Scene时失败，修正诊断流程后完成，不修改产品处理这些工具错误。
