## 已确认的错误和修正

真实短手动输入的径向位移差可分为轮心运动差与表面形状差。四轮累计差约-0.1715/-0.1648/-0.1403/-0.1352mm，轮心运动差只有约1e−7m量级；主要来自表面项。原Fn自旋半径达到约7.87e−5m，根因是沿悬架轴扫掠的见证点属于平移后的未加载包络，不能直接作为实际轮心的法向材料点。

`UnsprungGeometry.normal_offsets`从同一轴对称包络支持函数取法向梯度，`tire_ports`明确区分材料点端口和法向包络端口；正式Vehicle传入后一种。Fn的六个转子列严格为零，轮心/车身梯度保留，实际物理冲量/有限端口仍在唯一120Hz世界。没有通过设小量阈值清零、改质量/刚度/求解阈值或禁用碰撞处理。数学推导及适用边界见[径向共轭端口](../../../radial-contact-ports.md)。
