## 实际问题及修复

`component-bench-AB-r1`的A完成，B在制动释放初始化失败，未生成有效B结果。`component-bench-init-failure-r1`保存真实输入/30轮轨迹/原执行全部源码。轮端所需转矩小于容量，但原有限差分跨过静止/滑动分支，末端口残差2.975655e−5 N·m。固定容量端口改用精确分段导数，原方程/全部残差阈值/30轮上限不变。

`component-bench-port-comparison-r2`在同一保存输入上读取原执行源码与新函数：旧仍失败，新2轮通过，端口2.775558e−17 N·m，动量1.675867e−13 N·s，力4.858419e−12 N，局部能量2.709725e−14 J。其余依赖源码相同；仅台架采样覆盖的未激励分类另有非力学修正。

`component-bench-port-comparison-r1`在Windows路径归一化断言处失败，未运行物理对照；r2修复工具，原失败目录保留。初T0 r1为导入排序Ruff失败；r2 22通过。37项端口/台架/共同解T0通过。工具初次多括号在运行前被Ruff发现并修复，无虚构成功记录。

## 复现命令

各输出目录必须新建，不能覆盖原记录：

```powershell
.venv/Scripts/python.exe tools/physics/run_sim_double.py tools/physics/suspension_bench_check.py --output 新AB目录
.venv/Scripts/python.exe tools/physics/run_sim_double.py tools/suspension_bench_ui_check.py --height 720 --output 新界面目录
```

`raw-evidence.zip`含全部本节点日志、输入、完整记录、失败源码/轨迹与工具；`executed-model.zip`为最终实际执行的模型、UI与公式资产。`manifest.json`保存逐文件/归档SHA，`source.json`与`runtime.json`保留实际源码/SDK。示例输入`example-synthetic.json`可从高级参数导入，须先载入显式独立轮心工程模型再运行轮跳。
