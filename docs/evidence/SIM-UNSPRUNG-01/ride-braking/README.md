## 几何修复与失败

旧一般查询在真实25kg子步的后轮离开Box处返回未闭合支持间隙0.836775m；原严格检查拒绝并终止。r1未导出完整记录。r2捕获了可信纯数值失败输入，随后因目录提前创建而导出FileExistsError，未保存完整快照/信号；该工具错误修复，未补造旧完整记录。所有原工具字节及固定输入保留。

新Box剖面算法按真实支持函数、完整轮胎轴向包含条件、全法线锥上界及见证点证明距离，未能证明的构型仍使用一般凸体算法。没有捕获几何错误后返回估计轮荷、放宽1e−11m支持检查、改变材料/附着/碰撞/固定时钟。远处Box仅按真实支持AABB距离下界超过原查询范围时剔除。

两份实际失败夹具均在4迭代通过旧1e−9Ns/1e−5N/1e−9Nm门槛；本子步动量约1.42e−13Ns、力1.76e−9N、局部能量约5.03e−12J。primitive-comparison.json保存旧一般算法仍拒绝该输入与新可证明距离−0.004912831m；不宣称修复所有凸体输入。独立圆/Box解析距离、真实见证点和全空间支持方向检查通过。
