# 变安装位移 / 受载几何刚度

2026-10-15，基线b64be95，codex/simulation-fidelity独立树，合成部件与几何夹具。实现安装运动学子集，不等于完整K&C。主项目/共享环境/默认开关/公开包保持。

## 实际机制

四角`(q,弹簧增量,减振器增量)`通过保单调PCHIP得到部件压缩、当前运动比及其导数，端点外明确切线外推。弹簧力/切线由同一部件势能求导，含`ks·xs·rs′`几何项；减振器实际速度/力/热保持共轭，冻结法向切线含阻尼几何梯度。原34未知量/120Hz/唯一世界及残差门槛保持。

v3部件数据另带几何留出，插值节点不混入验证位置。每角9节点/8留出，合成二次几何的弹簧位置峰差31.25µm、减振器9.868µm，通过显式0.2mm门槛。它只验证位移，运动比/二阶导数是插值导出量，不冒称实测。错误几何留出拒绝，来源和范围随实际配置保存。

详细[推导与使用](../../../variable-installation.md)。实操沿用高级参数导入悬架台架，`example-synthetic.json`为合成示例，需先导入独立轮心工程配置再运行轮跳。F1按实际记录/配置显示当前模式，曲线模式明确区分参考材料刚度与总切线，旧记录公式和OEM缺失归属保留。
