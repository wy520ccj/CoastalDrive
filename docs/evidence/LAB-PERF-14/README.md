## 依据、实现与边界

先对原完整制动/实体凸起做重复量诊断，不改变查询；两组payload均与LAB-PERF-13逐字节一致。凸起测量阶段288个子步中，有限接触对象各请求115312行平面与非平面候选，每类36408行（31.57%）输入完全重复；制动48个子步17664行中5600行重复。初始化另列于原始诊断，不拿诊断耗时证明收益。

候选缓存由本次FiniteRadialContact持有，对应本子步新建的静态RadialRoads描述和固定配置。键包含中心/轮轴dtype、向量shape/strides与原始字节，保留正负零、相邻ULP和向量布局；没有空间量化或近似比较。只复用完全成功的候选元组，空候选也可复用；原EPA/网格异常向上传播，部分失败不写入缓存。

平面全缺失沿用原批量，部分缺失只用原行切片，不压紧或重排矩阵/向量。缓存内容只有数值候选，不含额外世界节点。每次仍按原表面/候选次序选择接触，重新计算up相关腾空帧、轮胎/力端口、材料、共同残差和能量账；返回数组独立，不暴露缓存数组。下一真实子步/道路描述新建缓存，不复用旧世界位置。

首轮完整ABBA显示纯平面约慢4%，缓存管理超过省下的计算。最终纯平面保留原批量路径，不建立候选字典/逐轮键；存在有限实体时才启用共同的逐轮复用。首轮原值、12次payload与当时源码保留，最终收益只采用最终实现的新批ABBA，不挑较快时段。

派生缓存采用cached_property，旧可信检查点无需新增字段即可重建。保存检查点时只在浅复制件中清空候选缓存（纯平面保留None），不清空原求解对象，也不把临时数据写入长期记录。真实保存/加载及全部数值字段复算通过。
