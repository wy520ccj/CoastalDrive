## 实现与保真

共同方程已固定为16个动量、8个轮胎力、10个有限端口残差。原每次np.r_通用拼接改为直接写入对应34维区间；3项差速容量同样直接组装，没有减少任何方程或修改运算。轮胎材料、有限传动、接触几何和原生陀螺仍逐项参与。

新增`unsprung_body_torque`读取本次实际四轮力、轮心力臂、反力和转子偏置，以原顺序执行叉积/累加/相减。原生角速度预测及3×3隐式陀螺求解继续使用原实现；120Hz、双子步、34变量、差分epsilon、Newton/线搜索/收敛阈值及能量账保持。

只有wheel扩展重编；其C文件删除新增注册行后与基线全文相同，既有lab_contact_native.h计算段是新文件的原文前缀。共同解从config_rear之后的Newton/差分/结果/能量账尾部全文相同。其余四个扩展、共享.venv与SDK未改；游戏源码/配置/入口不在改动范围。
