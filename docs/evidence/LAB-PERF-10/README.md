# 试验台Box六向支持与包围盒准备批量化

2026-10-16收尾，基线`c18179e`。本块减少真实Box包围盒和全局证明中的支持包装、单位矩阵及小数组准备；原物理模型、支持函数、筛选标准与精度保持。持续优化目标active。

## 实现与保真

`radial_box_bounds`按原算术计算六向真实支持和包围盒gap，原NumPy范数及`> wheel_radius+suspension_travel`筛选保留。`box_axis_supports`单独按Box证明所用的归一轴准备六向法线/支持点，同一构型内精确复用。未归一轴与归一轴的结果不混用，不跨子步缓存。

每个方向仍调用原`support_values`，符号、运算顺序及零符号保持；没有通过几何对称性近似推算另一个方向。静态只读单位坐标轴模板只用于原锥基构造，不持有任何世界状态；动态法线和见证点仍是本次查询的数组。

全局候选次序、距离证明、容差、52轮细化及NumPy sin/cos、一般凸体路径、真实中点/末点查询、材料/陀螺、120Hz/双子步/34变量/差分/Newton及能量账保持。只重编wheel扩展；原C文件去掉两行新增注册后全文相同，原头文件计算段逐字保留。其他物理源码、四扩展、共享.venv、SDK及游戏保持。
