默认车撞栏后的接触活动集发散；正式修复在低车身外廓沿运动方向前视100ms，仅决定是否以4个机械子步积分，撞击后保持1秒再恢复。没有时间缩放、瞬移、取消碰撞、吞异常或改变收敛门槛，Snapshot仍120Hz。空路240步完整输出核对保持。三车18组最终全部出现真实冲量且无异常，见`logs/play-repair-collisions-predictive-r3/`及最终原生库`logs/play-repair-collisions-rounding/`。

新决赛120km/h目标策略又发现严格末位舍入循环：原生连续分支缺少已有`shared_solution_result`的末六轮邻近表示搜索，报8.52651e−14。将同一现有搜索补齐到`joint_iteration_helpers.h`，原30轮/坐标验收保持。隔离构建后完整决赛101.525秒成功，再将同一个pyd复制进`src/`。原库在`logs/play-repair-native-baseline/`，最终库与构建中间件在`logs/play-repair-native-rounding/`。其他扩展未重编。

失败候选均未采用：分块法向修正、14维联合修正、64轮上限、撞后才细分、两拍前视、仅车身中心高度前视；完整旧日志仍在`logs/play-repair-*`。最终`joint_iteration.h`内容保持基线。
