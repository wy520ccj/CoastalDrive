# 生涯结算的车辆取景复用

2026-10-28，接续[区域撞后实测](regional-impacts.md)。实际剖析显示，山脊碰撞转结算的320.143ms最慢帧，含177.861ms更新与140.237ms绘制；其中车辆取景约161ms。此处处理这一项明确开销，高速继续驾驶时的持续积压另行定位。

## 修改

- WorkshopVehicle在同车、同角度、同投影矩阵与零件标记下，保存原二分取景所得的完整相机变换和镜头偏移。更换实际车模即清空；不同视口、焦距或标记独立计算。仍使用原网格、包围盒及13次投影算法，首次取景结果不改。
- 生涯车辆区域提取为同一个vehicle_box计算，实际页面和加载准备共用。生涯道路加载时，将真实预览放在hidden下准备取景和资源，正常绘制一帧后关闭预览缓冲。成绩和结果页面仍由原规则产生；未预造结果、改存档或驾驶状态。
- 镜头偏移以独立tuple保存。Panda的getFilmOffset返回值可能引用镜头内部数据，直接保存对象会被后续清零操作改写。

原生物理、120Hz、碰撞精度、车辆配置、追车镜位及美术资源保持；生产修改仅application.py和ui下workshop_vehicle/career_layout两文件。

## 失败与修正

首轮准备时额外清除了零件标记，又重新取景，导致车辆位置与原结算有偏差；取消该额外操作，沿原show→highlight(None)时序，首轮未作为最终画面采用。

首次完整相关T1为34过1失败，车库转动视角裁切回归暴露缓存偏移引用问题。临时诊断清缓存再计算可恢复；将回归检查的期望值也复制为tuple后，原缓存明确失败：期望0.03884的横向偏移被改成0。修为独立数值，保留原失败日志和新回归；未放宽车模完整显示阈值。

初始T0为8过/Ruff通过，使用了尚未修正的期望值引用，不能单凭该结果认定缓存正确。最终检查及实际窗口结果记录在下段与[result-framing.json](result-framing.json)。

## 实测范围

同玩家coastal-roadster、2509×1180、正常山脊生涯、原音频/默认本机环境，从静止控制到120米转向真实撞栏，原规则立即结算，记录5墙钟秒。全前台、0丢时，截图在计时结束后取得。该短测只覆盖这一正常触发流程，人工与长期性能仍开放。
