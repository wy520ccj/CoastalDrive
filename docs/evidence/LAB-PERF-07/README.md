# 试验台陀螺精确复用与重复末状态预测消除

2026-10-15，基线`bd65709`。本块只消除同一共同解内重复的原隐式陀螺计算，以及有限接触中随后被有限悬架结果覆盖的速度/姿态预测；持续优化目标active。

## 实现与保真

共同解内世界惯量和dt固定，以实际自由角速度的完整字节作为陀螺结果键。同字节输入仍对应同一原隐式陀螺公式；不同字节不合并，不量化，不跨子步或世界复用。每次自由角速度仍先由原力矩和原线性求解计算，缓存返回的冲量继续进入原动量方程和能量账。

有限接触有有限悬架末状态时，直接使用该状态提供的轮心速度和姿态；原来被覆盖的重复计算不再执行。没有有限悬架时保留原预测公式。中点/末点真实道路查询、有限悬架、材料和轮胎力均保持。

120Hz、两机械子步、34未知量、差分epsilon、Newton/线搜索/收敛阈值与能量计算保持。共同解从config_rear之后的全部求解/结果/能量账尾部全文相同，原隐式陀螺函数未改；其余源码和五个原生扩展SHA相同，扩展没有重编。共享.venv、Double SDK及游戏保持。

## 调用数及验证

施工前真实初六拍探针记录1692次陀螺输入，同一子步内614次输入字节重复，其中仅288次相邻重复。后续分析采样另一组六拍，原陀螺求解1692→1095次、NumPy线性求解3420→2823次、姿态增量1620→1080次。残差1692次、真实道路查询1122次、端口552次、原生力矩1692次保持。减少的是重复计算，未减少差分列或真实接触查询。

前分析复用LAB-PERF-06/profile-after，六核心源码和五扩展与本基线SHA一致；新旧配置/协议与初六拍完整快照摘要也相同。仅比较调用数，不用跨时段分析器耗时证明提速。

新增14项包括：12组有/无有限悬架、微小垂向正负运动及零输入的旧正式完整公式逐位对照；2组原生陀螺共同解检查确认同一解只计算唯一输入、下一独立解重新计算，且完整结果/能量账精确重复。18组额外旧/新求解输入也保持一致。

最终Double与普通SDK相关T0各49项、Double试验台31模块308项完整回归100.80s/Ruff通过，含真实记录保存/加载/完整复算、原失败子步、旋转网格边缘的原异常一致性及新增数值检查。初次正式检查仅因新测试导入排序被Ruff停止，pytest未执行；整理后以独立`*-final`目录验证，初始报告保留。
