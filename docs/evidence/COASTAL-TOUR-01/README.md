`summary.json`记录完整驾驶首末源码/SDK、实际请求/配置、逐站结果；三站子目录有原始记录与复核。初次驾驶/结算/总览PNG属于最终显示微调前版本。`before-final-display`保留两处旧显示源文件、SHA与最终差异，完整驾驶在最终微调后明确复用。

`checks`包括六次T0（含失败与修复）和最终两库完整相关T1，各76项及seed0/17/23通过；失败原因见任务包。`archive-manifest.json`记录81份原始证据的来源/字节数/原始SHA；`source-manifest.json`记录最终10个源码的LF SHA。清单与本说明不计原始证据份数。

本批不测量改装收益，不改变物理/默认调校/原生模块，不关闭原T2物理失败、实时和人工Gate。
