# CTRL-01 四轮制动与ABS

基线 `5bd5f88`。本功能通过四轮实际制动容量、轮转动方程和轮胎力改变运动；不直接改车身速度、轮速或横摆。功能自动部分已完成，本地提交范围包含本页证据；全阶段/人工驾驶未完成。

## 机制

单轮请求先进入独立压力执行器，再换算制动容量。归一化液压压力使用25ms设计时间常数；关闭ABS仍有同样机械液压响应。ABS读上一完整物理步的轮速/轮心纵向速度，用正制动滑移 `λ=(|vx|−sign(vx)rω)/|vx|`。控制利用液压响应期内的滑移趋势预测，按滑移误差调节增减压速率，保留压力范围/变化率和滑移死区。低于1.5m/s、无支撑或松踏板退出电子调节；机械制动与压力衰减继续存在。

[Bosch](https://www.bosch-mobility.com/en/solutions/driving-safety/antilock-braking-system/)说明四轮独立压力调节的原理；[MathWorks控制块](https://www.mathworks.com/help/vdynblks/ref/antilockbrakesystem.html)区分轮速反馈、控制输出和下游制动执行器。此处为通用设计控制器，不是上述产品复刻或实车标定。轮心速度/绝对轮速目前取仿真真值；真实轮速传感器、车速估计器与传动系拖曳控制留待后续。

两模式默认同一25ms制动器且ABS开启，菜单可独立关闭；困难仿真不会为了制造难度禁用车辆电子系统。成绩按新制动器版本、模式和ABS开关分区，历史成绩保留。

## 同条件A/B

水平独立Bullet平面，重力9.81m/s²，静置240tick后一次设置初速度和纯滚动轮速；之后严格120Hz推进，四轮状态每tick统计、每6tick完整CSV。A/B只改变ABS开关，液压时间常数、车辆、路面与命令完全相同。前四工况100km/h，倒车30km/h；停止条件水平速度<0.1m/s。弯中制动请求2°，split-μ左侧铺装1.1、右侧草地0.45。距离为水平路径积分，锁止轮秒为四轮锁止持续时间之和，不能等同于整车抱死秒数。

数据：[final-abs/summary.json](final-abs/summary.json)。低速锁止统计包含ABS退出后的1～1.5m/s区间。铺装前轴制动容量不足以触及轮胎峰值，不会凭空显示ABS介入；后轴减压使其恢复滚动。低附着减轻持续抱死后制动力利用更高，停车距离缩短。弯中制动B横向位移5.43→11.92m、最大绝对航向130.38→72.53°，但不能凭此认定稳态操稳完成。split-μ累计解卷绕航向变化A=390.56°、B=189.71°，B侧移约7.83m；仅看包裹到±180°的HPR会遗漏A转过一整圈，工具已补逐tick解卷绕和实际横摆率。单轮ABS没有解决横摆稳定性，ESC另立任务。

## 修订与失败保留

- `initial-abs` / `initial-abs-v2`：固定增减压速率原型。低附着虽减少锁止，压力过度释放后反复再建，距离71.612→81.495m。保留原CSV，不将这一结果作为完成证据。
- `trend-pressure-v1`：增加滑移趋势预测及与误差成比例的压力变化率，减少过度释放；上述表为真实运行结果。轮胎模型纯纵向峰值滑移约0.185/0.101/0.076（μ1.1/0.6/0.45），目标0.12是设计折中值，未声称真实轮胎标定。
- `legacy-actuator-migration`：接口接入、默认配置尚未切换时，对旧零迟滞/无ABS基线三场景各1200tick，共1804546字段实际差异为零。当前工具通过`--legacy-actuator`明确复现此机械A分支；新默认制动器的轨迹允许有机制导致的变化。
- `final-legacy-actuator`：默认配置切换后，显式选择旧制动器再测全部三场景，1804546字段实际差异仍为零。
- `ui-720` / `ui-720-v2`：真实ABS介入的截图断言失败；实际显示插值遗漏新制动字段，物理快照有状态但HUD读不到。保存截图及失败输出，修复后另存目录验证。
- `ui-720-v3` / `ui-1080`：插值修复后ABS介入已可见，但720p设置说明第五行被首按钮遮挡；改为四行操作说明并增加真实文字边界测试，最终两分辨率见`ui-final-720` / `ui-final-1080`，页面和HUD由实际快照渲染。
- `t1`：289通过、真实圈速重载测试1失败，启动/弯坡未执行。原因是新增物理版本成绩分区后测试仍读取旧键；修正为读取本场score_id并确认旧分区未写入。相关短测修复后通过，最终完整相关T1见`t1-v2`。
- 新空中制动测试首次把停转后的观测相对轮速与施力阶段制动转矩严格乘积判正，停止舍入得到约−1.8e−16W；随后改为验证实际转动能下降和车轮/车身总轴向角动量守恒。原有能量与求解阈值未改，空中轮仍通过真实机械制动停止相对转动，ABS不介入。
