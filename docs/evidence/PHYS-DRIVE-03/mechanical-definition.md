# 有限粘性限滑定义

本实现采用设计用速差耦合：τ=clip(c·s, −Tmax, Tmax)，c单位N·m·s/rad、容量Tmax单位N·m。小速差区为粘性反力，容量区仍允许滑动；没有静摩擦锁死或温度模型，参数不是实测。[MathWorks速差耦合](https://www.mathworks.com/help/vdynblks/ref/limitedslipdifferential.html)及[四驱中差模型分类](https://www.mathworks.com/help/sdl/ug/four-wheel-drive-testbed.html)支持区分速差耦合、开放和锁止机制；具体截断粘性律是本项目明确设计。

相对壳体轮轴速si=ωi+Ω·ai，ai来自本拍机械转向轴。前轴滑差s0−s1，后轴s2−s3，中差(s0+s1−s2−s3)/2。八维q=(Ω3, ωe, ω0…ω3)的端口梯度同时包含壳体与轮轴分量；广义作用为−τ∇s，前后轴/中差各自可配置。非驱动轴与非四驱中差在配置边界拒绝启用。

未饱和端口在同一隐式末状态消元：Mnew=M−dt·c·(Mg)(Mg)ᵀ/(1+dt·c·gᵀMg)。饱和端口施加固定±Tmax。每种分区沿用原有限离合、双向损失和制动约束，只有满足实际末状态本构律的分区才接受。接触导数也用这一分区的响应矩阵，不在求解后补限滑转矩。空挡中的车轮差速耦合仍存在，未建输入轴保持原边界。

总轮端矩包含原开放分配与限滑转移；Tires用这组真实转矩提交轮轴反力，独立机械账核对车身动量、四轮转子、曲轴、接触、制动、离合、齿轮损失和限滑热。每个限滑端口的单子步热dt·τ·s非负，Powertrain只按完整120Hz步累加子步热并读回最后子步滑差/转矩。没有第二套车速或差速器转速状态。

默认c/Tmax全为0，仍是开放差速。轴惯量未在本块冒充实现；下一块需新增实体轴速与储能方程。
