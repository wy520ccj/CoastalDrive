# 滚动接触力括根与主线整合

原二维Newton在真实两米落体的非单调轮胎曲线非零残差谷底失败。原解析Jacobian与有限差分一致；纯减半步长、最佳减半点、残差方向限制、重算线性预测及混合局部求解均未完整解决，未接入生产。预测脚本前三轮还漏接vehicle_tires导入别名，结果不作为候选实现测试；修正后的失败也保留。

滚动接触力现在按实际摩擦峰值给Fx/Fy括根，先解固定Fx的横向同一残差，再用Schur导数a-b*c/d更新纵向，Newton点离开括根区间时取中点。只裁剪求解初值，未裁剪最终力；完成标准仍为原hypot残差<1e-4N。20纵向迭代、每次最多20横向迭代；这是新的求解安排，不声称与旧20轮二维Newton轨迹相同。非滚动分区继续使用原二维Newton；共同20轮、端口30轮、法向/能量/几何精度、120Hz和硬件保持。没有异常捕捉后切换物理。

真实落地A/B两秒全轨迹保留：77拍首次有轮接触，79拍四轮接地，99/100拍起回弹，125/126拍再次四轮接地；两秒末四轮都支持。旧测试恰好1秒终态接地假设不成立。测试改为两秒并要求最后60拍所有四轮持续支持，CSV仍检查真实动态接点。
