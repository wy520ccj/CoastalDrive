## 实现

- 继承计算成果：交通感知只取车身快照、道路精确有界缓存、地形索引网格、重复UI写入跳过。正式快照仍有四轮；120Hz物理、交通决策、碰撞和驾驶参数保留。
- Scene消费分段步骤，驾驶时3ms软预算；地形/山体逐行，设施逐项，草木按20m局部原生合批。整段完工后才挂入。仍沿用1200m物理装卸窗口；取消、反向、重定位和菜单释放有回归检查。实际最大单帧装配约13.86–15.10ms，最大原子步骤约12.19–14.17ms，不宣称硬3ms上限。
- 引擎原生/Draw把绘制提交放到第二线程，物理与游戏逻辑留在主线程。修正重开场景时的同步补齐入口，使其只在加载阶段执行；不会每帧重新走同步整段生成。
- 高速远山、地形和海面350–850m空气透视，850–1050m渐隐；草木430–560m渐隐，整组700m才裁剪。共享原天空的地平线色，未换天空素材，避免云纹混到山面。16级固定屏幕覆盖图样没有随机时间噪声，保留原不透明深度。
