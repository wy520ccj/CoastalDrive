# PHYS-MODES-01 两模式与通用参考车

本批基线为`38f2a86`。共用120Hz/Bullet/四轮物理，配置与驾驶输入分别贯通Vehicle、Simulation、Session及交通生命周期。正常游戏保留原曲线和输入；困难仿真选用原始设计发动机曲线、显式惯量、零额外车身角阻尼，关闭游戏车速/倒挡力渐退及三个键盘便利策略。困难仿真仍采用当前简化发动机/离合、射线悬架与无松弛轮胎；本批完成模式与参考参数接口，整体物理完善目标继续。

主菜单F2或右下角驾驶模式按钮进入设置，原六个主菜单动作保持。困难仿真Q请求R、E请求D，S仅制动；前进挡仍自动换挡。模式只能在主菜单选择，起步重建世界。参考车与正常游戏计时成绩分开，原正常游戏成绩键保留。NPC共用所选车辆参数，明确使用GAME_INPUT交通映射；控制生成与车辆解码使用同一参数，玩家仿真输入使用SIMULATION_INPUT。

## 参数与原模式等价

- [完整参数表](../../vehicle-reference.md)与[冻结JSON](reference-parameters.json)覆盖53个车辆字段、9个输入字段、单位/设计来源、真实几何及两模式静置240tick的Bullet读数。所有车型数值为设计或设计推导，尚无真实车型测量数据。
- [迁移前基线](normal-baseline/metadata.json)：test无交通、coastal两车、endless弯坡两车，各seed23/1200tick。逐tick玩家/NPC姿态、速度、四轮轮速/接触/力、事件及输入完整保存。
- [迁移后对照](normal-migration-current-v2/summary.json)：分别比较262592、770978、770976个字段值，合计1804546；所有实际数值差异为零。比较器对几何读回允许有限float32误差，但本次没有使用该容差。
- `normal-migration-current`保留比较器首次失败：Python tuple与JSON list未统一类型造成误报；v2规范化序列后通过，原基线未覆盖。

## 标准工况与理论A/B

[正常游戏输入](standard-game-driver/summary.json)、[参考车输入](standard-reference-driver/summary.json)、[参考车直接执行器](standard-reference-actuator/summary.json)均保存七工况CSV与配置/源码哈希。GAME与SIMULATION的同一归一化转向量经不同输入包络会产生不同请求，不能将两者转向响应差别只归因于轮胎。研究执行器输入的阶跃与弯中制动采用2°中心齿条请求，定圆采用atan(L/R)，实际齿条仍受同一机械响应及角速率约束。

直接执行器与相同车辆配置的跨输入策略测试180tick逐帧严格一致。三组参数研究用独立水平面Bullet世界、相同指令和120Hz步进，制动初速度及滚动轮速只在试验开始设置一次，运行中无速度/轮速校准。

| 机制变化 | 旧A | 新B | 理论与实测 |
|---|---:|---:|---|
| 单轮惯量1.8→3.6kg·m²，全油门12s末速度 | 31.6279m/s | 30.7409m/s | 四轮转动等效质量由66.12→132.23kg，受力相同情况下加速更慢；路径223.05→215.71m |
| 质心0.42→0.62m，20m/s起始/.45制动/2s，末0.5s前轴增载 | 1029.13N | 1515.54N | 真实Bullet前轮Fn增加；增载比1.473接近高度比1.476，平均减速度4.39760→4.39737m/s²基本相同 |
| 铺装μ1.1→.6，100km/h全制动至水平速度<.1m/s | 44.2178m | 71.2814m | 附着下降，平均减速度8.70481→5.33215m/s²，停车时间3.1833→5.1917s |

[参数研究完整读数](reference-ab/summary.json)与六份轨迹CSV记录实际轮载、轮速、滑移及制动力。质心试验使用相同制动容量，未达到附着饱和，隔离了载荷转移方向；准静态ΔFn≈m·|a|·h/L只解释趋势，未作为实际轮载的替代值。当前无ABS的全制动允许真实轮抱死，摩擦幅度尚未由实车数据标定。

## 验证

- T0：车辆配置/动力总成/轮胎/原操控/接触/道路目标84项通过；模式生命周期与试验工具9项通过；参数方向3项通过。
- [T1](t1/summary.json)：236项pytest、Ruff、三种子headless和0/23种子弯坡30s全部通过。新增参数方向与研究驾驶器配置反解在其后完成，完整T2将覆盖最终源码。
- [参考车弯坡seed0](reference-hills-0.json)、[seed23](reference-hills-23.json)：各30s、12车，无碰撞/驶离道路，原6.9m/15°等检查不放宽。研究驾驶器按玩家当前配置及输入包络反解请求。
- [720p实际渲染](ui-720-v2/summary.json)与[1080p实际渲染](ui-1080/summary.json)检查主菜单、模式设置及仿真倒挡HUD；Q/R真实运行速度−4.323m/s，模式/倒挡/制动说明可见，文字未溢出。`ui-720`保留首轮截图脚本错误：误向应用启动接口传countdown参数，修正为实际启动与倒计时后在新目录完成；未改产品接口。
- `source-start.json`记录完整T2启动时src/tests/tools所有Python文件SHA；T2运行期间不修改这些文件。T2当前运行中，结束后保存完整结果与结束哈希。

本批未运行T3、可见窗口性能Gate或人工驾驶验收，尚未新增ABS/TCS/ESC。下一功能先在同样试验条件下增加单轮制动执行器与ABS反馈，观察真实轮速/滑移/横摆响应。
