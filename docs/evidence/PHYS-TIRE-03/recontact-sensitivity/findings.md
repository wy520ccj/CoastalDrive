# 再接触子步/ABS隔离

只新增运行ABS on4/on16与off2/off8四条simulation、airborne-recontact、6秒轨迹。ABS on2/on8引用已有substeps轨迹，引用原始文件与summary的SHA写入本目录summary。TCS/ESC均保持on、柔性on，其余完整参数不变；新运行前后源码SHA一致。脚本随后仅增加对已保存CSV的commanded−requested后处理，后处理脚本SHA另列，没有重跑物理。

on2→4航向−0.045299°、路径+0.083390m；on4→8航向−4.977148°、路径+0.801855m；on8→16航向−0.028053°、路径+0.029432m。因此on2/4与on8/16落入不同结果分支，不能声称2→8已有整车子步收敛。关闭ABS后2→8航向差收缩至+0.412387°、路径−0.015456m，但两者本身累计偏航更大；此处不把关闭ABS当修复。

on2/on8逐tick最早分叉：ABS commanded（以及commanded−requested）tick77/0.641667s；完成步yaw tick80/0.666667s；施力轮荷左右差tick97/0.808333s；ABS active分支tick166/1.383333s。tick77前轮命令约0.620037与0.620056，尚属很小差异。on2前轮首次完成接触采样tick75，施力轮荷tick76才使用该接点；后轮首次采样tick82。这些字段时点不能混用。

off2/off8完成步yaw最早分叉tick80；轮荷左右差tick104；总brake commanded tick82分叉，但ABS均未介入、commanded−requested始终没有分叉，因而该off命令差不能称ABS调压。ESC仍on，分轮请求可继续变化。

由隔离证据推断，再接触产生的小响应差经ABS/ESC反馈与接触演化放大，ABS相关分支对最终差异有明显影响；现有证据没有唯一定位到某一ABS规则，也不能排除碰撞/接触本身的敏感性。最早yaw变化发生在轮荷左右差出现之前，所以不能直接把后续轮荷不对称当最初原因。能量账本与求解残差良好不替代整车子步验收；该异常保留为明确限制。

数值首分叉采用1e−9仅作为观察截断，没有新设验收门槛。全tick原始CSV、完整配置、各能量项、引用SHA与执行账目见summary.json。
