# 初轮发现与修正

保留失败及中间证据，最终验收另列。

首轮全仓[T2](t2/summary.json)pytest超过1800s墙钟额度并被入口标记timeout；此前擦碰音频集成测试已出现失败，其余14项检查为not_run。261个src/tests/tools Python在该轮前后SHA一致。单独[擦碰T0](rail-contact-t0.log)复现：原初值及恒定2°方向输入下，碰撞分层播放一次，但刮擦attack为4而非1。先观察真实manifold/持续接触及音频候选门槛，再决定修正；不把首轮超时或失败计为通过。

1. 单轮顺序柔性积分的真实5°坡停10秒位移0.0331866m，超过原0.01m门槛。分子步外力时序修正后仍为0.0155513m；不能仅凭单轮能量正确关闭整车问题。改为四轮共末速度求解，同一车体末速度上满足四轮接触和干式制动约束，收敛后才提交真实状态，原位移/步位移/坡面真实受力门槛通过。
2. 共末速度刚性制动的初轮误差产生约−2.6e−7W制动功，违反已有−1e−7W数值门槛。统一双精度正交接触基、对称惯量响应，收紧制动互补残差；保持原能量/制动功门槛，不钳负功。
3. 启用弹性后旧直接轮胎制动测试出现约0.00753m/s短暂回弹。原刚性单调停车测试以显式关闭柔性配置保留；增加柔性机械+弹性总能量及制动功检查，允许由已有储能产生的真实回弹。
4. `vehicle-t0-initial.log`：69通过、2失败。新整车低速制动测试使用正常游戏输入，按住S/刹车0.4秒后会实际请求倒车，末速度约−0.79m/s；它不能检验保持制动的停车。改为`SIMULATION_INPUT`直接制动，保留0.01m/s和轮轴相对角速0.01rad/s门槛，`braking-command-t0.log`两项通过。未改游戏倒车延时或轮胎停车阈值。

`component-scan/`记录当时单轮模型2025样本与三条各240步序列；它早于四轮共同求解和最终默认开启。原始数据与源SHA保留，不能替代最终整车或四轮账本验证。

## 全轨迹审计工具校正

初版审计报告保留为`trajectory-audit-initial.json`；其道路耗散汇总未填值，且Windows路径分隔符造成生成源SHA与审计SHA的路径键不匹配。修正脚本后仅重读原始vehicle-ab/substeps CSV.gz，生成`trajectory-audit-corrected.json`：道路耗散保留原符号并完整统计，源路径统一POSIX格式后比较72个src文件SHA，两个矩阵summary的src前/后SHA均与审计开始时相同。力求解tick与Bullet观测tick差值−1至0是正常阶段偏移，单独留统计，不列为违规。原始物理CSV、src、tests、tools均未修改。

## 有符号路面功最小样本定位

更正轨迹审计中的最小`road_dissipation`为−5.979554443689232e−6J，来自`substeps/game-airborne-recontact-2.csv.gz`第471 tick、轮0；该字段是每body-tick内2个轮胎子步的累加值，保留原始有符号数。此时force_contact_tick=470、sample_tick=471，`force_mode=compliant-sticking`，Fn=4018.0458984375N、force_grip=4284.351708230524N、Fx=−3215.0600192140673N、Fy=−0.04382356097217538N，原求解残差0.0008192666026920676N。施力阶段接触片滑移为κ=2.2252963587966745e−7、α=4.523958043361867e−7；求解时车轮纵/横向速度为0.12698259949684143/3.3207470551133156e−6m/s。该工况配置K=150000N/m、b=1000N·s/m、tire_substeps=2，body dt=1/120s，子步dt=1/240s。

低速sticking理想路面速度为零，有限接触残差ε会使`|vp|≤ε/(Kh+b)`；故每子步负功幅度受`h*(D+ε)*ε/(Kh+b)`限制。使用该tick冻结轮荷的抓地预算D=4284.351708230524N及原ε=0.001N，可给两个子步总和的保守界`dt*(D+0.001)*0.001/(K*dt/substeps+b)=2.1971039529e−5J`。实测负路面功幅度约为该界的27.22%；使用预算而非最后子步的实际力幅度，是为了覆盖tick内两个子步。此估算不改变0.001N原残差门槛。路面功为有符号接触账目，故不得概括为“全部物理耗散非负”；本次材料、弹性数值与坐标耗散各自保持非负。
