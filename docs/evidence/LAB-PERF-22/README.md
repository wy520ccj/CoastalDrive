正式实现JointJacobianHint：previous是本次原始输入矩阵，current是本次成功求解的独立输出。矩阵以未缩放物理坐标保存，进入当前共同解时按state_scale/row_scale换算；不带入旧轮荷、材料、接触点、残差或车辆状态。矩阵只给搜索方向，原完整残差/精确有限端口行决定当前候选是否下降，旧方向失效时仍重建当前差分。

每个车辆独有一个数值种子。创建导向、重置和initialize_rolling清空；配置对象、dt、传动比或同步状态变化时不带入。新的UnsprungAdvanceInput持有独立hint；合格求解后由commit路径发布current供下一子步使用，不修改previous。输入矩阵不被求解器改写，输出矩阵只读且存储独立。没有跨车辆/世界共享方向矩阵。

可信单步检查点保存previous，清除派生current。输入和输出分开，加载后重复求解使用原输入种子；旧检查点缺少新增可选字段时由原数据类默认None维持冷启动。未把UI/场景/快照当作物理或算法状态来源。

jacobian_updates=False继续原完整中央差分Newton，不使用种子。默认的34维方程、每轮精确有限端口行、当前真实几何、Broyden更新/重建、原30轮/12线搜索、合格校正及动量<1e−9 Ns/力<1e−5 N/端口<1e−9 Nm门槛保持。Newton循环AST完全相同，原evaluate/configuration/velocity_terms和最终能量段保持；本块只在循环前换算种子、循环后导出矩阵。
