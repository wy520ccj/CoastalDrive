- 安装版：按当前用户安装，开始菜单游戏/实验台入口、可选桌面快捷方式、标准卸载器。

- 包含Python/Panda3D/NumPy、普通精度游戏与实验台、运行资源和许可证；无需安装开发环境。
- `coastaldrive-check.exe`供技术排障，自动打开测试窗口并运行实验台往返；日常玩游戏打开`coastaldrive.exe`。
