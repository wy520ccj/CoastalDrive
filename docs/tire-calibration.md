# 轮胎部件标定

当前入口拟合稳态轮胎Fx/Fy曲线，使用生产物理的同一个`tire_force`函数。只识别六项：指定轮胎/表面的有效参考附着μ、固定基准下纵/横刚度、峰值/纵刚度/侧偏刚度三项负荷指数。固定轮荷基准、形状/曲率以及胎面弹性/阻尼/轮轴惯量；不能凭稳态数据宣称辨识瞬态参数。

| 参数 | 数据中的可辨识信息 | 工程用途 |
|---|---|---|
| μ | 参考轮荷附近的峰值力 | 指定轮胎/路面条件的极限制动/联合附着；不是可跨表面复用的纯路面常数 |
| Cκ0 | 小纵滑移的力斜率 | 制动/驱动滑移、ABS目标附近响应 |
| Cα0 | 小侧偏的侧向力斜率 | 转向与前后操稳平衡；本输入声明同一套四轮轮胎，后轴采用同一部件基准刚度 |
| pD、pκ、pα | 不同轮荷下峰值/斜率变化 | 空载/装载及转弯左右轮荷变化的复用；固定Fn0，整车质量不进入轮胎基准 |

完整序列分割拟合/验证，不能将同一序列拆到两组。拟合只用纯纵/纯横；联合滑移留出不参加优化。两轴分别至少三个轮荷、最大/最小≥1.5，每个轮荷需正负、小滑移≤0.003与峰区覆盖（纵≥0.15、横≥0.10rad）。这使刚度、峰值与载荷指数有分开的信息来源，不能仅用停车距离同时调整六项。

条件文件声明轮胎ID、表面ID、胎压kPa、温度°C、速度m/s、零外倾、稳态和同套四轮安装。当前不拟合胎压/温度/速度依赖或外倾推力；系数只在声明条件及数据范围内验证。κ驱动为正，α车轮局部右向为正；正α产生负Fy。外部数据须先按此约定转换，不能只改列名。

## 输入和运行

CSV必须按下列字段顺序，Fx/Fy为轮胎局部力N：

```text
series,split,kind,fz_N,kappa,alpha_rad,fx_N,fy_N
```

`split`为train/validation，`kind`为longitudinal/lateral/combined；同序列同轮荷同工况。每种验证工况至少四点。|κ|≤2、|α|≤0.6rad；支持的输入是稳态无外倾测量，不把瞬态完成步滑移率直接当台架稳态数据。完整条件样例见[合成条件](evidence/SIM-TIRE-FIT-01/accepted/conditions.json)，标明source_kind=synthetic，不能作为实车或轮胎厂测量。

```powershell
.venv/Scripts/python.exe tools/physics/fit_tire_bench.py --csv 台架.csv --conditions 条件.json --vehicle reference-rwd --output 新输出目录
```

工具保存原始输入/条件、SHA、预测CSV和fit-report.json。在缩放参数上用阻尼Gauss-Newton最小二乘；按Fn及序列点数归一化拟合残差，使大载荷/密集序列不单独支配目标。基准/形状固定，不通过新增自由参数强行拟合。

验收检查收敛、六列Jacobian满秩、条件数<1e8、参数未碰公开边界，以及每类拟合/验证的向量误差RMS≤5%、单点≤10%。误差除以**该原始序列的观测力峰值**，不能靠增大拟合D降低验证百分比。这些是公开的本工具质量条件，不是轮胎企业或法规统一合格阈值。Jacobian秩/条件数不是统计置信区间。

搜索边界随报告导出：μ0.05～3、基准刚度1000～1e6N/滑移单位、峰值指数0.4～1.5、刚度指数0.2～1.8。超出边界/未通过时保留失败报告并退出2，不写可应用候选。报告是模型适用性判断，失败后应补信息或更换有依据的模型，不移用验证点重新拟合。

通过后生成candidate-vehicle.json。实验台“记录 → 导入工程模型”可载入，随后开始试验；载入本身不建物理世界。切换车型清除工程覆盖。F1显示实际参数、来源分类和条件；待运行参数、旧试验配置区分。完整配置和来源保存到记录；复算从保存配置恢复，不重新读取可能被修改的候选文件。来源元数据捕获副本，固定A后不会受调用方后续编辑影响。

当前只提供**合成算法验证候选**，没有实测拟合的车辆版本。示例用于演示输入/识别/拒绝/应用链，不更新任何默认车型。原生文件选择对话框和人工体验仍待确认，自动GUI验证使用公共文件导入接口。

## 证据与依据

合成独立公式、3N扰动恢复、刻意错误联合留出拒绝、解析小滑移瞬态核核对、实际整车A/B/复算和720/1080渲染见[证据](evidence/SIM-TIRE-FIT-01/README.md)。这些验证算法与既有模型的兼容性，不能作为实测精度证明。

[CarSim数据来源](https://www.carsim.com/products/carsim/data.php)将轮胎力/力矩台架、悬架K&C及质量惯量列为车型数据来源；[MathWorks轮胎参数化](https://www.mathworks.com/help/sdl/ref/tiremagicformula.html)说明实验数据拟合及柔性、惯量、滚阻等机制。此处使用自有代码和数据，不复制其示例系数，也不把现有简化曲线称为完整商业轮胎模型。
