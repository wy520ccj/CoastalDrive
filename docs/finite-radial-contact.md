# 有限径向接触与材料力

本节点修复真实凸起边缘的接触特征切换。原生产链沿悬架轴扫掠，然后在子步内冻结压缩梯度；轮心从地面驶上实体Box时，实际末压缩已经改变，共同求解仍预测旧地面。旧记录的单步径向储能差约8.028J。调整轮胎刚度或阻尼不能修复这个几何错误。

## 几何与唯一物理世界

`radial_geometry`只读取Simulation已有静态道路的顶点、形状位置及四元数，不创建刚体或推进另一套状态。轴对称胎冠支持函数与既有包络一致。有符号距离负值表示压入，径向压缩为负距离。无限Plane解析计算，有限Box/凸壳/三角形采用双精度GJK/EPA；多个支撑候选取最大真实压缩。有限Box平面内部按支持点投影核对特征，边缘仍按实际凸体查询。

新的C++扩展只执行几何查询；原生Bullet动力学仍为原有精度。它使用独立双精度编译单元，不向Panda传递Bullet对象。私有EPA副本保留Bullet许可并标明改动：扩展容量与索引宽度、补偿叉积、相对面积判据、收紧面可见性精度。穿透结果另核对支持间隙，未闭合直接报错；不回退到旧扫掠值。目标构建命令为 `.venv/Scripts/python.exe tools/build_radial_contact.py build_ext --inplace`，setup也包含独立扩展和打包入口。

## 同一末状态与功

共同求解的16维速度前十维为车身/轮心，其后为传动/自旋。每次残差评估以轮心初位置加步长乘末速度，以及末角速度的旋转指数查询试探末接触。真实积分仍由唯一原生世界执行，预测量不覆盖世界位姿。

中点包络支持点决定子午线力臂 $k\mathbf a_m$。令 $\mathbf v_s=\mathbf J_0\mathbf z+\boldsymbol\Omega\times k\mathbf a_m$，空间离散梯度为

$$\overline{\mathbf n}=\mathbf n_m+\frac{-(\delta_1-\delta_{\rm target})/h-\mathbf n_m\cdot\mathbf v_s}{\|\mathbf v_s\|^2}\mathbf v_s.$$

只在存在末接触且运动非零时使用该式。同一平面直接计算小位移和包络高度割线，避免近似等深度相减；没有钳零小速度或放宽共同残差门槛。令 $s=\|\overline{\mathbf n}\|$，单位施力方向为 $\mathbf n=\overline{\mathbf n}/s$。材料系数力、实际施力大小和储能为

$$F_n^*=\max\left(0,k_r\delta_++c_r\frac{\Delta\delta_+}{h}\right),\quad F_n=sF_n^*,\quad U_r=\tfrac12k_r\delta_+^2.$$

虚功满足 $\delta_1-\delta_0=-hs(\mathbf g_n\mathbf z+v_n^{\rm steer})$；材料储能使用系数力乘压缩增量，实际冲量使用实际力乘单位端口。s由几何计算，是离散梯度范数，不是可调增益。它在平面无旋转极限等于1；接触切换时方向表示有限步的平均功方向，不能称为瞬时几何法线。六个转子列为零，轴对称自旋不改变包络。

指定转向改变轮轴包络，其功显式归属于执行器；静态凸起没有虚构道路输入功。轮荷、摩擦预算、滚阻、切向材料变形和实际提交均使用同一末解。轮胎系数、质量、120Hz主时钟、真实碰撞和原1e−9Ns/1e−5N/1e−9Nm求解阈值保持。

## 工程意义与边界

修复使凸起轮荷变化来自实际轮胎压缩并进入制动预算，研究簧下质量、径向刚度、接地变化和颠簸制动才有物理意义。40kg、200000N/m、500Ns/m仍为设计假设。企业标定需要部件加载曲线、轮端质量及相同工况实测轮荷/车身响应，不能依据残差改善把参考车称为实车模型。

实际2.4s凸起的2子步峰值由8.028213J降为0.003230560J，累计残差仍−0.057585769J。4子步峰0.002997459J、累计−0.084126503J。有限惯量、原生导向/浮点误差及完整收敛仍开放，局部共同账约1e−10J不代替全车验收。默认簧下开关继续关闭；实际制动A/B、实测、人工与整体Gate未完成。执行版本及细化见[证据](evidence/SIM-UNSPRUNG-01/finite-contact/README.md)。
