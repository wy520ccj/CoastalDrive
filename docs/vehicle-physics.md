# 车辆物理参数与后续模型

本轮参考用户提供的《汽车理论》第 6 版符号表，优先采用会改变驾驶结果、可以验证的量。符号表说明物理量及单位，不提供这辆游戏车的实测参数；当前数值仍是游戏调校，不能当作某款真实车辆的标定。

## 已有且继续保留

- 质量 1200 kg、轮胎半径 0.33 m、发动机转速与扭矩曲线、五挡速比、主减速比、传动效率；发动机功率由扭矩与角速度决定，无需再设一个互相矛盾的固定最大功率。
- 渐进油门/刹车、扭矩响应、自动换挡中断、发动机制动、倒车延迟。
- 轴距与轮距控制四轮位置，车辆运动由 Bullet 刚体与射线悬架计算。键盘转向有连续响应及高速转角限制。
- Bullet 已产生重力、坡道下滑、俯仰/侧倾、悬架压缩回弹及刚体转动。没有再叠加一套平行的车身运动方程。

## 本轮接入实际计算的量

以下表记录道路载荷阶段的实现；2026-10-01轮胎接管后的受力与单位以文末“独立轮速与两个模式”为准。

| 量 | 当前处理 | 对驾驶的作用 |
|---|---|---|
| 空气密度、风阻系数、迎风面积 | `F = 0.5 ρ Cd A v_rel²`；默认 1.225 kg/m³、0.32、约 2.14 m²；支持固定风速向量 | 相对空气速度越高，阻力越大；逆风降低实际加速能力 |
| 滚动阻力系数 | 柏油约 0.0136，路肩/草地约 0.0765；按估计总法向载荷计算，低速平滑衰减 | 草地更费力，松油减速有质量及坡度关系 |
| 轴距、轮距 | 2.2 m、1.68 m，作为共同轮位参数 | 轮位与转向包络使用同一轴距 |
| 重心高度、前轴静载比例 | 0.42 m、50%；准静态载荷转移约为 `m h (a + g sinθ) / L` | 加速后移、制动前移；改变前后轮可用纵向力 |
| 路面附着系数 | 柏油 1.1、路肩/草地 0.45；每轮纵向力上限为 `μ Fz` | 后驱动力和制动力不能无条件超过可用附着；离地轮不施加驱动力 |
| 车轮总制动转矩、前制动份额 | 3643.2 N·m、60%；换算轮周力，再按 1/120 s 转换为 Bullet 制动冲量 | 前后制动力有分配，实际刹停距离随附着和轴荷变化 |
| 横摆角速度、质心侧偏角 | 从刚体状态计算，F3 可查看 | 用于之后的操稳分析与训练观测，不另外作为力重复施加 |
| 坡度阻力 | `m g sinθ` 仅作诊断量；实际坡道力来自 Bullet 重力 | 避免同一坡度阻力算两遍 |

风阻面积与滚阻数值由原先的 0.42 和 160 N / 900 N 阻力调校转换而来，目的是保留已认可的驾驶手感。前后轴荷是用于限力的准静态估计，受力后约 0.15 秒平滑；不是四个真实轮胎接触力的测量。`road_grip` 等 Bullet 悬架/抓地参数也不是这里的物理附着系数，不能混用单位。

F3 显示风阻、滚阻、轴荷估计、横摆角速度与侧偏角。固定风速目前通过 `Simulation(wind=(x, y, z))` 设置，没有增加天气菜单。

## 暂不加入的量

- **油耗率、百公里油耗**：当前没有续航或经济驾驶玩法。等有能耗目标，再使用发动机效率图和燃油模型。
- **完整侧偏刚度、轮胎侧偏曲线、滑转率控制、转向不足系数、ABS/ESC**：值得作为下一轮物理专项。需要轮速状态、轮胎曲线与实测/目标数据；当前纵向限力不等于 ABS，也不是完整摩擦圆模型。
- **簧上/簧下质量、弹簧 N/m、阻尼 N·s/m、固有频率**：当前 Bullet 射线悬架已有回弹。不能把教材 SI 参数直接塞给 Bullet 的归一化刚度字段，也不能把没有独立轮胎刚体的实现称为完整多体悬架。
- **路面功率谱、座椅振动和人体舒适性指标**：需要路面扰动和舒适性玩法后再加；不会用无依据的随机抖动冒充真实颠簸。
- **土壤黏聚力、沉陷指数、剪切变形、胎压与接地面积**：是软土越野的专用模型。当前是硬路面和路肩，不实现土壤变形，因此不添加空参数。

## 2026-09-30 道路载荷与接触测量

道路坡度改为支撑接触法线在车头方向的坡度，不再使用车身俯仰。载荷转移的加速度沿道路切线求得，仍保留0.15秒平滑。无支撑时坡度为None、准静态载荷为零；坡度阻力仍仅作诊断，不重复施加重力。

`CarState.wheel_contacts`是最近一次完成的物理步中四轮只读测量，`contact_tick`为该车自reset后的采样步数。初建/reset时空tuple表示没有有效测量；空中轮有明确的未接触状态与零载荷。新模块`vehicle_contacts`处理读数和坐标重定位，快照插值保留最新测量时刻。

`normal_load`为沿接触法线的实际支撑力N，`suspension_force`为截断前原始悬架力N；世界竖直分量另由法线z分量得到。悬架长度与压缩量单位m，skid为Bullet无量纲摩擦缩减系数，不能代替κ。诊断只用于观察和标准试验，尚未替换准静态纵向限力。

A/B、定圆、阶跃、弯中制动和split-μ数据见 [测量基础报告](evidence/PHYS-03/README.md)，后续路线见 [物理完善路线](physics-roadmap.md)。

## 车型差异的边界（2026-09-28确认）

用户允许不同车型使用不同物理性能参数。车型参数归 vehicle_config，Vehicle、VehicleResponse 与 Simulation 仍共用一套实现；不能通过不同 Scene、显示缩放或按键控制分支伪造性能差异。接入时由游戏在创建/重建 Simulation 时明确传入车型配置，车库预览不推进或偷偷修改当前世界。

VEH-01 本次仅确认这一许可，未接入按车型选物理参数，也未臆测真实经典车的质量、扭矩或操控。当前车型仍使用既有已验证参数。下一参数任务应贯通 VehicleConfig → Vehicle/VehicleResponse（包括 reset 和轮心），保留默认配置回归，并单独验证各车型加速/制动/转向/外廓；不复制第二套物理、不预建车型框架。

## 2026-10-01 输入与执行器

当前VehicleResponse已按功能拆为driver_assist、powertrain、vehicle_steering。DriverAssist处理驾驶输入便利行为，SteeringRack保存实际虚拟前轴中心转角/角速度与机械限制，Powertrain保存发动机、自动换挡和转矩响应。Vehicle.apply_command是统一受力入口，apply_control先做辅助再调用它。

研究控制使用`vehicle_state.VehicleCommand`，steering为度、throttle/brake为0～1、direction为−1/0/1。`Simulation.step`接收Control或VehicleCommand，仍只有一个120Hz世界；输入策略与车辆参数分别配置，两模式在共享核心上选择各自配置。ARCH-01当时默认七标准工况1168×117列完全一致，见[ARCH-01](evidence/ARCH-01/README.md)。上节车型配置授权在这些新职责间贯通，旧模块名只记录当时背景。

PHYS-04实际前轮已使用Ackermann，steering表示虚拟前轴中心角，左右真实角分别由轴距/轮距计算。中心角限制与输入包络保持，内轮角高于中心角、外轮低于中心角。低速定圆与真实前进/倒车方向见[转向报告](evidence/PHYS-04/README.md)。

## 2026-10-01 独立轮速与两个模式

当前四轮独立转动由`Tires`持有，每轮Iw1.8kg·m²、半径.33m；驱动/制动单位为轮端N·m，实际轮速由`Iw Δω=h(Td−Tb−rFx)`与三维刚体冲量联合积分。车体右轴与向前滚动的轮转子角动量方向相反，驱动/制动内部反转矩和轮胎反作用单独记账。不能把轮胎转角或Bullet skid换名为ω/κ。

真实悬架法向支撑决定自定义Fx/Fy预算；原生frictionSlip/EngineForce/Brake持续为零。前后轴荷估计保留为诊断，不再限驱动/制动。风阻为独立外力，滚阻使用实际支持轮荷总量，仍沿水平速度作为中心外力。每步完成后的κ/α、轮荷与上一施力阶段区分，另存整步接触/制动冲量。

轮胎采用简化径向Magic Formula联合滑移，默认Cκ60000N、前后Cα50000N/rad，shape1.9、curvature.97；低速分母尺度1m/s，.25m/s以下在摩擦圆内求静摩擦无滑移约束。两轮胎子步正/反次序推进，唯一Bullet刚体步为1/120s，max_substeps=0。既有能量/动量、摩擦所有权与静态坡面受力试验见[迁移报告](evidence/PHYS-TIRE-01/README.md)。

用户要求正常游戏/困难仿真两模式，困难仿真像仿真软件一样主打真实，以完整参数表通用参考车起步，再接实车型。正常游戏动力曲线在迁移B基础上×1.055补偿新增轮转动惯量，使既有动力目标保持；未补偿B完整保存，不能把此补偿视为实车标定。[PHYS-MODES-01](tasks/PHYS-MODES-01.md)已贯通每车配置、明确输入辅助/执行器与模式选择，仿真参考车独立使用参数。两个模式不复制物理世界，不靠减抓地制造难度。

当前ABS/TCS/ESC均已接入同一真实执行器与唯一轮胎力路径，独立开关A/B与完整功能组T2通过：[电子控制证据](evidence/CTRL-03/README.md)。ESC制动分配能够释放一侧驾驶者制动请求，以实现满踏板对开附着纠偏；驾驶者制动仍禁止发动机驱动。横摆、侧偏、轮速、轮荷与路面μ取上一完整步仿真真值，未用估计器冒充传感器。
