# 阶段 5A：有限道路交通

日期：2026-09-21。版本：0.5.0。范围是把 1.4 km、三车道的高速预览做成能持续运行的有限交通场景，并清理自由驾驶的比赛框架。无限道路、主动变道、超车、AI 和正式车库不在本阶段。

## 本阶段交付

- 交通车继续使用固定种子出生，但前车距离按车体净距计算，跟车车道只在横向接近时生效。交通车受到玩家和其他交通车影响，近距时会减速，侧碰后先压低横向回正力，避免立即把车体拖穿回车道。
- 交通车驶出 1.4 km 末端后，在远离玩家且与其他车辆留出净距的位置重新进入有限道路。回收位置由车道和循环计数确定，同一种子和同一控制轨迹可重复；没有安全位置时才暂时退出世界，不把车辆传到玩家车头前。
- 高速 R 复位先尝试当前车道、邻车道及前后 8/16 m 的位置，要求与活动交通车中心距离大于 4.2 m；找不到空位时保留原位置，不强行压进车辆。
- 自由驾驶隐藏检查点框架，并把框架刚体碰撞掩码降为查询层；计时挑战开始时恢复显示和车辆碰撞。主菜单和驾驶模式切换会重建场景，避免只改物理而留下画面。
- 交通刚体固定横滚/俯仰自由度，循环重生时清零姿态；碰撞仍由 Bullet 求解，不用每帧设置玩家位置来“修复”碰撞。

## 基线与复现

环境沿用 0.4.1：Windows、Python 3.14、Panda3D 1.10.16、120 Hz 固定步。执行：

```text
.venv/Scripts/python.exe -m pytest -q
.venv/Scripts/python.exe -m ruff check src tests tools
.venv/Scripts/python.exe tools/h3_feedback_check.py
.venv/Scripts/python.exe tools/phase5a_traffic_check.py
```

本次结果：102 项 pytest 通过，Ruff 通过，H3 反馈回归通过。长时记录在 `logs/phase5a/traffic-check.json`。

## 设计边界与 H4A 交接

当前交通车仍是带盒状碰撞代理的简化刚体，主车才使用完整 BulletVehicle、轮胎射线和 `Control` 响应。交通控制的共同语义目前是巡航速度、净车距、纵向加速度和车道横向误差，尚未把每辆 NPC 变成完整四轮车辆；这使 8 车的有限预览稳定、易测，但不能宣称已经完成统一车辆控制。

交给 H4A 的具体问题：是否把交通车迁移为共享车辆组件，如何在 8–16 车下保持 120 Hz，侧偏/轮胎力由 Bullet 还是自有响应负责，碰撞后如何重新选车道和目标。设计草案见 `H4A-traffic-design.md`。5B 的无限分段和 5C 的变道超车要等这个边界确定后再做。

## 未完成事项

- 高速仍是有限 1.4 km 预览，终点逻辑和回收位置不是无限道路。
- 没有主动变道、超车、双向道路或交通灯。
- 交通外观和盒状代理仍是原型资源，车轮/外观轮廓的正式对齐属于 6A/6B。
- 需要用户继续试玩高速跟车、急刹和侧碰后的手感；自动长时通过不替代人工视角验收。
