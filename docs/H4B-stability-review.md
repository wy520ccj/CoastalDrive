# H4B 弯坡稳定性与长距离检查 — 0.6.3

2026-09-22。本轮补齐弯坡路的100公里运行和10个种子的正常车流检查，修复返回起点接口，并减少道路查询的重复计算。全部工作在本地完成。

## 修复与运行成本

- 一次交通决策共用玩家和NPC的道路坐标，避免每个驾驶员重复投影全部车辆。道路内侧用同一纵坐标的中心线点快速判断路面，边缘仍使用完整投影；路肩抓地判定保持原来的6.75米边界。
- 同一种子、12辆NPC、30秒物理运行，600组完整快照和交通控制输出在优化前后逐字节相同；样本运行时间从18.246秒降到8.101秒。它说明这项场景的计算开销下降，不是游戏帧率翻倍的测量。对比记录在 `logs/h4b/followup/before.json`、`after.json`，共同SHA-256为 `a0ff1433af7f425f9c9a591d8889c3022d137ac97b44db0222b77af10e166637`。
- `Simulation.reset_player()`无参数调用原先把旧起点当成重定位后的局部坐标，远处返回时可能落到路外。现在按当前原点换算，并立即加载起点道路。游戏R键使用的就近安全复位不受该问题影响；另用真实Session流程验证了菜单重新开始。
- 新增停车压住坡道接缝、约115 km/h跨接缝、远处返回起点、菜单重开及路面边缘判定回归。全套175项测试、Ruff通过。

## 长距离结果

`tools/curve_drive_check.py`使用普通Control驾驶，120 Hz物理；每步检查玩家/NPC及邻近NPC/NPC接触、全局坐标连续性，每秒检查车道范围、离地高度和横滚。新增距离目标、多种子、进度文件、内存/实体统计和失败现场记录。结果存在时拒绝覆盖。
