# 生涯系统设计依据

用户实际试玩否定此前明亮工坊与道路A/B叠页。重新按赛车游戏的赛事循环组织产品，不继续给原报告加装饰。

| 一手参考 | 采用的结构 | CoastalDrive实现 |
|---|---|---|
| [GT7驾照手册](https://www.gran-turismo.com/gb/gt7/manual/license/01) | 起步/转向/停车逐渐进阶，赛前说明条件与奖励，分档成绩 | 入门起步、停车、宽门绕桩；赛前只展示目标和三档星级；结果直接重试/继续 |
| [FH5 Horizon Adventure官方说明](https://forza.net/news/forza-horizon-5-road-to-mexico-september-update) | 可短时间完成的挑战；成长点数开启后续章节；可选择路线 | 三章六赛，星级总数开赛事；前两项可自由选择，不强迫金牌才能进下一章 |
| [NFS Unbound官方开发说明](https://forums.ea.com/discussions/need-for-speed-unbound-discussion-en/under-the-hood-show-up-and-show-off/9398276) | 车库集中处理性能升级；赛事与成长提供购买资源 | 星级增量奖励积分，解锁并购买现有真实轮胎/制动配置；展示价格/已拥有/已安装 |

采用的是可核对的机制与信息层级，不复制游戏美术、商标、车辆或完整经济参数。赛事距离/阈值按本项目真车物理测定；不把其他游戏的数值硬搬过来。

## 玩家循环

主菜单“海岸生涯”→六项赛事板→单项简报（目标、星级、奖励）→静止起步比赛→结果（获得星级、积分、解锁）→继续/重试/车库。

- 生涯有明确章节和可见下一目标。停车、绕桩、弯道与山路体现不同技能；不把所有任务都做成参数实验。
- 1星是完成基础目标，2/3星鼓励改善操作；首次提高星级才发差额奖励，同一成绩重试不重复刷积分。没有每日任务、随机抽奖或付费货币。
- 起步无速度门槛，停车无固定入门速度，绕桩漏门跑完后按通过数评级。碰撞/复位/离开场地和超时仍按明确条件处理。
- 赛事成绩跨改装保留，进度不会因为换一个零件消失。旧工程A/B与旧严格课题记录留在其原文件，不参与生涯奖励。
- 每页只承担一个任务。赛事页面不显示硬件单位、A/B工程曲线或长段说明；零件具体参数集中在车库零件卡显示。

## 实现边界

新规则读取权威Snapshot与道路标架；Simulation与120Hz不变。独立进程在HighwayResult中回传生涯结果，UI不另算比赛成绩。新生涯文件独立，损坏文件保留并提示，不用旧奖牌推造新生涯成绩。
