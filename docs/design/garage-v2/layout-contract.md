# 车库页面布局规格 v2

依据已实际查看的FH5升级商店截图与本目录三张生成设计图。以1672×941设计图为基准，所有页面保持同一画布与位置。界面为真实控件，背景图不包含文字、车或按钮。

| 区域 | 设计坐标 x/y/w/h | 职责 |
|---|---|---|
| 顶栏 | 0/0/1672/74 | 左品牌、中三页导航、右真实星级/积分 |
| 左操作面板 | 52/122/462/706 | 唯一任务区；32px内边距；标题→分类→详情→价格→主操作 |
| 车辆展示 | 545/250/1080/580 | 完整车身和四轮，不与左面板交叠 |
| 车辆信息 | 1475/127/155/63 | 当前车型、真实kW与kg；右对齐 |
| 底栏 | 0/860/1672/81 | 确认、返回、查看车辆、返回原赛事；不重复顶层导航 |

- 字号层级：面板标题44px、车型26px、部件24px、普通正文18px、辅助16px；中文使用思源黑体Bold，英文品牌使用Chakra Petch。
- 橙色仅标记当前分类、活动页与主操作；正文深墨色，次要说明中灰。面板白色92%不透明，顶/底栏深色72%。圆角4px。
- 升级页分类固定2×2格，轮胎/制动/悬架/动力均有实际功能。09/10为接续先生成的动力/悬架设计图；选择分类只换面板下部详情，购买安装后显示实际安装结果。星级不足时分类可查看，安装按钮显示解锁门槛。
- 车辆页使用同一左面板里的列表，不铺满画面。真实车型数/解锁/当前驾驶状态来自存档，超过可见数量在列表内部翻页；缩略图必须来自实际资产渲染。设计图里的4车是示例数量，不授权虚构车型或使用许可不清的Ferrari候选。
- 涂装页按同一列放选中材质样本、5种颜色、应用按钮；预览不写存档，应用才保存，离开取消预览。
- 主要操作固定在面板x75–490/y711–767；恢复/取消在底部分隔线下方。操作结果放面板内，禁止跑到车辆上覆盖。
- 16:9按高度比例整体缩放；4:3保持操作区可读，车辆展示区缩窄并重新取景，背景居中裁切；不把整个UI缩成一张小网页。
- 资源不齐时记录待办，不以新的程序立方体车、球体车漆或拼凑线条图标代替。原模型仍保留于历史与存档，不冒称本版高质量新增资源。
- 对照验收：三页控件沿同一轴对齐；主按钮不漂移；车辆全入画且不进入左操作区；窗口变化不重叠；键盘焦点沿真实位置移动；显示不创建第二个物理世界。

## 实际车辆的展示取景

- 保持上述面板/车辆/分段区边界；默认展示角55°，允许原左右旋转。按实际被三角形引用的网格顶点投影取景，排除部件包围盒空角和未引用顶点。最终镜位再计算居中，不用上一次二分候选的范围。
- 车身占展示框宽/高上限分别90%/75%，垂直中心保留原向下8%偏移；车轮、车顶、尾翼和后视镜均计入。换漆复用几何缓存；换车或硬件改变时重新提取。仅作用于共享车库展示，工程固定镜头和道路相机保持。
- BRZ短视口宽高比2.17的真实车身宽占比由旧35°/包围盒的56.05%提高到55°/网格的75.51%；同35°改用网格为61.47%。这不是地面反射、光照融合或性能阶段验收。

## 地面融合（17）

- 保持既有构图/控件/车型，参考实际截图生成17；只取低强度地面反射及淡出，不采用生成图额外美化的车身形状。实际反射来自当前车模及漆色，围绕轮胎地面z=0镜像，峰值20%并在.85米内淡出，原接地阴影保留。
