# 车库页面布局规格 v2

依据已实际查看的FH5升级商店截图与本目录三张生成设计图。以1672×941设计图为基准，所有页面保持同一画布与位置。界面为真实控件，背景图不包含文字、车或按钮。

| 区域 | 设计坐标 x/y/w/h | 职责 |
|---|---|---|
| 顶栏 | 0/0/1672/74 | 左品牌、中三页导航、右真实星级/积分 |
| 左操作面板 | 52/122/462/706 | 唯一任务区；32px内边距；标题→分类→详情→价格→主操作 |
| 车辆展示 | 545/250/1080/580 | 完整车身和四轮，不与左面板交叠 |
| 车辆信息 | 1475/127/155/63 | 当前车型、真实kW与kg；右对齐 |
| 底栏 | 0/860/1672/81 | 确认、返回、查看车辆、返回原赛事；不重复顶层导航 |

- 字号层级：面板标题44px、车型26px、部件24px、普通正文18px、辅助16px；中文使用思源黑体Bold，英文品牌使用Chakra Petch。
- 橙色仅标记当前分类、活动页与主操作；正文深墨色，次要说明中灰。面板白色92%不透明，顶/底栏深色72%。圆角4px。
- 升级页分类固定2×2格，轮胎/制动/悬架/动力均有实际功能。09/10为接续先生成的动力/悬架设计图；选择分类只换面板下部详情，购买安装后显示实际安装结果。星级不足时分类可查看，安装按钮显示解锁门槛。
- 车辆页使用同一左面板里的列表，不铺满画面。真实车型数/解锁/当前驾驶状态来自存档，超过可见数量在列表内部翻页；缩略图必须来自实际资产渲染。设计图里的4车是示例数量，不授权虚构车型或使用许可不清的Ferrari候选。
- 涂装页按同一列放选中材质样本、5种颜色、应用按钮；预览不写存档，应用才保存，离开取消预览。
- 主要操作固定在面板x75–490/y711–767；恢复/取消在底部分隔线下方。操作结果放面板内，禁止跑到车辆上覆盖。
- 16:9按高度比例整体缩放；4:3保持操作区可读，车辆展示区缩窄并重新取景，背景居中裁切；不把整个UI缩成一张小网页。
- 资源不齐时记录待办，不以新的程序立方体车、球体车漆或拼凑线条图标代替。原模型仍保留于历史与存档，不冒称本版高质量新增资源。
- 对照验收：三页控件沿同一轴对齐；主按钮不漂移；车辆全入画且不进入左操作区；窗口变化不重叠；键盘焦点沿真实位置移动；显示不创建第二个物理世界。

## 赛事页统一设计

继续使用内置ImageGen、以01升级页作风格参考，先生成05结算、06赛事、07简报、08暂停设计，再改真实控件；完整提示词为同名`-prompt.txt`。背景、字体、顶栏74px、底栏y860/81px、橙色和4px圆角与车库一致。

| 页面 | 内容构图 | 主要操作 |
|---|---|---|
| 赛事板06 | x52/y122起、左右同边距的一个内容区；标题→三章成长→3列2行赛事实景卡；卡下部深色条集中放名称、距离、星级或解锁门槛 | 底栏右侧继续推荐赛事，旁边车库；卡片可鼠标或按实际位置用方向键选择，橙框表示焦点 |
| 赛前简报07 | 左约2/3赛道预览，图底集中标题、下接比赛信息与驾驶提示；右约1/3为三档目标、每星奖励、最佳与规则提示 | 底栏右侧开始比赛，旁边车库；锁定仍可看简报，不能起跑 |
| 赛事结算05 | 左462px面板依次为赛事、结果、三星、用时、积分、总星数、新车/零件/赛事解锁；右侧当前真实车模和下场推荐 | 底栏统一重试、查看新车或车库、继续赛事；保存失败替换左下任务位并提供重试，禁止盖住车辆 |
| 暂停08 | 与车库同一左面板，赛事、暂停状态、继续/重开/退出三项同宽纵排；右侧真实当前车辆，赛事信息独立下置 | 继续为橙色主要操作；Esc恢复原权威世界，不重建或推进物理 |

- 4:3按941px设计高度重排宽度，结算面板收至画幅32%，车辆重新取景；底栏缩短提示，不压叠三个操作。窗口变化保留当前页、结果数据和选中动作，不重新领奖或保存。
- 设计图为布局与视觉规范，示例数值、车型和赛名不作为规则来源；运行时使用实际EVENTS、当前WorkspaceVehicle、CareerResult和CareerProgress。预览继续使用真实游戏赛道截图，未把设计图中更精细的道路当作已实现赛道。
- 05设计示例只列一辆新车；实际同时解锁多车时，车型行列主名称及“同时解锁”名称，零件另行，赛事另列，不省略实际解锁。
- 对照差距保留：真实车型的材质/光照和实际道路精细度低于生成设计；这次统一页面构图，不冒充整个美术资源与人工观感已通过。

2026-10-22接续：用户要求优先开放的现实车型，i20/BMW显示实际来源车型名，真实读数旁标“项目调校”；旧存档键不变。i20替换原H1简易外观，车模与轮胎/内饰图来自ANDREO12的开放源资产。精细三车车漆经隔离对照采用roughness .12 / metallic .65，样本与缩略图同步重渲染；控件位置/规则保持。本轮没有重画或改变已冻结页面构图。

2026-10-22光照接续：修正PfmFile行坐标与Texture装载翻转导致的六面反射错位、天顶/地面颠倒；沿用原128面尺寸、单主灯、曝光和接地阴影。底漆仍.12/.65，在车库paint节点叠加IOR1.5、粗糙度.10的无色透明面层；结算/暂停同用此展示光照，工程预览清除面层，道路着色保持。仅把“原厂橙”改为“日落橙”、窄屏制动说明收短为“制动力偏向前轮”；位置/字号/页面构图保持。

2026-10-22改装接续：动力8星/450积分、悬架12星/400积分；只在明确安装后修改当前车，并共用完整恢复链。详情沿用原图539–695区域：零件图154×154、名称/简短用途、指标标题642、数值666、价格695。功率或平均弹簧刚度显示真实当前→候选值，安装后只显示当前值；设计图示例的固定数字不写入规则。结果零件行允许两行、46px高、17px字，不省略同时解锁的零件；图标按实际零件分类选取。原顶栏/主按钮/底栏/展示区域保持。

2026-10-22车型接续：旧R2槽替换开放的真实Lotus Elise模型，旧存档键/参数/3星解锁保持，显示项目调校；实时车模和独立源车轮复用正式车库展示。七辆目录缩略图统一按实际网格投影正交取景、88%范围留边，避免车头和轮胎裁切；原列表位置、字号与操作不动。

## 驾驶HUD接续11

先实际查看Neowin的FH5实机截图（https://cdn.neowin.com/news/images/uploaded/2021/11/1635882692_forza_horizon_5_2021-11-02_15-23-16.jpg），采用靠边分组/中央留白的功能关系；再用内置ImageGen，以当前GR86真实道路图和01升级页为参考生成 `11-driving-hud.png`，提示词同名保存。该图是设计参考，运行时全部用真实控件和实际快照，不把位图作为HUD或替换3D场景。

| 区域 | 1672×941设计坐标 x/y/w/h | 职责 |
|---|---|---|
| 赛事状态 | 36/40/482/272 | 章节、赛事、主要进度、用时、进度条与下一目标 |
| 三星目标 | 36/322/484/65 | 真实金星门槛，不预发当前成绩星级 |
| 操作提示 | 36/731/531/174 | 情境提示、W/S/AD与C/R键帽；仿真模式显示Q/E选挡 |
| 仪表 | 1141/686/496/219 | 真实车速、挡位、转速及ABS/TCS/ESC状态 |
| 暂停 | 1447/40/189/61 | 可鼠标点击，进入原暂停页；Esc原键盘行为保持 |

- 左区靠左、右区靠右、下区靠底；按941设计高度缩放，两画幅中央道路/车辆保持可见。暗色透明底、8px设计圆角、白字/灰色辅助字与原车库橙色；不用旧奶白描边、整屏底部两行密字或重复“返回赛事”按钮。
- 冲刺显示赛程百分比；停车显示距中心米数（10米内保留一位小数）与Snapshot停稳时间；绕桩显示真实通过数/总门数与下一道门距离。时间、目标和显示进度均来自现有CareerResult/EVENTS，UI不另行评星。
- 原通用驾驶HUD保留给其他玩法；生涯进入/离开时只切换显示组。读快照不维护第二套车辆状态；仪表沿用原7000rpm显示标尺，不更改各车发动机限制。
- 六张赛事预览重新用当前实际场景拍摄，初驶明确使用现有BRZ Varis资源，消除旧方盒车截图；其余保留真实道路/门位。相机取景不移动物理车辆，许可随Preview-License与SHA清单保留。

## 首页、声音、辅助（12—14）

- 先实际查看William Emery发布的FH5 Garage UI原图（ArtStation作品lD1oL5，完整调校页与换装页），再生成12首页、13声音、14辅助；不将参考游戏的截图或品牌资源嵌入游戏。
- 仍以941设计高度布局，同一海岸车库底图、74高顶栏、860起的底栏、橙色主操作、思源黑体与Chakra品牌。首页左面板x=画宽×.031、y122、宽min(462,画宽×.355)、高706；声音/辅助宽min(620,画宽×.46)。4:3按可用宽度重排，主画布不整体缩小；原工程工具的旧父节点保留独立缩放。
- 首页左列按空间顺序为生涯、车库、自由驾驶、计时、专家台，分组副标题说明用途。默认聚焦生涯；底栏右侧为驾驶辅助、声音、退出。上下沿左列移动，底栏左右移动，上键回左列末项；返回保留原焦点。
- 声音的三个通道纵向排列：标题/用途/百分比/进度与加减按钮为同组；上下按通道移动，左右调值。电台名、曲名与切换按钮同组。辅助使用ABS/TCS/ESC三行原生开关，开启/关闭有文字与滑钮位置，不再画简陋车辆示意。
- 两设置页借用原八个/四个业务按钮、保存及暂停返回逻辑。车库共用唯一WorkshopVehicle显示场景，不创建物理世界；进入其他页面停用对应显示缓冲，刷新移除背景控件、焦点几何和滑钮。实际车型/颜色来自玩家车辆，不为贴合设计示例改漆或改硬件。
- 右车展示框位于面板右侧18px、y220、高620；按真实车型外廓完整取景。生成图中的更大车身和更精细光照仍是美术目标，不以排版完成冒充材质融合完成。
- 首页直接进车库时底栏写“返回首页”，动作返回原首页；赛事简报/结算进车库时仍返回原赛事。Tabler五个线性图标使用官方3.49.0/MIT字体子集，许可与源包保留。
