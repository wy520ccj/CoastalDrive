# 37 滨海两模式的光照与路面统一

2026-10-28，VISUAL-EXTEND-01第二块。范围为原滨海自由驾驶/计时挑战的晴空、照明、车辆反射与路面材质；不替换赛道、地形/树木轮廓、碰撞或规则。后续完整植被升级单独制作样板，不能以本次光照材质统一宣布全部美术完成。

## 事前研究与真实输入

沿用[设计36](36-lab-daylight.md)已实际审看的RenderPipeline汽车/材质/编辑器整图和固定版本源码。此次采用的是过滤环境与粗糙度相配、同一光照源同时驱动车漆和场景、稳定投影和资源只准备一次的方法；不引入全屏SSR或更换管线。用户接续明确“不同地形要符合现实、有差异”，因此复用光照方法而不把每个区域换成同一背景：山脊保留当前48d薄云，有限滨海使用项目已登记的43d更开阔晴空/同源环境/太阳约42.9度；不修改生涯现在的天空/资源。试验台维持固定照明便于试验比较。

本轮重新运行真实滨海场景，实际查看`logs/visual-extend-20261028/coastal-before/coast-000.png`及090图：旧彩绘黄云占近半画面，路面为均匀色，树/石/地形保持原低多边形轮廓，海面和道路边界清楚。225图另存。该工具只固定镜头，静态分项不能作为正常驾驶帧率；当前试验台预览仍在，不能称单实例整机性能。

## 制作规格

- 以000起点图作编辑参考，保持原相机、道路宽度/曲率/护栏、红白路肩、植株/石块/路灯全部位置、树冠几何轮廓与海岸线。
- 仅将旧彩绘天改为更适合开阔海岸的43d清朗晴空，沿用生成图37的开阔蓝天/少云关系；太阳方向与反射同源。阴影朝向一致，近景阴面仍有细节，不以大雾遮远景或提高整体曝光。
- 原路面使用已有Asphalt03实拍底色/GL法线/粗糙度；2–2.5m米制平铺，深中性灰、粗糙而非湿镜面，所有路标/护栏几何保持。原地面配色和海面先保留，不用一块新草纹理遮掉原地貌分区。
- 相同显示网格和状态组织，不增光源、后处理或通道；太阳投影沿像素格移动，避免新细节放大阴影游动。
- 同样光照/材质适用于自由驾驶和计时挑战，两者的检查点可见性/倒计时/HUD/计分分别保留。
- 同时检查原/新场景模型数据不变、赛道/碰撞/车辆配置保持、模式往返及资源生命周期。画面实图和正常窗口性能/人工接受分别记账。

已使用内置ImageGen基于真实000图生成并保存[37-coastal-daylight.png](37-coastal-daylight.png)。目标图保持原构图与低多边形树轮廓，薄云晴空和路面材质可制作；生成器额外增强海面细节和草地微层次，不能把这些视为已实现，也不据此重做海面或植被。目标是完整画面中的光照材质统一，不把生成图冒充已实现。
