# 43 与陆地连续的城镇段

当前追车布局由[45](45-city-street.md)进一步校正：常规两街41/131米，首排中心约65–70米，桥位退回65/155米；本文及44的较早位置为对应历史阶段。大陆、自然岸线、四住宅族与材质来源继续沿用，城市整体尚未验收。

墙面涂层校色：顶点色定义本图的奶油白/浅灰/赭色涂层，White Plaster 02只提供相对表面变化；按原1K底色解码后的线性RGB均值归一化，避免将灰色摄影底色再次乘暗整栋楼。色斑仅保留35%混合，避免涂层变成裸水泥的大块斑驳；原贴图像素、法线、粗糙度、天空、太阳和曝光不变，近远档使用同一校色；必须用同镜位且阴影已就绪的实际图对照。

远景仍需保留真实窗洞与后退窗片，不能把玻璃叠在整面墙前靠深度偏移支撑；两档的开口、遮蔽和平均覆盖率保持一致，省去的是窗框小件、帘褶与金属细杆。

街区密度校正：复用本图的两侧街道、背靠背院落和错落楼群关系，第二街从245米收至175米；每段仍为8栋共享住宅，不靠增加楼数填空。两排楼中心约110/148米，第二排入口转向外侧街道，两排后院围合约14米宽的公共绿带。沿路位置错开约半个地块，避免四模板像展品一样成列。上层缓台延伸至175米，175–245米衔接原下层岸后地形；只改35米以外的表现地形。横街两端增加人行衔接，公共绿带设贯通步道，原散置树木移到街边和后院绿带，控制种植总量。仍须检查入口朝向、地块净距、段界衔接与原追车构图。

## 事前研究

实际查看[Seth Brown的FH5 Guanajuato](https://seth_brown.artstation.com/projects/eaGB3P)首幅完整街景：街道坡度、院墙/建筑基座和入口相互连接，街区顺地形伸展，非单栋陈列。实际查看[Josef Šenfeld的KCD2 Troskowitz](https://josefsenfeld.artstation.com/projects/AZg9vX)landscape完整图：草地、路径、宅基地和背后林地形成连续高程与使用关系。只采用空间组织，不复制墨西哥色彩或中世纪物件。

核对当前实机生成器：海侧陆地约74米即降至海面，旧楼却位于220–260米，city-quay是唯一支撑；仅细化立面不能解决。当前建筑侧向图留在logs/all-scene-20261029/city-before。

## 制作规格

- 城镇位于工程区间2/3对应的海侧大陆缓台，地形从原路肩连续展开到约340米自然岸线；两端用240米以上的距离过渡，与相邻海岸连续。海侧不再出现矩形托盘/人工孤岛。
- 原主路、路肩和20–34米物理树带不变；新增缓台只在现有表现地形范围外展开，海平面仍为原值。
- 岸后是草土、街道、步道、地块、院落的组合。只给街道和步道铺装，不能把城镇整体铺成水泥板。
- 两条地方道路沿城镇走向连接，横街与街角形成可读街区；楼门面向街道，低中层建筑为主，少量较高体量组成层次。四种几何模板重复组合，近处有窗洞层次、基座/屋顶，远处简化但保留轮廓与平均明暗。
- 街区有绿地及行道树，所有楼基与种植根部读取同一地形高度。模板在加载阶段准备，路段中复制/摆放；不新增灯或全屏效果，不引入城市交通模拟或改变高速玩法。
- 施工后先看侧向地形/街道全貌，再看正常3.2米追车视角；检查段边界、两端过渡、岸线和近远模型。静态采图不能替代真实驾驶性能。

设计检查：新图已消除孤立水泥托盘；保留连续大陆、自然岸线和街区逻辑。生成器改变了主路构图、远景和水面，这些不照抄；实际实施以原路网/光照/天空为准。设计中的完整建筑细节必须在运行样板逐项对照，未通过不能报完成。

2026-10-29用户否定灰盒立面后，继续按本图施工：住宅采用有厚度的窗洞/窗框、可读的成组阳台和金属栏杆、门厅雨棚、石基、屋顶女儿墙及局部退台；灰泥按一米尺度读取真实CC0表面，玻璃与墙体材质分开。庭院补低墙、树池、成组灌木和乔木；地方街道补路缘、标线和灯杆，院内少量停放项目已有车辆，仅为静态表现且不生成碰撞。四模板和两档LOD共享资源，不将已否定的简陋盒体当作完成品。

实际3.2米镜位的4.2公里复测表明，首排165米外/海平面缓台偏离本图的近中景关系，楼群只剩地平线上的细条。按图校正：首街靠到85米、首排楼中心约110米，落在比主路低约4米的陆地上层缓台；145–235米逐渐衔接下层街区及自然岸线，原35米内树带不动。楼基按实际四角高程做水平基础，低端石基外露，门前台阶连接坡地，不能把门埋进地面。240米外简化窗框/微细栏杆及金属响应，保留同样阳台、退台和屋顶轮廓；庭院小灌木在190米外退出。近中景和接地须用实际追车镜位重新验证，不能只看俯视图。

门厅细节延续本图的完整装修与通行关系：石基在正门两扇门片前断开，中央门框保留，门前台阶与门槛相接。窗帘只改变窗洞内侧颜色，不改变阳台/侧墙涂层；近远档相同表面保持一致颜色，避免切换时变色。

背景山体继续以本图的深绿林坡和灰褐裸岩为目标。材质沿用已有顶点RGB的林地宏观分区，alpha只控制岩面覆盖；三向平铺读取当前有许可的岩层图，岩石采用与默认山体相同的反照率校准。修正本地覆盖材质丢弃林地RGB、直接使用未校准岩面底色的问题；不调暗全局太阳/曝光，不换认可天空，不增加雾或用雾遮盖山体。不改变当前几何、距离裁剪或驾驶视线，先用同镜位离屏成品检查。

庭院接地沿用本图的坡地宅基地：低院墙和压顶读取各自四角实际地面，随纵坡连接；仅花池和小停车位顶面保持水平，其基础下探入土。入口铺装随坡到门前，台阶包含落地的实体立面，不能只悬挂踏板。院树按自身根位取高程，灌木落在实际花池土面；不以整院铺板抹平高差，不增加住宅/乔木数量、碰撞物或渲染通道。四模板和街区布局保持，构件仍按既有材质局部合批。

院墙和楼基选Amal Kumar的CC0 Rustic Stone Wall 02，已查看作者实拍色卡整图：灰褐板状石横向叠砌、约十层/1.5米，比大块堡垒石或破损灰泥更符合本图矮墙。使用官方1K原底色、GL法线、粗糙度，原像素不改；每1.5米重复一次，按线性均值归一后由既有顶点色确定灰褐底色，保留完整石缝变化。院墙/花池为粗砌石，压顶、台阶及窗框收边仍较平整。将原庭院stone组替换为masonry，台阶并入原trim组，保持三组材质；每栋基础仍一个Geom。灰泥沿用原35%变化与0.18法线强度，石墙法线0.6，不改灯、天空、曝光或物理。来源及SHA见art/expressway/sources/city-stone/manifest.json。

步道选Charlotte Baglioni摄影、Dario Barresi处理的CC0 Floor Pavement；已实际比较三种完整底色图，排除Pavement05的小石块和Square Concrete Pavers的细格花纹，保留灰色大方块与浅石缝。官方2米尺度、1K原底色/GL法线/粗糙度，变化80%、法线0.35，继续既有暖灰顶点色；UV按道路横距/里程的米制坐标展开，600米重复周期是完整300次贴图，段界不得断缝。人行道、横街步道、公共绿带和入户通路共用贴图与原PBR shader。入户步道宽2.96米，端点接实际楼门立面；移除院内重复平板，台阶保留实体，材质组不增加。三类表面共九图在加载样面提前准备，不把首次上传留到驾驶中。

公路—城市林缘沿用本图的成组树冠、低灌丛和看城开口：每200米仍6棵7–9米乔木、12株1.5米灌木，重组成3组，每组2树/4灌。树群置于首排门位35/78/121/164米之间的空档，门位前后5米保留沿横向看城的植被净空；树干在公路49–65米处，35米内权威树带不动。两种源树仍各一棵7/8/9米，避免借增树和放大树冠填空。院树局部左右错落，停车地块继续避开停车位；仍按树根自身位置接地。完整原3.2米追车镜位优先，不能用单株或俯视近图冒充10–100米构图验收。
