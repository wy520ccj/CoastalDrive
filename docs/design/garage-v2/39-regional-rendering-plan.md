# 全场景画面扩展：地区与用途

2026-10-28用户明确更新总目标：将画面质量与优化推广到全场景，保持玩法/地区真实差异，多参考tobspr/RenderPipeline。先完成海岸设计38与真实成品的差距，再逐块推广；当前已接受的山地晴空、驾驶参数与3.2m镜位保持。此文是范围与技术规格，不能代替设计图；海岸继续复用已先生成的38作为目标，其它实质视觉调整须先生成对应设计图。

## 源码核对的范围

TrackId共四种：滨海环路、多车道高速原型、无限高速、动力学测试场。GameMode共14种：自由/计时/距离，制动课/短距制动，绕桩课/快速绕桩/绕桩练习，生涯，组合弯/山脊冲刺，河谷巡航，安全超车，山路会车。不能因为共享Scene而把这些入口全判通过。

| 场景族 | 地区与实际用途 | 画面方向 | 优化与验收重点 |
| --- | --- | --- | --- |
| 有限滨海自由/计时 | 同一滨海环路 | 设计38低空夕阳、冷蓝高空/海面、金色碎光；松林草坡/岩岸/灯塔层次 | 同源天空/反射、静态准备复用；保留真实动态水面，两模式分别检验 |
| 生涯/组合弯沿海路线 | coast-club等有曲率的海岸道路 | 与地区一致的植被/岩岸，稳定同场天气；不能在路段边界突然昼夜切换 | 准备/合批分帧，LOD与阴影连续，模式规则/检查点独立 |
| 山脊/会车/生涯山路 | ridge-club及高程变化道路 | 保持已接受48d晴空与山地植被；冷暖随受光面，不套海岸橙色 | 近中远草树岩组成、坡顶视野、车辆接地、分段边界 |
| 河谷/超车/高速 | 原路线与交通走廊 | 地势更低、开阔水岸或道路设施；同地区素材有组合差异 | 更远视距、遮挡/批次与交通可读性；不可删交通或景物过关 |
| 试验台/测试场 | 车辆试验与A/B数据 | 稳定中性照明与易读地面，真实接地；不混入夕阳眩光或动态天气 | 共享过滤环境、不重复加载大HDR；试验台独立/主窗口往返同车同物理 |
| 菜单/车库/工坊/结算/暂停 | 选车、改装、试验、比赛反馈 | 沿用成熟字体/层级；按用途和当前地区保持视觉连续，不另堆说明卡片 | 按真实操作链逐页核对，保护已接受布局/键盘/保存与回看 |

## 本轮新增仓库研究

固定原仓库f858d071d54902e7d00eb0046dd5730eac9e4678，已保存完整树目录与实际源码。原云层CloudVoxelStage用256×256×32体素、分开生成/着色；precompute.py先离线生成128³与32³三维噪声。ApplyCloudsStage为半分辨率raymarch→上采样→合成，实际是多个运行步骤，不能只因为名字叫优化就直接接入。本仓库render_clouds.frag.glsl明确标注WORK IN PROGRESS/unfinished，部分高度/覆盖逻辑未启用，因此不把它视为可直接生产移植的成熟云实现。

可借鉴的组织方法：预计算噪声和可静态准备的资源、显示与照明/环境反射同源、按需要限定运行成本。海岸接下来先做离线云层/天空样板，运行继续使用普通天空贴图与预过滤环境，不把多步体积云成本塞进驾驶帧。样板只作为设计38的资源实现候选，必须同镜位真实运行对照后决定采用。

继续沿用已实看原作者汽车/SSR/编辑器整图与设计36/38。细分地区的资源选择须核对实际模型/许可，不能把同一套树/草换色后到处复制，也不能用新设计图掩盖之前未达到设计38的事实。
