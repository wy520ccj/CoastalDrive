# 31 山脊随车草坡与林缘

2026-10-25。复用26实际查看的Petr Sušanka Nebakov Nature与Stefan Williams HD2岩体完整场景研究；本轮重新打开作者原页核对内容，实际对照r148山脊120m与现有30。内置imagegen以r148为编辑目标、30为群落/光色参考生成31，生成后才施工。本机原游戏包只读，HD2仍未解出网格。

## 制作规格

- 原山脊左弯、坡度/8m地形、追车相机、银白Lotus、道路/护栏/HUD保持。10–150m植被为主体，不增加远山/浓雾/光束，不以黄金时段染整幅画。
- 保留29同一实拍天空/太阳方向与强度。树冠迎光面读出黄绿/橄榄绿，背阴保持可见层次；不是整树统一乘暖色。原树形/LOD/既有天空遮蔽继续保留。
- 草坡用数米到十几米连续不规则生长斑块：大部分低草，局部略高的鲜/干草互相过渡；地表、草高、品系和受光变化使用同一世界坐标场。保留候选数量与原格根部高度，不靠删除整片草换纹理。
- 继续用现有原件牧草地/干草地低通mip组织群落，与林冠覆盖相接；密林下已有落叶土与较低密度，林缘不画独立褐圈。草簇顶点全用同一株根位置的生长值，保持枝叶连贯，原8m三角形高度贴合不变。
- 先落实草高与原法线受光的中距离变化，地面底色随同一生长值轻微变化；源图集、可见alpha阈值、mip、透光与高光不改。不得重新铺贴脸细叶或全树LOD0；r43/r44该方向收益已有限。
- 正常山脊120m先看连续坡面，再看40/190/270m，另取沿海450m与原相机对照；正常渲染帧耗、草根GPU高度、用户实际驾驶/视觉分别记账。

## 设计检查

31的右坡草高/疏密关系比当前均匀草毯更清楚，左侧林下层次更完整，未增加建筑或幻想物件。生成仍将树叶整体偏黄、改变车与HUD字形/尺寸，局部护栏和道路线型也有漂移；这些不写入实机。光色以29当前日照为边界，不能照搬秋黄色。31是目标，未实现或通过人工验收。

## 树冠受光样板的实施边界（施工前）

r156固定原随车120m，直接读simplepbr色调映射前HDR，10–150m可见树木像素分离直射、透光、天空漫反射、高光与阴影。候选继续沿31的阴面有细节、迎光成大形关系；不抬整幅曝光/太阳，也不关闭自阴影。当前材质已有太阳透光，天空间接光却仅有正面反射；下一仅试薄叶的背面天空透光，以同一SH的反法线方向、原SSS贴图/透光颜色/BackDiffuseMultiplier和天空遮蔽估计。0/0.5/1/2强度同镜位实际选型，0为原效果，2仅夸张诊断；通过后只对木本植被启用，草/石/车/道路保持。模型位置/法线/alpha/LOD和阴影深度不变。

该项是本项目的局部两面环境光近似，非KCD2真实GI或原参数绝对还原。理论方向参考NVIDIA GPU Gems 3第4.4节的薄叶双面透光；反向SH采样公式为此处的实现选择，不能归称文献的原式。转向billboard的阴影偏移仍不套用到固定叶卡。先看整体树冠，不再增加贴脸纹理。


同镜位选型后采用木本叶片1倍背面天空透光，草在着色器内编译掉此项，不仅把运行强度设零。天空SH二阶展开反转方向只有一阶项变号，复用未截断的正面结果减去两倍一阶项；实际原树三档GPU误差最大约9.54e-7，阴影深度字节保持、SSS零遮罩时画面逐像素保持。该项只补薄叶的反面天光，不改变原太阳透光、世界曝光或树木源法线；其它树冠明暗形体问题仍待后续样板。
