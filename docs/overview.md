# CoastalDrive 程序介绍

**CoastalDrive 把滨海驾驶、车辆参数试验和工程车试驾连接在一起。** 它使用Python与Panda3D/Bullet构建，既有可以直接操作的驾驶场景，也有能够设置工况、记录结果、比较方案的车辆动力学实验台。

> 当前是开发中的半成品，功能不齐全，潜在bug可能较多。[下载开发试玩版](download.md)前请按开发阶段的完成度预期体验。本文介绍当前已接入的能力，具体实验仍受车辆配置和计算条件约束。

## 两种工作方式

| | 驾驶游戏 | 车辆实验台 |
|---|---|---|
| 主要用途 | 自由驾驶、挑战和实际操作体验 | 在相同条件下研究参数对结果的影响 |
| 场景 | 海岸道路与无限高速、交通车辆 | 默认无交通的研究场地及显式凸起工况 |
| 输入 | 键盘操控与驾驶辅助 | 预设工况、直接执行器输入或路径驾驶员 |
| 时间 | 随实际驾驶推进 | 固定步离线计算，可暂停/单步；回看读取历史快照 |
| 输出 | 驾驶画面、仪表、成绩与诊断 | 动画、曲线、工程指标、A/B与完整记录 |

两个工作区共享同一物理核心与工程车配置，在同一个系统窗口中切换。进入另一工作区前释放旧会话；同一次程序内保留实验台草稿、A/B、曲线、时间游标和窗口尺寸。保存并应用工程车后，下次启动可恢复已保存车辆及关联试验。

## 游戏内容

滨海道路提供自由驾驶与计时挑战。自由驾驶适合感受转向、加减速、不同车辆配置以及碰撞反馈；计时挑战沿既定检查点完成路线并保存成绩。车辆允许停车后倒车调姿，也能使用复位键回到当前路段中心并扶正。

无限高速包含持续生成的道路、直路/弯坡和三档车流，可自由巡航或参加5公里无碰撞挑战。交通车辆具有跟车、变速、变道及碰撞行为；繁忙车流、长时间运行和复杂事故恢复仍需要进一步验证。

车库提供可选外观/工程设计和五种车漆。工程设计包括游戏调校、后驱/前驱/四驱参考车，以及GR86 Premium 6MT配置；部分设计共用外观资源，工程设计数量不等于独立外观模型数量。GR86配置包含公开硬件资料和明确的工程初值，尚未完成实车标定。

表现层包括海岸环境、驾驶相机、仪表与诊断信息、发动机与碰撞声、主菜单音乐和可切换的驾驶电台。设置页可调整音量并试听电台；驾驶中窗口失焦会自动暂停。声音及美术的实际体验仍按阶段分别验收。

## 实验台能做什么

先选择车辆设计，再设置工况与条件。可修改的内容包括初速、路面附着、ABS/ESC、时长、转角、转向起始时间、质心高度、轮胎基准载荷及工况专用字段；完整工程JSON可通过记录菜单导入。无关字段会随工况禁用，防止填写了数值却误以为参与计算。

当前十种工况如下：

| 工况 | 用途 |
|---|---|
| 直线制动 | 比较附着、制动与电子辅助下的速度、减速度及停车距离 |
| 阶跃转向 | 观察突然施加前轮转角后的横摆与车身响应 |
| 固定转角 | 观察固定直接转角下的持续运动 |
| 正弦转向 | 观察周期转向输入下的响应 |
| 执行器输入 | 直接设置转角、踏板/离合比例与挡位 |
| 定圆试验 | 路径驾驶员沿参考圆行驶，观察路径误差与车辆响应 |
| 参考双移线 | 跟随研究用双移线路径，观察横向瞬态和路径跟踪；不是ISO认证测试 |
| 对开附着制动 | 比较左右附着不同条件下的制动与偏转 |
| 单侧凸起 / 轮跳 | 使用匹配的独立轮心工程模型，观察越过实体凸起后的车身/轮心与接地响应 |
| 单侧凸起 / 制动 | 在凸起与制动组合条件下观察车身、悬架和接地；同样需要相应工程配置 |

参数悬停和F1说明提供公式、符号、单位、用途、来源及对应实现入口。工程输入与自动计算量有明确区分，已运行试验使用自己的冻结配置，之后编辑但未运行的草稿不会改变原结果。

主界面提供两张主曲线、详细信号与曲线组切换。工程分析包含制动指标、横摆/侧偏/侧倾、轮荷与附着利用率，以及相应配置下的悬架/乘坐接地读数；只有满足计算区间、稳态或模型条件时才生成对应指标，并保留条件未满足的原因。

计算可暂停或单步。拖动时间轴会切换车辆姿态和曲线游标，运行中回看会暂停离线计算；回放倍率只影响已有记录的观看速度。复杂模型可能慢于实时，应分别观察模拟时长和实际计算耗时。

## 从一次试验到实际试驾

1. **建立基线。** 进入实验台，以100km/h、μ=1.1运行直线制动，完成后固定当前结果为A。
2. **改变一个条件。** 将μ改为0.6并运行B，查看速度/减速度曲线、模型停车距离及A/B差值。
3. **检查和保存。** 通过时间轴回看过程，检查完整配置与指标条件，导出CSV/HTML报告。
4. **进入游戏对照。** 打开“游戏联动”，运行同命令的游戏积分对照，或保存车辆并进入滨海自由驾驶。
5. **返回继续分析。** 点击驾驶界面右上角或暂停页的“返回实验台”，继续查看原工况、草稿、A/B和游标。

游戏联动应用的是已正常完成试验的有效配置。游戏侧保留原有键盘辅助和单机械步取舍，参考实验保留双机械子步；同命令对照保存两边记录与误差，不会自动调参，也不自动判定误差合格。详细保存/恢复规则见[车辆设计闭环](vehicle-design-loop.md)。

## 记录和数据

导出会新建独立记录目录，包含`signals.csv`、`vehicle.json`、`experiment.json`、`snapshots.bin`和`report.html`。有A基线时另存基线与比较信息。记录保留执行器命令、完整车辆配置、原始快照及模型来源，便于区分“改了什么”和“结果变了多少”。

载入时检查数据一致性。同源复算要求相容的源码/原生运行库及记录条件；不满足条件时不把旧记录冒充为当前版本重新算出的结果。动画回放本身读取已保存快照。

默认设置、成绩、日志和工程数据在`%LOCALAPPDATA%\CoastalDrive`；卸载保留此目录，自行导出到其他位置的文件也由用户保管。[安装、更新与卸载说明](download.md)

## 技术实现

唯一权威的Simulation以120Hz固定步推进，控制输入、物理状态、游戏规则和表现层分别组织。界面、相机、音频和分析读取完成步快照，避免界面帧率另行改变物理时间。

车辆模型涉及动力/传动、离合与挡位、轮胎纵横向响应、悬架与轮荷、路面接触及ABS/TCS/ESC等辅助。部分计算使用项目内严格浮点的C/C++扩展。普通精度Windows运行包自带这些依赖；隔离双精度Panda3D/Bullet运行库仍通过源码开发入口配置。

本项目按源代码、回归测试、固定种子试验、实际渲染与用户试玩分别验证。开发记录中的局部速度收益或短测通过不自动代表整个模型精度、长期性能或游戏体验已完成。

## 当前重点与后续方向

现阶段重点是打通工程车设计、参考试验、游戏积分对照和试驾，修复使用中暴露的输入、切换、记录与显示问题，并建立标准工况和可解释的误差范围。

后续仍需继续完善模型验证和实车参数标定、复杂道路/交通的稳定性、性能与跨机器兼容，以及玩法和内容。AI训练接口、自动标定和玩家一键AI接管属于后续研究方向，本版未提供。具体顺序以[当前进度](current-progress.md)和[开发计划](development-plan.md)为准。

想直接体验请从[下载页](download.md)获取完整安装包；想了解实现可从[仓库首页](../README.md)的源码说明开始。遇到问题请在[Issues](https://github.com/wy520ccj/CoastalDrive/issues)附版本、操作步骤与必要日志。
